# Handoff: 우리아이학원찾기 (학원 검색·정보 서비스)

## Overview
학부모가 지역(시/도 → 시군구 → 읍면동)과 과목·학원명으로 학원을 검색하고, 분류별 개수 → 학원 목록 → 학원 상세로 이어지는 흐름을 제공하는 웹/모바일 반응형 서비스입니다. 이 번들은 오늘 작업한 **모든 화면**을 담고 있습니다.

## About the Design Files
이 번들의 `.dc.html` 파일들은 **HTML로 만든 디자인 레퍼런스(프로토타입)**입니다. 최종 룩앤필과 동작을 보여주는 목적이며, 그대로 프로덕션에 넣는 코드가 아닙니다. 목표는 **이 디자인을 대상 코드베이스의 기존 환경(React/Vue/Next 등)과 패턴·라이브러리로 재구현**하는 것입니다. 환경이 아직 없다면 프로젝트에 가장 적합한 프레임워크를 선택해 구현하세요.

각 `.dc.html`은 브라우저로 바로 열리며, 동작을 위해 같은 폴더의 `support.js`가 필요합니다(런타임). 로고 자리에는 `image-slot.js`(드래그 이미지 슬롯)가 쓰인 화면이 있습니다. 실제 구현에서는 이 런타임을 쓸 필요 없이 마크업/스타일만 참고하면 됩니다.

## Fidelity
**High-fidelity (hifi)** — 색상·타이포·간격·상호작용이 최종안입니다. UI를 픽셀 단위로 재현하되, 코드베이스의 기존 컴포넌트/디자인 시스템을 사용하세요. 데이터(학원 개수, 목록, 가격 등)는 모두 **플레이스홀더**이며 실제 값은 백엔드에서 채웁니다.

## Screens / Views

### 1) 홈 — `우리아이학원찾기.dc.html`
- **Purpose**: 지역·과목/학원명 검색 진입점.
- **Layout**: 상단 화이트 헤더(로고+서비스명), 연보라(#eef1fb) 히어로 영역에 큰 타이틀 2줄 + 안내문 + 파란 테두리 검색 카드. 하단에 지역/분야 요약, 푸터.
- **Components**:
  - 헤더: 로고 슬롯(36px, 파란 배경 돋보기 아이콘) + "우리아이학원찾기"(800, 18px, #1a2a52).
  - 타이틀: "우리 아이에게 맞는 학원, / 수강료까지 한눈에" (800, 34px, #16213e). 안내문 "지역을 선택하고 과목이나 학원명으로 검색하세요." (#6b74a0).
  - 검색 카드: 흰 배경, 1.5px #3b5bdb 테두리, radius 16. 상단 3개 select(시도 선택/시군구 전체/읍면동 전체), 하단 텍스트 입력("과목이나 학원명") + 파란 "검색" 버튼.
  - 요약: `지역  서울 · 경기 · 인천`, `분야  국어·논술 · 수학 · 영어 · 과학 · 미술 · 음악 · 체육 · 외국어 · 독서실·스터디카페` (라벨+목록 hanging-indent 정렬; 외국어부터 nowrap 그룹).

### 2) 검색 결과(분류별 개수) — `검색결과.dc.html`
- **Purpose**: 지역 선택 후, 분류별 학원 개수를 카드로 보여줌.
- **Layout**: 헤더(로고+필터 3 select+검색바), breadcrumb(홈 › 서울 › 강동구), 제목("강동구 학원 총 1,569개"), 카테고리 카드 그리드.
- **Components**: 정사각형 카드(aspect-ratio 1). 각 카드 = 아이콘 타일(연보라 배경, 파란 글리프/아이콘) → 과목명 → 개수(파란 800).
  - 아이콘 매핑(임시, 추후 실제 로고 교체): 국어·논술=가나다, 수학=π, 영어=ABC, 과학=Phosphor `flask`, 미술=`paint-brush`, 음악=♪, 체육=`basketball`, 외국어=`translate`, 독서실·스터디카페=`book-open-text`, 기타=`dots-three`.
  - **반응형**: 웹 5열×2행(`repeat(5,1fr)`), 모바일(≤560px) 3열, `기타`는 마지막 줄 가운데 정렬(`grid-column:2`).

### 3) 학원 목록 — `학원목록.dc.html` (서울+강동구) / `학원목록_서울.dc.html` (서울 전체)
- **Purpose**: 검색어(예: "국어") 결과 학원 리스트.
- **Layout**: sticky 헤더(필터+검색, 검색값 "국어"), breadcrumb, **카테고리 필터 바(10개 버튼)**, 학원 카드 그리드.
- **카테고리 바**: 웹은 10등분 1줄(`repeat(10,1fr)`), 버튼=아이콘+과목명(2줄 허용)+개수. 선택된 과목(국어·논술)은 파란 활성 상태. 모바일은 5열×2행 그리드, 개수는 각 버튼 **우상단 배지**로 표시.
- **학원 카드**: 웹 2열(`repeat(2,1fr)`), 모바일 1열. 카드 = 학원명(700, 15.5px) + 우측 가격(파란 800, 예 `170,000원~`) 또는 `수강료 미확인` 회색 pill; 그 아래 위치·유형(예 `인사동 · 보습`).
  - **정보 제공 여부**: 가격 아래 라벨 `정보 미제공`(회색) / 정보 제공 학원은 카드 우하단 **노란 대각선 리본 "정보확인"**(#f5c518)으로 강조하고 상위 노출.
  - **두 변형 차이**: `학원목록.dc.html`은 시군구=강동구, breadcrumb 홈›서울›강동구, 위치에 구 생략(예 `인사동 · 보습`). `학원목록_서울.dc.html`은 시군구=전체, breadcrumb 홈›서울, 위치에 구 포함(예 `강동구 인사동 · 보습`). 코드에서 선택 조건에 따라 이 규칙으로 표시하세요.
- **모바일 프레임**: 앱 최대폭 520px, 콘텐츠 375px 가운데 정렬. 스크롤바는 오버레이(숨김) 처리.

### 4) 학원 상세 — `학원상세.dc.html`
- **Purpose**: 개별 학원 정보.
- **Layout(웹)**: breadcrumb(서울›강동구›수학). 상단 2박스 한 줄(프로필 | 기본 정보, 같은 높이 stretch) → 전체 폭 **개인 배너** → 전체 폭 **AdSense 광고** → 2열(왼: 쿠팡 배너·수강료·888광고 / 오른: 쿠팡 배너) → 별점은 프로필 안, 하단 다른 학원 목록.
  - **모바일 순서(grid-template-areas)**: 프로필 → 개인 배너 → 광고 → 기본 정보 → … 로 재배치.
- **프로필 박스**: 좌상단 `● 운영중`(초록), 우상단 **노란 "정보확인" 배지**(seal-check). 학원명(800, 25px). 태그 pill(수학/초등학생/중학생/고등학생). 중앙 **지도 보기** 박스. 좌하단 별점(★★★★☆ 평균 4.0점 (1명 참여) · 내 별점: 4점), 우하단 **정보 등록·수정 요청** 버튼.
- **기본 정보 박스**: 헤더 "기본 정보" + 행(주소/전화(파란 링크)/분야/정원/등록일). **카드 하단에 파란 "지금 전화 문의" CTA 바**(02-3426-9092)를 붙여 빈 공간 채움.
- **다른 학원 목록**: 제목 "강동구의 다른 수학학원" + 우측 "명일동 · 수학 더보기"(현재 학원의 주소 동·대표과목 기준). 각 행 = 학원명 + 배지.
  - **배지 규칙(중요)**: `정보확인`(노랑)은 학원이 폼으로 수강료 등 정보를 제공한 상태 → **항상 `수강료✓`(초록) 동반**. `수강료✓` 단독은 가능. 둘 다 없음도 가능. (예: 106=없음, 1:1코칭=수강료✓, 21수학=정보확인+수강료✓, CMW=정보확인+수강료✓, CM수학=없음.)

## Interactions & Behavior
- 지역 select 3단(시도→시군구→읍면동)로 범위 좁힘. 검색 버튼 → 목록/개수 페이지 이동.
- 카테고리 카드/필터 버튼 클릭 → 해당 과목 목록. 선택 과목은 활성 색상.
- 학원 카드/행 클릭 → 학원 상세.
- 전화 CTA → `tel:` 링크. 지도 보기 → 지도 뷰(미구현, 자리만).
- "더보기" → 현재 학원의 동·대표과목 기준 추가 목록.
- 반응형: ≤560px에서 모바일 레이아웃(단일 열, 필터 바 2줄, 상세 그리드 재정렬). 앱 최대폭 520px, 콘텐츠 375px 가운데 정렬.

## State Management
- 선택 지역(시도/시군구/읍면동), 검색어(과목/학원명), 선택 카테고리.
- 목록: 학원 배열(이름, 가격 또는 미확인, 동, 유형, 정보제공 여부).
- 상세: 학원 상세(주소/전화/분야/정원/등록일/수강료 항목/별점/정보확인 여부), 인근 동일 과목 학원 목록.
- 정보확인=true ⇒ 수강료 데이터 존재를 보장(폼 제출로 수집).

## Design Tokens
- **폰트**: Pretendard (Google/CDN). 아이콘: Phosphor Icons (regular + fill).
- **색상**:
  - 배경: `#f2f4fb`(목록/상세), `#eef1fb`(홈 히어로), 카드 `#ffffff`.
  - 텍스트: 진한 `#16213e`, 헤더네이비 `#1a2a52`, 보조 `#48507a`/`#6b74a0`, 뮤트 `#9aa0c4`/`#c2c8e0`.
  - 액센트(파랑): `#3b5bdb` (hover `#2f49b0`). 연보라 타일 `#eef1fb`.
  - 테두리: `#e5e8f4`, `#dfe3f3`, 구분선 `#eef1f7`.
  - 상태: 운영중/수강료 초록 `#1f8a5b`(배경 `#e8f5ee`), 정보확인 노랑 `#f5c518`(텍스트 `#4a3a00`), 지도핀 `#e8556b`.
  - 미제공 라벨 `#b3b9d4`, 미확인 pill 텍스트 `#7c84ab`/배경 `#eef1f7`.
- **radius**: 카드 12~16, 타일 10~15, pill 999.
- **간격**: 카드 패딩 16~22, 그리드 gap 10~20.
- **광고 플레이스홀더**: 45° 줄무늬 `repeating-linear-gradient` + 1px dashed `#d6dbec` + monospace 라벨.

## Assets
- 아이콘: Phosphor Icons(CDN). 과목 아이콘은 **임시 글리프/아이콘**으로, 추후 실제 과목 로고 이미지로 교체 예정.
- 로고: 현재 파란 돋보기 아이콘(placeholder). 실제 로고 이미지로 교체 예정.
- 광고: Google AdSense / 쿠팡 파트너스 / 개인 배너 자리(실제 스크립트·이미지 미포함).
