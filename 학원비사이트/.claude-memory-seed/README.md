# 메모리 씨앗 — 새 세션이 심을 것

이 폴더는 **우리아이학원정보** 프로젝트의 메모리다. 원래 블로그스팟API 세션에 뭉쳐 있던 것을
프로젝트별로 분리하면서, 이 폴더에서 열리는 새 세션이 자기 메모리 폴더로 옮기도록 놓아둔 것.

## Claude가 할 일 (첫 세션에서 1회)

1. 시스템 프롬프트에 적힌 **이 세션의 메모리 폴더 경로**를 확인한다
   (`C:\Users\hardb\.claude\projects\<이 폴더의 인코딩된 이름>\memory\`).
2. 이 폴더의 `*.md` 파일을 **전부 그 memory 폴더로 복사**한다 (`README.md` 제외, `MEMORY.md` 포함).
3. 복사가 끝나면 **이 `.claude-memory-seed` 폴더를 통째로 삭제**한다.
4. 프로젝트 `CLAUDE.md`에서 "메모리 씨앗" 섹션을 지운다.

경로를 추측하지 말 것 — 시스템 프롬프트가 알려주는 실제 경로를 쓸 것.

## 왜 이렇게 하나

메모리 폴더 이름은 작업 디렉토리 경로를 인코딩해서 자동 생성되는데(한글이 대시로 바뀜),
씨앗을 놓는 쪽에서는 그 이름을 정확히 맞힐 수 없다. 새 세션은 자기 경로를 정확히 아니까
심는 건 그쪽이 하는 게 안전하다.

## 공통 작업 원칙은 여기 없음

개발 5단계·목업 먼저·API 물어보기·반응형·로컬 프리뷰 같은 전 프로젝트 공통 원칙은
`C:\Users\hardb\.claude\CLAUDE.md`(글로벌)에 있고 모든 세션에서 자동으로 읽힌다. 복사하지 말 것.
