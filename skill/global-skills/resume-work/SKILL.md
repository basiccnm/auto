# 작업 재개 (Resume)

1. HANDOFF.md를 읽는다. 없으면 STATUS.md, CLAUDE.md 순으로 확인한다.
2. "하다 만 작업과 다음 단계" 항목부터 이어서 작업한다.
3. 확정된 결정사항은 다시 묻거나 뒤집지 않는다.
4. 시작하기 전에 "어디서부터 이어가는지"를 한 줄로 사용자에게 보고한다.
5. HANDOFF.md의 내용과 실제 파일 상태가 다르면, 작업을 진행하지 말고 차이점을 사용자에게 먼저 보고한다.
