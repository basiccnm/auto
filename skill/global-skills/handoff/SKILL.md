# 인수인계 (Handoff)

프로젝트 루트에 HANDOFF.md 파일을 만들어 다음을 구체적으로 기록한다:

1. **지금까지 한 작업** — 완료된 것
2. **확정된 결정사항** — 뒤집으면 안 되는 것
3. **하다 만 작업과 다음 단계** — 어디까지 했고 바로 다음에 뭘 해야 하는지
4. **주의사항** — 건드리면 안 되는 파일, 알려진 문제, 함정

기준: 다음 세션이 이 파일만 읽고 질문 없이 바로 이어서 작업할 수 있는 수준으로 자세하게.

규칙:
- 이미 HANDOFF.md가 있으면 덮어쓰지 말고, 오늘 날짜 섹션을 맨 위에 추가한다.
- 추측이 아니라 이번 세션에서 실제로 확인된 사실만 기록한다.
- 작성 후 파일 경로를 사용자에게 알려준다.
