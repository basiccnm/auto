## ⑥ 함정 (다시 밟지 말 것)

- **`index.js` 접두어 화이트리스트** — `api_*.js` 에 라우트를 열어도 `path.startsWith(...)` 목록에
  없으면 **조용히 HTML 404 로 샌다.** (보상 API 는 `index.js:2598` 에 등록 완료)
- **잔액은 `star_ledger` 하나로만 센다.** `balance` 컬럼을 따로 두면 두 값이 반드시 어긋나고,
  그때부터 어느 쪽이 맞는지 알 수 없다
- **`created_at` 은 UTC 인데 비교는 KST 로 하면 9시간 어긋난다** — 중복 방지가 통째로 안 걸려
  같은 미션을 같은 날 두 번 내면 도장이 두 번 나갔다. `date(created_at,'+9 hours')` 로 DB 안에서 맞춘다
- **`child_id` 는 INTEGER** (`children.id` 가 INTEGER). TEXT 로 넘기면 에러가 아니라
  **«0건 일치»로 조용히 지나간다**
- **APK 빌드** — `JAVA_HOME` 을 Android Studio JBR 로 잡아야 한다(기본 Java 8 로는 실패).
  APK 는 프로젝트 밖 `%LOCALAPPDATA%\eduthink-build\...\apk\debug\` 에 떨어진다
- **`.wrangler/` 를 커밋하면 로컬 D1 이 깨진다** — `.sqlite` 본체와 `-shm`/`-wal` 이 어긋나
  «database disk image is malformed» 가 난다. 지금은 무시 처리됨
