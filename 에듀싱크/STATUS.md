판정은 `"success": true` 로 한다 — wrangler 는 실패해도 종료코드가 0 일 때가 있다.

```bash
python scripts/d1_apply.py scripts/migrate_xxx.sql            # 로컬
python scripts/d1_apply.py scripts/migrate_xxx.sql --remote   # 원격
```

### 왜 바뀌었나 — 「미션 1개 = 보상 1개」가 잘못이었다
하루 3개 × ★1 = 3개. 이러면 ★100 도 한 달이라 **큰 목표를 걸 수가 없다.**
게임은 잡몹마다 소액을 주고 그게 쌓여 10,000짜리 아이템이 된다. **하루 회수량이 커야 큰 목표가 선다.**
→ 미션을 많이 주고, 조금씩 여러 번 주고, **상품 가격을 크게** 잡는다.

### 스타코인 (이름 변경: 별도장 → **스타코인**)

- **6년짜리 게임**(초1~초6). ★10,000 짜리 상품이 성립한다
- 🔴 **하루 리밋이 이 시스템의 심장이다.** 리밋이 화폐 가치를 정하고 → 상품 가격표를 정한다.
