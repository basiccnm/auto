#### 폰 연결 방법 (무선 디버깅 — 다음에 헤매지 말 것)
1. 폰: 개발자 옵션 → 무선 디버깅 **켜기** → 「기기 페어링」 팝업을 **연 채로 둔다**
2. 팝업의 **포트 + 6자리 코드**로 `adb pair 172.30.1.35:PORT CODE`
3. **연결 포트는 다르다.** 포트 훑기로 찾는다 (30000~50000 TCP 스캔 → 열린 것들에 차례로 connect)
4. ⚠ `adb kill-server` 를 하면 연결이 끊기고 **포트가 바뀐다.** 되도록 하지 말 것
5. ⚠ 릴리즈 빌드는 **웹뷰 디버깅이 꺼져 있다**(의도된 보안 설정) — 폰에서는 CDP 를 못 쓴다.
   **스크린샷과 logcat 으로만** 확인한다
6. ⚠ debug 판이 깔려 있으면 서명이 달라 덮어쓰기가 막힌다 → **지우고** 설치

#### 상단도 잘렸다 — 위아래는 한 쌍이다 (2026-08-09, 폴드6)
