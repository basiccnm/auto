## ③ 함정 — 같은 실수 금지

- 🔴 **옛 전역 `button{min-height:44px; padding:13px}`(style.css)가 ns 버튼에 샌다.**
  ns 버튼 규칙마다 `min-height:0` · `padding` 을 직접 쓴다. 요소 선택자는 이름을 못 간다.
- 🔴 **이름이 겹치면 샌다** — `.chip`(32×44 사고) · `.stats`(행 45px 사고) → `ns-` 로 갈았다.
- 🔴 **여백 값을 두 곳에 적지 말 것.** `.gmw`/`.dw-years` 가 `-20px`·`-16px` 를 손으로 박아
  뒀는데 `#screen` 여백이 변수로 바뀌자 3px 이 새어 가로 스크롤이 생겼다 → **같은 식**을 쓴다.
- 🔴 **면 색을 글씨로 쓰지 말 것.** `color: var(--accent)` 는 흰 카드 위에서 4.08~4.48 이다.
  글씨는 `--accent-ink`(=`--t-ink`). 43곳을 이걸로 고쳤다.
- 🔴 **하단 바는 `bottom:0` 이 아니다** — `calc(var(--sa-b) + var(--ns-8))`.
  0이면 내용이 넘칠 때 3버튼 내비바 **밑으로** 들어간다(폴드6 실측).
- 🔴 **아래는 이제 «웹뷰를 잘라서» 막는다 (2026-08-11 저녁, 폴드6 실기 확정).**
  CSS 여백 방식은 앱 안 새로고침 뒤 `--sa-bottom` 이 0 으로 남아 실기에서 뚫렸다
  (입력바·이용약관 버튼이 내비바 위에 겹침 — 대표님 발견).
  MainActivity `applyBottomInset()` 이 **웹뷰 레이아웃 bottomMargin** 으로 내비바만큼 자른다.
  ⚠ 웹뷰 자신의 padding·부모 padding 은 **조용히 무시된다**(둘 다 실측 실패) — 마진만 먹는다.
  내비바 자리 색은 창 배경 #F2F3F6. 웹 쪽 `--sa-bottom` 은 이제 항상 0 이다(이중 방지).
  상단은 자르지 않는다(시계 그림이 상태바 뒤로 흐르는 디자인) — 상세 머리는 `.ns-hd.sub`
  sticky(top:var(--sa-t))로 고정, 내용은 그 밑에서만 흐른다.
- 🔴 **네이티브 인셋 다리는 «안 닿을 수 있다».** 에뮬 3대 중 **2대에서 `--sa-top` 이 빈 값**이었고
  머리가 상태바 밑으로 들어갔다(2026-08-11 «상태창에 다 걸친다»). 두 겹으로 막았다:
  ① CSS `--sa-t` 에 **바닥값 24px**(`max()`) — 위쪽은 상태바 없는 세로 폰이 없으니 안전
  ② MainActivity 되풀이 4회 → **8회**(0·150·400·900·1800·3000·5000·8000ms) + `onConfigurationChanged`
  ⚠ **아래쪽(`--sa-b`)엔 바닥값을 못 깐다** — 제스처 폰은 0 이 정답이라 깔면 바가 붕 뜬다.
  그래서 아래는 **다리가 반드시 닿아야** 하고, 그게 이 되풀이를 늘린 이유다.
- 🔴 **홈은 «한 화면»이다 — 페이지가 구르지 않는다**(2026-08-11).
  `#screen:has(.ns-home)` 을 `height:100dvh; overflow:hidden` 으로 못 박고,
  남는 높이는 **서랍장(.ns-chest)이 먹고 모자라면 자기 안에서 구른다**(`flex:1; min-height:0`).
  ⚠ 예전엔 `min-height:100vh` + 하단 바 `sticky` 라, 내용이 넘치면 바가 **내용 위에 겹쳐**
  마지막 줄을 가렸다(320×640 + 내비바 48px 에서 23px 실측 — 대표님이 눈으로 먼저 찾았다).
  sticky 를 걷어냈다. 목업 `.phone{overflow:hidden}` 과 같은 규칙이다.
- 🔴 **고칠 때마다 상태바·내비바가 깨졌다** → 스윕에 **자동 검사**를 넣었다.
  화면마다 ①글자·버튼이 `--sa-t` 위로 올라갔나 ②고정 요소가 `--sa-b` 를 물었나
  ③끝까지 내렸을 때 마지막 내용이 내비바 위에 남나(`tailGap`) 를 잰다. 셋 다 0 이어야 한다.
  ⚠ 에뮬은 내비바가 없어 그냥 재면 **늘 통과한다(헛통과)** — `window.__navTest=48` 로
  3버튼 폰 조건을 만들어 한 번 더 돌릴 것.
- 🔴 **웹뷰 textZoom 100 고정**(MainActivity) — 시스템 글자확대가 px 화면을 부풀렸다.
- ⚠ **대비를 잴 때는 반투명을 합성하고, 그라디언트 면은 건너뛴다.** 안 그러면
  「흰 글씨 위 흰 면 = 1.0」 같은 헛것이 잡힌다(오늘 헛것 6건을 이걸로 걸러냈다).
- ⚠ **바꿨다고 말하기 전에 값을 잰다.**
