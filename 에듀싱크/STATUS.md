## ② 🔴 다음 사람이 제일 먼저 볼 것

### 최소 크기 기준으로 안 짰다 (구조적 결함)

목업을 **393×852 한 크기**로 만들고, 기기마다 어긋나면 덧대는 식으로 고쳤다.
그래서 폰이 바뀔 때마다 새로 터졌다(밤새 그것 때문에 여러 번 되돌렸다).

**맞는 순서는 이것이다:**
1. 가로는 **제일 좁은 기기(320px)** 기준으로 잡는다
2. 세로는 **제일 짧은 기기(640px)** 기준으로 잡는다
3. 큰 화면에는 **여백을 준다** (요소를 키우지 않는다)

**확인한 크기는 둘뿐이다** — 412×915 · 369×906. **320·640 은 안 봤다.**
손대기 전에 그 두 크기부터 재 볼 것. 깨질 가능성이 크다.

```
adb shell wm size 720x1600 ; adb shell wm density 320   → 360×800
adb shell wm size 720x1440 ; adb shell wm density 360   → 320×640
```
⚠ 에뮬이 크기 변경 중에 죽은 적이 있다. 죽으면 `wm size reset` 후 다시.

### 하단 빈 공간

기본 폰(915 높이)에서 서랍장 아래가 **109px** 빈다. 대표님이 두 번 지적했다.
서랍을 늘려 채웠다가 앞판이 103px 로 부풀어 되돌렸다(80px 이 정답).
**채우려면 내용을 늘려야 한다** — 「오늘 급식」 칸 추가가 후보(개학하면 매일 값이 찬다).

## ③ 함정 — 같은 실수를 반복하지 말 것

- 🔴 **`design.css` 에 덧대지 말 것.** 안 맞으면 **원래 규칙 자리에서 값을 고친다.**
  이 파일은 「덮어쓰기 금지」로 만들었는데 내가 패치 블록을 5개 쌓았고, `:root` 가 둘이 됐다.
  `style.css` 를 덮어쓰기 234개로 만든 것과 똑같은 짓이다.
- 🔴 **클래스 이름에 `ns-` 를 빠짐없이 붙일 것.** 안쪽 이름을 `chip` 으로 뒀더니
  `style.css` 의 `.chip{min-height:44px}` 가 새어 들어와 칩이 32×44 로 늘어났다. → `.ns-c`
- 🔴 **flex 자식은 기본이 stretch 다.** `align-self:center` 를 안 주면 부모 높이만큼 늘어난다.
- 🔴 **가림막(scrim)은 그림이 있을 때만** 켠다. 항상 켜두면 기본 테마의 연한 파랑을
  하얗게 씻어낸다 — 세 번 지적받고 찾았다.
- 🔴 **＋ 는 글자로 그리면 가운데가 안 맞는다**(글자는 자기 여백이 있다). CSS 막대 둘로 그린다.
- 🔴 **하단 바 좌우 글자 폭이 다르면 가운데가 밀린다.** 가운데를 고정폭으로 박는다.
- ⚠ **바꿨다고 말하기 전에 값을 잰다.** 치환이 조용히 빗나가 「고쳤다」고 보고한 적이 두 번 있다.
