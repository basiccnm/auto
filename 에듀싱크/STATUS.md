## ③ 함정 — 같은 실수 금지

- 🔴 **옛 전역 `button{min-height:44px; padding:13px}`(style.css)가 ns 버튼에 샌다.**
  ns 버튼 규칙마다 `min-height:0` · `padding` 을 직접 쓴다. 요소 선택자는 이름을 못 간다.
- 🔴 **이름이 겹치면 샌다** — `.chip`(32×44 사고) · `.stats`(행 45px 사고) → `ns-` 로 갈았다.
- 🔴 **여백 값을 두 곳에 적지 말 것.** `.gmw`/`.dw-years` 가 `-20px`·`-16px` 를 손으로 박아
  뒀는데 `#screen` 여백이 변수로 바뀌자 3px 이 새어 가로 스크롤이 생겼다 → **같은 식**을 쓴다.
- 🔴 **면 색을 글씨로 쓰지 말 것.** `color: var(--accent)` 는 흰 카드 위에서 4.08~4.48 이다.
  글씨는 `--accent-ink`(=`--t-ink`). 43곳을 이걸로 고쳤다.
- 🔴 **하단 바는 `bottom:0` 이 아니다** — `calc(var(--sa-b) + var(--ns-8))`.
  0이면 내용이 넘칠 때 3버튼 내비바 **밑으로** 들어간다(폴드6 실측).
- 🔴 **아래는 이제 «웹뷰를 잘라서» 막는다 (2026-08-11 저녁, 폴드6 실기 확정).**
  CSS 여백 방식은 앱 안 새로고침 뒤 `--sa-bottom` 이 0 으로 남아 실기에서 뚫렸다
