판정은 `"success": true` 로 한다 — wrangler 는 실패해도 종료코드가 0 일 때가 있다.

```bash
python scripts/d1_apply.py scripts/migrate_xxx.sql            # 로컬
python scripts/d1_apply.py scripts/migrate_xxx.sql --remote   # 원격
```
