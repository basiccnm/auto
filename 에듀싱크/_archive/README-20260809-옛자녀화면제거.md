# 2026-08-09 — 옛 자녀 화면 제거

## 무엇을 지웠나
- `childview` — 게임 세계 이전의 **옛 자녀 홈**. 라우터가 이미 `#game` 으로 돌려보내 껍데기였다.
- `childboard` — **별의 길**. 프로필의 「모은 코인 · 연속 출석 · 오늘 획득」과 같은 값을
  그림으로 한 번 더 보여줬을 뿐이다. 대표님 판단: 필요 없는 것은 남기지 않는다.

## 무엇을 남겼나 (지우면 안 된다)
- `childtheme` — 아이 **첫 실행 필수**. 라우터가 여기로 보내고(app.js:7585),
  고른 색이 게임 세계 `--accent` 를 실제로 바꾼다(mint→rose 로 `#0F9E86`→`#D93B72` 실측).

## 되살리려면

거기서 `childview:` / `childboard:` 블록을 꺼내면 된다. git 이력에도 남아 있다.
