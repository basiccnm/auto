## 3. 글자

| 자리 | 크기 | 굵기 |
|---|---|---|
| **시계** | **64px** | 700 |
| 프로필 이름 | 22px | 800 |
| 하단 라벨 | 13px | 800 (이모지 20px 아래) |
| 화면 제목 | 17px | 700 |
| 본문 · 항목 이름 | 16px | 600 |
| 라벨 · 값 · 드로어 항목 | 14px | 700 |
| 부제목 · 보조 | 13px | 500 |

글꼴은 **시스템 글꼴**. Google Sans·NotionInter 는 우리가 못 쓴다. 굵기로만 위계를 만든다.

> ⚠ 한글 시스템 글꼴에 **중간 굵기(500)가 없는 기기**가 있다. 400 으로 떨어지거나
> 억지로 굵어진다. 그래서 위계는 500/600 이 아니라 **600 ↔ 800** 처럼 벌려서 준다.

## 5. 화면 문법

### 감싸는 구조 — 위·아래가 색, 가운데가 흰색

```
홈      파랑 칩(시계+전광판)  →  흰 카드들  →  진한 파랑 하단 바
드로어  진한 파랑 프로필      →  흰 메뉴들  →  파랑 틴트 바닥
```

### 🗄️ 서랍장 — 우리 시그니처

「오늘」 카드는 **서랍장**이다. 앱 이름이 아이서랍이라 화면에서도 서랍이 보여야 한다.

- 몸통: `--chest` 면 + 안쪽 여백 9px
- 앞판: 흰 면 + 선 + `6px` 모서리, 서로 **9px 틈**
- 손잡이: 앞판 위 가운데 `28×4px` 바 (`--handle`)
- 두께: `0 2px 0 rgba(32,33,36,.08)` — 앞판이 살짝 떠 보인다

### 카드 그림자

```
0 1px 2px rgba(0,0,0,.04), 0 2px 8px rgba(0,0,0,.04)
```
아주 옅게 하나만. 「백지 같다」를 막는 최소치다.

### 하단 바 — 배치 고정

```
[1fr | 48px | 1fr]   달력(절반 정중앙) · ＋(화면 정중앙) · 미션(절반 정중앙)
```
＋는 흰 원 + 파랑 글자. 좌우는 **이모지 위 + 한글 아래** 둘 다.

> ⚠ 좌우 글자 폭이 달라 가운데가 밀렸던 적이 있다. **가운데를 고정폭으로** 박아야 한다.

### 드로어

```
프로필(파랑 면)   🌱 ─── 콩  🗄️     ← 서랍은 여기서 바로
                  학교   경기초 · 3-난초
                  이용권  체험 44일
                  자녀폰  연결 안 됨
학교(파랑 칩)     급식 · 시간표 · 학교정보 · 커뮤니티
우리 아이(자주 칩) 서류 · 대화·알림 · 고객센터·문의
바닥(파랑 틴트)   내 정보 · 설정
```

## 6. 색이 뜻하는 것

| 색 | 뜻 |
|---|---|
| **파랑** | 행동(＋·버튼) · 학교 것 |
| **자주** | 우리 아이 것 |
| **무채색** | 나머지 전부 |

색이 있는 곳은 화면당 **다섯 군데 이하**. 그래야 색이 장식이 아니라 정보가 된다.
