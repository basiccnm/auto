학교퀘스트 — 【자녀】 화면 사용법 (자세히)   2026-08-13
이 문서와 다르게 동작하면 그게 버그입니다. 항목 번호로 말씀해 주세요.

자녀폰은 로그인이 아니라 **연결**입니다 — 부모 폰에서 6자리 코드를 받아 넣으면 그 아이 것이 됩니다.
연결한 직후 「내 화면 고르기」(테마)가 한 번 뜨고, 그 다음부터 바로 아이 홈으로 열립니다.

════════════════════════════════════════════════════════════
K1. 아이 홈  — 앱을 켜면 여기
════════════════════════════════════════════════════════════

 ┌ 맨 윗줄 (고정 · 스크롤해도 안 사라짐) ───────────────
 │ 🐧      내 캐릭터. 누르면 내 프로필(레벨·모은 별·기록)
 │ 첫째    이름  /  Lv.1 새싹  ← 레벨과 등급
 │ 🔥 0    며칠 연속 했는지
 │ ★ 12   지금 가진 별 (쓰면 줄어듭니다)
 └──────────────────────────────────────────────────────

 ┌ 오늘의 길 ───────────────────────────────────────────
 │ ▓▓▓▓░░░░ 🚩        오늘의 길   5 / 25
 │ 오늘 받은 별 / 오늘 받을 수 있는 최대. 깃발까지 채우는 게 하루 목표입니다
 │ (최대치는 엄마아빠가 정합니다)
 └──────────────────────────────────────────────────────

 ┌ 오늘의 퀘스트   4 / 9 ───────────────────────────────
 │ 🌅 아침   2/3      누르면 → K2 아침 미션 카드
 │ 🏫 학교   1/3      누르면 → K3 학교 미션 카드 (급식·누구랑·수업)
 │ 📚 방과후 1/3      누르면 → K4 방과후 미션 카드
 └──────────────────────────────────────────────────────

 ┌ 💛 엄마아빠 퀘스트   1 / 2 ──────────────────────────
 │ 엄마아빠가 직접 준 미션만 여기 **목록으로 펼쳐집니다**
 │ 줄을 누르면 → K5 미션 하나(상세). 바로 완료되지 않습니다
 │ 받은 게 없으면 「아직 받은 퀘스트가 없어요」
 └──────────────────────────────────────────────────────

 ┌ 🏪 스타코인 상점 ›  →  K7 ──────────────────────────
 ┌ 맨 아래 초록 버튼 「퀘스트 시작하기」 → K6 오늘의 퀴즈
 · 아이 홈에는 ‹ 가 없습니다 — 여기가 집입니다

════════════════════════════════════════════════════════════
K2 / K4.  아침 미션 · 방과후 미션 카드
════════════════════════════════════════════════════════════
 · 미션이 타일로 깔립니다. 타일마다 : 그림 · 이름 · 걸리는 시간 · ★N
 · ★ 타일을 누르면 = 상세(K5)가 열립니다. 완료는 상세의 큰 버튼에서만 (2026-08-14 통일 —
   목록이든 카드든 «탭=열기, 확정=큰 버튼 하나»)
 · 타일 밑 딱지 :
       눌러서 확인       누르면 상세가 열리는 미션
       확인 기다리는 중  보냈고 엄마아빠가 볼 차례
       했어요            끝난 것
 · 🎁 세트 보너스 — 그 카드의 미션을 **다 하면** 별을 더 줍니다.
   「N개 다 하면」이라고 몇 개 남았는지 보여줍니다
 · ‹ 를 누르면 아이 홈으로

════════════════════════════════════════════════════════════
K3. 학교 미션 카드 (급식 · 누구랑 · 수업)
════════════════════════════════════════════════════════════
 · 🍚 오늘 급식 / 🙌 오늘 누구랑 / 📖 재밌던 수업 — 30초면 끝나는 기록입니다
 · **학교 안 가는 날**(방학·주말)에는 그 칸이 흐려지고 「방학중」으로 잠깁니다.
   눌러도 안 열립니다 — 고장이 아닙니다
 · 지금은 방학이라 급식·수업이 잠겨 있습니다 (개학 8/20부터 다시 열림)

════════════════════════════════════════════════════════════
K5. 미션 하나 (상세) — 줄이나 타일을 눌렀을 때
════════════════════════════════════════════════════════════
 · 큰 그림 + 미션 이름 + 칩(영역 / N분 / ★N / 📷사진)
 · 「왜 이 미션인가요」 — 왜 좋은지 (있을 때만)
 · 맨 아래 큰 버튼이 **여기서만** 완료를 확정합니다

     아직 안 한 것
        「다 했어요!」       → 그 자리에서 완료 + 별 + 축하 화면
        「📷 사진 찍기」     → 카메라 화면 (사진 미션)
     보낸 것
        「엄마아빠가 볼 거예요」 (누르면 목록으로 돌아감)
     끝난 것
        「다 했어요!」 (이미 끝 — 목록으로 돌아감)

 ⚠ 목록에서 줄을 한 번 눌렀다고 완료되지 않습니다.
   실수로 스쳐서 별이 나가는 걸 막으려고 **상세의 큰 버튼**을 거치게 했습니다
 ⚠ 통신이 느린 순간에는 축하가 먼저 뜨고 1~2초 뒤 서버에서 확정됩니다.
   이미 처리된 미션이면 서버 상태에 자동으로 맞춥니다

════════════════════════════════════════════════════════════
K6. 오늘의 퀴즈 (⚔️ 보스전)
════════════════════════════════════════════════════════════
 · 「시작하기」 → 문제 → 보기를 누르면 **바로 채점**되어 맞았는지 보여줍니다
 · 오른쪽 위 ✕ = 중간에 나가기. 푼 문제는 날아가지 않습니다
 · 다시 들어오면 「이어서 하기 ▶ (4번부터)」로 이어집니다
 · 배경색 : 시작 전 = 내가 고른 테마 색 / 푸는 중 = 보스전 주황 (모든 테마 공통, 일부러 그런 것)
 · 다 맞히면 보너스 별이 붙습니다

════════════════════════════════════════════════════════════
K7. 스타코인 상점 (아이)
════════════════════════════════════════════════════════════
 · 엄마아빠가 올려 둔 보상만 보입니다
 · 「바꾸기」 → 별이 깎이고 🎟 티켓이 나옵니다. 티켓을 엄마아빠에게 보여주면 됩니다
 · 별이 모자라거나 이번 주 횟수를 다 썼으면 **왜 안 되는지 글로 뜹니다**
 · 진열대가 비었으면 「아직 준비된 보상이 없어요 — 엄마아빠에게 부탁해봐!」
 · 아이 화면에는 「진열대에 올리기」 같은 부모 버튼이 안 보입니다 (정상)
 · 🎟 내 티켓 — 바꾼 것들이 여기 모입니다

════════════════════════════════════════════════════════════
K8. 내 프로필 · 테마
════════════════════════════════════════════════════════════
 · 왼쪽 위 캐릭터를 누르면 프로필 — 레벨 · 모은 별 · 지금까지 한 것
 · 테마(내 화면 고르기)는 아이가 스스로 바꿀 수 있습니다

════════════════════════════════════════════════════════════
아이가 헷갈리기 쉬운 곳 (개선 검토 중 — 대표님 지적)
════════════════════════════════════════════════════════════
 · 홈에 «오늘 뭐부터 하지»가 한눈에 안 옵니다 —
   리본 · 타일 3개 · 엄마아빠 퀘스트 · 상점이 동시에 말을 겁니다
 · 「퀘스트 시작하기」가 퀴즈로만 갑니다 — 미션이 아니라 퀴즈라는 게 글자로 안 드러납니다
 · 미션을 끝내려면 목록 → 상세 → 큰 버튼, 두 번 눌러야 합니다(오탭 방지 때문)
 → 이 세 가지는 화면 구조 문제라 목업을 먼저 만들어 승인받은 뒤에 손대겠습니다
