## 0. 이번 판의 대원칙 — 「시스템은 전부, 콘텐츠는 팩」

대표 구술 그대로:

> *"변화가 없으면 도태돼. 그런데 우리는 업데이트를 통해서 추가하는 거고,
> 이번달 미션 이런 식으로 넣고 빼고 블록화해서 이벤트성 미션을 넣어주고 빼주면 될 것 같아.
> 월드컵 기간이면 월드컵 같은 내용을 상식으로 넣어주고. 이게 만들면 되는 게 아니라
> **운영적인 부분도 같이 들어가줘야** 되거든."*

그래서 이번에 만드는 것과 미루는 것의 기준은 「기능이 크냐 작냐」가 아니다.

| | 이번에 | 이유 |
|---|---|---|
| **시스템·틀·스키마** | **전부 넣는다** | 나중에 넣으면 화면·DB 를 다 뜯어야 한다 |
| **콘텐츠(문제·미션·팩)** | 기본 하나만 | 팩으로 빼두면 나중엔 **데이터만** 넣으면 된다 |
| **운영 장치(기간·on/off)** | **넣는다** | 없으면 월드컵 개막에 못 맞춘다(스토어 심사 며칠) |

**판단 기준 한 줄** — *나중에 추가할 때 「코드를 고쳐야 하나 데이터만 넣으면 되나」.*
코드를 고쳐야 하는 것이면 지금 만든다. 데이터면 미룬다.

## 1. 아이 화면 — 확정된 모양

### 1.1 게임 전용 팔레트 (부모 테마와 분리)

부모 앱은 테마 18종이 `--surf`/`--card-a` 를 갈아끼운다. **아이 화면은 그걸 안 쓴다.**
아이 화면은 배경 그라데이션 한 쌍(`--sky1`/`--sky2`)만 테마로 바뀌고, 카드는 항상 흰색이다.

> 카드가 흰색 고정이라 **바탕만 갈아도 화면 전체가 바뀐다.** 테마를 10종으로 늘리든
> 나라별로 바꾸든 두 줄만 고치면 된다. 부모 테마의 색 토큰은 **절대 건드리지 않는다**
> (8/4 사고 재발 방지 — STATUS ⓪-C).

배경 5종: 하늘(기본) · 라임 · 라벤더 · 선셋 · 민트. 아이가 프로필에서 고른다.

### 1.2 홈 = 2×2 타일 4칸 + 상점 긴 바 (시안 v4 「B안」 승인)

```
┌─────────────────────────────┐
│ 🦊  Lv.7 일꾼 민준    ★1,240 │  ← 캐릭터 시트(아바타 슬롯 = 업데이트 자리)
│ ▓▓▓▓▓▓░░░░ 오늘 18/60       │  ← 코인 상한 게이지
├──────────────┬──────────────┤
│ 🌅 아침 미션 │ 🏫 학교 미션 │  ← 항상 있는 기본 3칸
│    3/3 ✓     │    1/3       │
├──────────────┼──────────────┤
│ 📚 방과후    │ ⚔️ 오늘의    │  ← 4번째 칸만 변동
│    0/2       │    미션      │
├──────────────┴──────────────┤
│ 🏪 스타코인 상점    ★1,240  │  ← 맨 아래 길게 하나
└─────────────────────────────┘
```

- **아침·학교·방과후는 기본 틀**이라 매일 같은 자리에 있다. 아이가 헷갈릴 게 없다
- **홈은 언제나 4칸 고정.** 넷플릭스식 가로 넘기기는 홈이 아니라 **카드 안**에서 미션이 많아졌을 때 쓴다
- **카드 안도 같은 타일 문법** — 화면마다 다른 규칙을 배울 필요가 없다
- 끝낸 칸은 아이콘에 초록 체크, 남은 칸은 테두리가 들려 «여기 눌러»가 보인다

### 1.3 클리어 연출 (대표 지시 08-08)

> *"아침미션 완료면 화면 빛 꺼지게 하고 클리어 이렇게 뜨게끔 해. 진짜 게임처럼."*

**세트를 완주한 순간에만** 화면이 잠깐 어두워지고 `CLEAR` 가 뜬다.
- 개별 미션 완료는 조용히(체크만). 매번 연출하면 3초 만에 성가신 것이 된다
- 어두워졌다가 밝아지는 데 1.2초. 아무 데나 누르면 즉시 건너뛴다
- `prefers-reduced-motion` 이면 어두워지지 않고 배지만 뜬다
- 세트 보너스 코인이 이때 날아와 지갑에 꽂힌다 — **보상이 눈에 보여야 한다**

### 1.4 프로필

이름 · 레벨 · 모은 코인 / 연속 출석 / 퀴즈 정답률 · 배경색 5개 · 뱃지.
**캐릭터 자리는 지금 비워둔다** — 이모지 + 「곧 캐릭터」 배지. 나중에 그 칸만 갈아끼우면
화면을 다시 안 짠다.

## 2. 경제 — 코인과 리그 점수를 **분리**한다

v1 의 「하루 30 리밋」은 폐기. 리밋으로 막으면 **성실하게 다 한 아이가 손해**를 본다
(「했는데 안 준다」). 막는 지점을 바꾼다.

| | 스타코인 ★ | 리그 점수 |
|---|---|---|
| 쓰는 곳 | 상점 · 미션 재도전 | **아무 데도 못 씀** (순위만) |
| 하루 상한 | **60 🔴** (+히든 5) | **없음** |
| 리셋 | 안 됨 — 계속 쌓인다 | **매월 1일** |
| 부모가 늘릴 수 있나 | 상한까지만 | 못 늘림(부모 미션은 고정 점수) |

**이 분리가 핵심이다.** 코인 상한에 도달한 뒤에도 코인을 태워 재도전하면 **리그 점수만** 오른다.

- **모으는 아이** — 상한까지만 하고 코인을 아껴 상점에서 쓴다
- **경쟁하는 아이** — 상한을 넘긴 뒤 코인을 태워 순위를 산다

둘이 진짜 배타적이 되고, 코인 가치도 안 무너진다. 그리고 **코인을 태워서 사는 게
「문제 푸는 기회」라 경쟁하는 아이일수록 공부를 더 하게 된다.**

### 2.1 히든 코인 (하루 +5)

출석 · 연속 기록 · 깜짝 이벤트처럼 **우리가 주는 것**은 별도 주머니.
부모가 미션을 아무리 늘려도 60 을 못 넘고, 히든은 부모가 못 건드린다.
「오늘 뭔가 더 있을지도」가 남는다.

### 2.2 재도전 (코인 소비처)

**오늘의 미션(퀴즈)만 재도전된다.** 급식·친구·수업은 하루에 한 번뿐인 사실이고,
아침도 두 번 오지 않는다. **반복이 자연스러운 건 문제 푸는 것뿐이다.**

| 회차 | 값 |
|---|---|
| 1회 | 무료 🎲 |
| 2회 | ★3 |
| 3회 | ★6 |
| 4회 | ★12 |
| 5회 | ★24 |
| 6회 | ★48 · **하루 5회까지 🔴** |

값이 배로 뛰어서 마지막은 하루치를 통째로 태우는 셈이 된다.

**2회차부터는 틀렸던 문제를 먼저 낸다.** 재출제가 「우려먹기」가 아니라 오답노트가 되고,
부모한테도 「틀린 걸 다시 맞혔어요」로 보여줄 게 생긴다. 문제 재고 압박도 줄어든다.

### 2.3 부모 미션은 고정 점수 · 리셋 불가

부모가 점수를 정하면 리그가 「우리 엄마가 후하다」로 갈려 경쟁이 성립하지 않는다.

- **부모 미션** — 하루 3개(기존 제한 유지) · **고정 점수** · **리셋 안 됨**
- **우리 카탈로그 미션 · 퀴즈** — 차등 점수(우리가 밸런싱)

**부모 미션이 리셋되면 부모가 아이와 한 약속을 아이가 코인으로 지워버리는 셈이라** 말이 안 된다.

점수는 코인보다 **차등을 훨씬 크게** 벌린다. 코인은 상한이 있어 ★1~3 으로 좁게 잡히지만
점수는 상한이 없으니 「이불 개기 5점 / 문제집 5장 40점」처럼 벌린다.
그래야 재도전으로 쉬운 것만 골라 담는 게 이득이 안 된다.

### 2.4 레벨 = 자기 만족

- **해낸 미션 수**로 오른다. 누적 코인이 아니다
- 코인 기준이면 퀴즈 잘 푸는 애만 빨리 오르지만, **미션 수 기준이면 꾸준히 한 애는 무조건 오른다**
- 경쟁은 리그에서 하니 레벨까지 실력을 반영할 필요가 없다
- **리셋 없음.** 34일 한 아이의 기록을 리셋으로 뺏으면 그날 앱을 지운다

## 3. 리그 — 월별 리셋 (⚠ 출시 때는 끈다, §6 로드맵)

### 3.1 왜 소그룹인가

하루 상한이 있어서 **한 달 최대치가 정해져 있다**(60×30 = 1,800).
전체 랭킹을 매기면 상위권이 전부 동점이 되고 결국 「누가 먼저 가입했나」로 갈린다.

**듀오링고식 소그룹 리그** — 30명씩 묶어 그 안에서 순위. 월말에 상위는 승급, 하위는 강등.
전체 1등은 못 돼도 **내 그룹 3등은 될 수 있어서** 모든 아이에게 다음 달 이유가 생긴다.

티어: 브론즈 → 실버 → 골드 → 플래티넘 → 다이아 → 마스터

### 3.2 리셋되는 건 순위지 명예가 아니다

**「7월 골드리그 1등」 뱃지는 영구 보관**이라 프로필에 계속 쌓인다.

### 3.3 묶는 기준 🔴

- **학년군(1~2 / 3~4 / 5~6)** 제안 — 1학년이 6학년과 안 붙는다
- 같은 학교로 묶는 건 우리가 학교정보를 갖고 있어 가능은 하지만,
  **아이들끼리 실명으로 서열이 생기는 거라 권하지 않는다**

## 4. 상점 — 부모가 채운다

**어른이 깔아서 아이에게 넘기는 앱**이다. 아이가 처음 켠 화면이 비어 있으면 안 된다.

> 부모 최초 설정에서 **진열대 채우기를 건너뛸 수 없는 단계로** 넣는다.
> 아이 코드를 만들기 전에 보상 3개를 올리게 한다. 부모 입장에서도 「내가 차린 것」이 되어
> 손을 놓기 어려워진다.

- 못 사는 것은 「760개 더!」로 남겨 **목표**가 된다 (별도 목표 게이지 안 만듦 — 상점 안에서 해결)
- 티켓: 「기다리는 중」 → 부모 「바꿔줬어요」 → 「받았어요」
- **아이 화면에 원화 절대 금지.** ★ 만
- **현금 코인 없음.** 코인을 파는 순간 「애한테 돈 쓰게 하는 앱」이 되고
  구글·애플 심사도 아동 IAP 를 훨씬 빡빡하게 본다. 구독료만 받는다
- 제휴·레퍼럴 상점은 **자금이 붙어야 하는 일** — 자리만 비워둔다(§6 단계4)

## 5. 문제 — 「쓰는」 게 아니라 「뽑아내는」 구조

### 5.1 표 + 템플릿

문제를 손으로 쓰지 않는다. **데이터 표를 넣고 템플릿으로 뽑는다.**
핵심 이점은 **오답 보기가 공짜로 나온다**는 것 — 같은 표의 다른 행을 뽑으면 된다.
문제 만들기에서 제일 귀찮은 부분이 사라진다.

| 표 | 뽑히는 유형 | 대략 |
|---|---|---|
| 나라 200개국 | 국기→이름 / 이름→수도 / 수도→나라 / 국기→대륙 | 800 |
| 속담 500 | 뒷구절 / 뜻 | 1,000 |
| 수학 | **규칙만으로 무한** — 학년별 자동 | ∞ |
| 영어단어 800(초등 필수) | 영→뜻 / 뜻→영 / 소리→단어 / 철자 | 3,200 |
| 공룡·동물·우주·곤충·바다생물·문화재 | 먹이 / 사는 곳 / 크기 / 분류 | 각 수백 |
| 국어(맞춤법·반대말·높임말) | 쌍 표 | 수백 |
| 한국 지리 | 시도→도청소재지 / 특산물 | 수백 |

연예만 자동화가 안 되고 유행도 타서 **시즌 팩으로 수동 유지**한다.

**그리고 이게 그대로 글로벌 전략이다.** 나라 표는 이름만 번역하면 그대로 쓰이고,
수학은 번역조차 필요 없다. 언어팩 갈아끼우기가 「문제 2,000개 다시 쓰기」가 아니라
「표 몇 개 번역」이 된다.

### 5.2 문제 유형

| 유형 | 시간 | 비고 |
|---|---|---|
| 4지선다 | 5초 | 기본. **지금 있는 480문제가 이것** |
| 그림 + 글자 보기 4개 | 5초 | 보기까지 그림이면 360px 에서 너무 작다 |
| OX | **3초** | 찍으면 50% — 점수를 깎는 대신 **시간을 줄인다** |

> 점수를 깎으면 아이가 「이건 싸구려 문제네」로 느끼지만, 시간을 줄이면 **긴장감**이 된다.

**회차마다 유형을 섞는다.** 매일 똑같이 4지선다 10개면 금방 지겨워진다.

### 5.3 그림 문제 규칙

- **그림을 다 받은 뒤에 타이머를 켠다.** 안 그러면 로딩 때문에 「나는 안 늦었는데 틀렸다」가 된다
- 10문제 그림을 통째로 먼저 받고 시작
- 그림은 **일러스트로 통일해 새로 만든다** — 복원도는 출처마다 저작권 조건이 제각각이라
  스토어에 올릴 때 걸린다. 국기만 오픈소스 이미지를 쓴다

### 5.4 자동 생성의 함정

- **난이도** — 저학년에 「부르키나파소 수도」가 나오면 안 된다.
  표에 **인지도 등급** 칸을 두고 저학년은 1등급만 쓴다. 등급은 사람이 한 번만 매긴다
- **억울한 문제** — 수도가 둘인 나라, 국기가 거의 같은 차드·루마니아.
  **「같이 내지 말 것」 목록**을 따로 둔다

### 5.5 학년별 미션 (국내판의 무기)

상식 퀴즈는 재미고, **학년별 교과 문제가 부모가 돈을 내는 이유**다.
「우리 애가 3학년 2학기 나눗셈을 매일 10문제씩 풀고 있다」가 되면 게임이 아니라 학습지다.

미션 카드 안에서 둘로 나눈다.

- **오늘의 미션** — 나라·공룡·속담 같은 상식. 학년 무관
- **학년별 미션** — 지금 배우는 것. **아이 학년을 이미 아니까 학기까지 계산해 단원을 낸다**

시작은 **수학부터.** 학년별 자동 생성이 완벽하게 되는 유일한 과목이라
1학년 덧셈부터 6학년 비례식까지 표 없이 규칙만으로 무한히 찍어낸다.
국어·사회·과학은 교과서 내용이라 사람이 써야 해서 그다음.

**용어 통일** — 「도전」이 아니라 **「미션」**. 부모가 준 것이든 우리가 낸 것이든 아이에겐 다 미션이다.

## 6. 팩 — 운영이 곧 상품

### 6.1 구조

문제와 미션이 각각 **팩**에 속하고, 팩에 **시작일·종료일·on/off** 가 있다.
「이번 달 미션」이 그냥 **팩 하나를 켜는 일**이 된다.

**⚠ 서버(D1)에서 켜고 꺼져야 한다.** 앱 업데이트로 넣으면 스토어 심사에 며칠 걸려
월드컵 개막에 못 맞춘다. D1 에서 팩을 켜면 그날 아침 아이 화면에 뜨는 구조여야 운영이 된다.

### 6.2 아이 쪽 장치

**기간이 지나면 못 얻는 한정 뱃지**가 생기니 매달 돌아올 이유가 만들어진다.
리그 뱃지를 영구 보관하는 것과 같은 원리.

### 6.3 운영 부담은 해마다 준다

| 종류 | 예 | 재사용 |
|---|---|---|
| **매년 도는 것** | 명절 · 계절 · 방학 · 크리스마스 · 새 학기 | 연도만 바꿔 다시 켠다 |
| **그때뿐인 것** | 월드컵 · 올림픽 | 이것만 새로 만든다 |

몇 년 지나면 반복형이 쌓여서 새로 만들 게 거의 없어진다.

## 7. 로드맵 — 시간 + **가입자 수**

> 대표 지시: *"로드맵은 시간도 있겠지만 **가입자수도 반영**해서 업데이트 이벤트를 넣어야 한다."*
> *"경쟁시스템도 바로 넣지 말고 일단 사람들이 가입을 하면서 사람이 많아지면 넣어야지."*

**리그는 사람이 없으면 죽는다.** 30명 그룹에 3명이 들어 있으면 1등해도 안 기쁘다.
학년군 3개 × 티어 6개 = **18개 방**이고 방마다 30명이면 **540명**이 최소선이다.
그래서 리그 게이트를 **500명**에 둔다 — 이건 감이 아니라 계산이다.

| 단계 | 게이트 | 넣는 것 | 왜 여기서 |
|---|---|---|---|
| **0. 뼈대** | — (지금~2주) | 팩 틀 · 점수/유형/그림 칸 · 캐릭터 슬롯 · 코인 상한 · 재도전 · 홈 4칸 · 클리어 연출 · 프로필/배경색 | **코드를 고쳐야 하는 것 전부.** 나중엔 데이터만 넣는다 |
| **1. 출시** | 0~500명 | 기본 팩 하나(미션 155 · 퀴즈 480) · 상점 · 티켓 · 레벨 | **리그는 끈다.** 대신 「지난달의 나」 비교로 채운다 |
| **2. 경쟁** | **500명** | 리그 on · 티어 · 월 리셋 · 한정 뱃지 · 시즌 팩 운영 시작 | 18개 방 × 30명 = 540. 방이 차야 순위가 의미를 갖는다 |
| **3. 콘텐츠 폭발** | **2,000명** | 표 기반 생성기(나라·공룡·동물·속담) · 그림 문제 · OX · 학년별 미션(수학) | 문제 소진 속도가 여기서 빨라진다. 그 전엔 480+재도전으로 버틴다 |
| **4. 수익 확장** | **10,000명** | 영어단어 · 레퍼럴 상점 · 캐릭터/꾸미기 아이템 | 레퍼럴은 트래픽이 있어야 협상이 된다. 캐릭터는 제작비가 든다 |
| **5. 글로벌** | 국내 안정 후 | 언어팩 · 로컬 표 교체 · 학교정보 모듈 분리 | 관문은 법(COPPA·GDPR-K·Families) |

**시간이 아니라 사람 수가 문을 연다.** 500명이 3개월에 오면 3개월 뒤에 리그를 켜고,
1개월에 오면 1개월 뒤에 켠다. 반대로 500명이 안 되면 리그를 켜지 않는다 —
빈 리그는 없느니만 못하다.

### 7.1 가입자 수에 걸린 이벤트

숫자 자체를 이벤트로 쓴다. 운영 비용이 거의 0 인데 화제가 된다.

- **500번째 가입** — 리그 개막 + 창단 멤버 뱃지(영구, 다시 못 얻음)
- **1,000 / 5,000 / 10,000 돌파** — 전체 아이에게 히든 코인 지급 + 돌파 기념 배경색
- 이건 **팩 시스템으로 그대로 된다** — 기간 대신 조건이 인원일 뿐

## 8. 지금 뚫어둘 자리 (단계 0 상세)

「값은 비어 있어도 칸은 있어야」 나중에 화면·DB 를 안 뜯는다.

| 어디 | 뚫는 칸 | 지금 값 |
|---|---|---|
| `quiz_questions` | `kind`(4지선다/OX/그림) · `image_url` · `pack_id` · `points` | `mcq` / null / `base` / 유형별 |
| 미션 | `category`(아침·학교·방과후·오늘) · `points` · `pack_id` · `is_parent` | 기본 3 + 오늘 |

**리그 점수는 단계 1 부터 이미 쌓는다.** 단계 2 에서 리그를 켤 때 「가입 순서로 유리」가
생기지 않게 하려면 **처음부터 세고 있어야** 하고, 어차피 첫 시즌은 그 달 1일에 리셋된다.

## 9. 모듈 분리 — 미션 시스템을 먼저 세우고 아이서랍을 붙인다

> 대표 지시(08-08): *"일단 이 시스템을 구축을 먼저 하고, 이걸 구축한 걸 아이서랍이랑 연결시키자.
> 그리고 만든 거는 해외판으로도 할 수 있게 하면 될 듯."*

**순서가 뒤집힌다.** 지금까지는 「학교정보 앱에 미션을 붙인다」였는데,
이제는 **「미션 시스템이 본체이고 학교정보가 붙는 모듈」** 이다.

### 9.1 시장 사실관계 (정직하게)

아이용 미션 앱은 **해외에 이미 있다** — OurHome · S'moresUp · Greenlight 등.
대부분 「집안일 체크리스트 + 용돈」이다. 비어 있는 자리는 다른 데 있다.

| | 기존 앱들 | 우리 |
|---|---|---|
| 부모가 미션을 안 넣으면 | **그날로 멈춘다** | 퀴즈·학년별 문제가 매일 자동으로 나온다 |
| 아이끼리 겨루기 | 없다(집 안에서만 돈다) | **리그** |
| 학교와 연결 | 없다 | 국내 한정 — 우리만 가능 |

### 9.2 자르는 선은 **한 곳**

물리적으로 워커·DB 를 나누지 않는다(인증·결제가 이중화되어 지금 단계에선 과하다).
대신 **코드에서 참조 방향을 한 방향으로 강제**한다.

```
[ 미션 시스템 ]  ← 학교정보를 직접 안 읽는다
      ↑
      │ 인터페이스 하나 (「학교 미션 제공자」)
      │
[ 아이서랍 · 학교정보 ]  ← 급식·친구·시간표
```

- 미션 시스템이 `schools`·`meal_ratings`·`kid_friends`·`subject_log` 를 **직접 조회하지 않는다**
- 학교 미션은 「제공자」가 미션 목록을 만들어 넘겨준다. 미션 시스템은 그게 어디서 왔는지 모른다
- **해외판 = 그 제공자를 안 끼우면 된다.** 홈 4칸이 3칸이 되고 나머지는 그대로 돈다

### 9.3 해외판을 하려면 STAGE 0 에서 반드시 해야 하는 것

나중에 하면 전부 뜯어야 하는 두 가지다.

1. **화면 문구를 하드코딩하지 않는다** — 전부 언어팩 키로. 지금 안 하면 화면 수십 개를 다시 연다
2. **학교정보 참조를 제공자 하나로 모은다** — 지금 흩어놓으면 나중에 못 뽑아낸다

숫자·날짜·학년 표기도 지역에 따라 다르므로 포맷 함수를 한 곳에 둔다.

## 10. 보류함 — 지금 안 한다

### BJ 미션 (2026-08-08 대표 착상, 번외)

방송 플랫폼(SOOP·치지직·유튜브) API 로 **BJ 미션을 만들어 공급**하는 안.
미션을 정의하고 → 수행하고 → 검증하고 → 보상하는 **구조가 우리와 같다.**

- ✅ 재사용되는 것: 미션 카탈로그 · 팩 시스템 · 검증 로직 · 리그
- ⚠ 다른 것: 그 판은 **시청자가 돈을 걸고 미션을 건다** — 결제·정산이 핵심인데 우리에겐 없다
- ⚠ 트윕·투네이션 같은 위젯 업체가 이미 자리를 잡고 있어, 진입장벽이 기술이 아니라 **BJ 영업**이다

**결론: 지금은 아무것도 하지 않는다.** 다만 미션 엔진을
「**누가 걸고 · 누가 수행하고 · 누가 검증하나**」를 파라미터로 두면 나중에 그대로 재사용된다.
이건 어차피 부모 미션 / 우리 미션을 나누느라 하려던 일이라 **추가 비용이 0 이다.**
