# 7. 함정 (실제로 당한 것들 — 계속 누적)

## 색·테마
- **RGB에 검정을 섞어 어둡게 하면 HSL 채도가 같이 떨어져 «탁해진다».**
  H 유지 · S 올림 · L 만 낮추는 HSL 파생으로 고정할 것(`build_themes.py` 의 `at_lum`/`deepen` 참고).
- `color-mix(in srgb, A x%, B y%)` 는 **x+y ≠ 100% 면 결과에 알파가 곱해진다**(카드가 반투명해짐).
- `color-mix` 의 %는 **앞 색의 몫**이다 — 뒤집어 쓰면 의도한 색이 안 나온다.
- 감사 스크립트가 `color-mix` 결과(`color(srgb …)`)를 못 읽으면 **그 배경을 통째로 건너뛰고 엉뚱한 값**을 잰다.

## 레이아웃
- `grid-template-columns: 1fr 1fr` 는 min-content 바닥이 있다 — 긴 제목이 칸을 밀어낸다.
  `minmax(0, 1fr)` + 자식 `flex:1; min-width:0`.
- 면 대비 측정을 **좌표로 박아두면** 레이아웃이 바뀔 때마다 엉뚱한 요소를 «카드»로 잰다 —
  DOM 에서 실제 `getBoundingClientRect()` 를 받아오게 짤 것.
- 함수 경계를 문자열 앵커로 잘라 옮길 때 **정확한 텍스트를 재확인 안 하면 `SyntaxError`** —
  `node --check app.js` 로 항상 확인.

## 데이터·서버
- **자녀 데이터가 오기 전에 부른 로더가 빈 배열을 박아버린다.** 토큰·자녀가 없으면 **`null`로 두고
  다음 그리기에 다시** 부를 것.
- **문자열 id를 D1에 넘기면 조용히 0건 삭제.** `bind()`는 타입을 그대로 보내고, 안 맞으면
  에러가 아니라 «0건 일치»라 `ok:true`가 난다. 진입점에서 `Number()`.
- **`env` 미전달** — `deleteChildCascade`는 `env.RECORDS` 없으면 R2 삭제를 조용히 건너뛴다.
- **자녀에 딸린 테이블을 빠뜨리기 쉽다.** 판별 기준은 «개인정보처럼 보이는가»가 아니라
  **`child_id`를 들고 있는가**. `orders`만 의도적으로 남긴다.
- **예외가 나면 JSON이 아니라 HTML 500이 나간다.** 앱은 그걸 파싱하다 죽는다.
- **검수 날짜가 방학·휴업이면 식단표·학사일정이 비어 보인다** — 앱 버그로 착각하기 쉽다.
  검수 시계를 학기 중으로 고정하고 볼 것(§5 참고).

## 도구·환경
- **한글이 셸 파이프를 지나면 깨진다.** `grep`으로 한글을 세면 0이 나온다 — node로 문자열 비교.
- **bash heredoc에 JS를 넣으면 따옴표에서 터진다.** Write 도구로 파일에 쓸 것.
- `wrangler`의 긴 `--command`는 조용히 아무것도 안 한다. 한 문장씩 + `"success":true`로 판정.
- **삭제 검증은 `--local`로.** `--remote`는 진짜 D1·R2를 지운다.
- `.dev.vars` 변경은 서버 재시작이 필요하다.
- **zip에 한글 파일명이 있으면 `Expand-Archive`가 «Illegal characters in path»로 죽는다.**
  `[System.IO.Compression.ZipFile]::ExtractToDirectory(zip, dst, [Text.Encoding]::UTF8)` 로 풀 것.
- **`ttPick`처럼 이름을 재사용하면 뒤 정의가 이겨 앞 동작이 조용히 사라진다** — 새 함수는 새 이름으로.

## CSS 특정도·전역 규칙 (8/4 추가)
- **전역 `button, .btn { min-height: 44px }`(터치 규칙)가 작은 원형 버튼을 타원으로 찌그러뜨린다.**
  폭만 줄이고 높이를 안 막으면 flex 가 줄 높이만큼 강제로 늘린다 — `min-height: 0` 로 그 버튼만 예외 처리.
  (실측: `.hd-bell`/`.hd-box` 가 38×44 타원이었다)
- **뒤에 오는 CSS 규칙이 특정도가 같으면 무조건 이긴다.** 미디어 쿼리·이음매 규칙을 앞에 뒀다가
  뒤에 온 다른 규칙에 그냥 덮인 사고가 두 번 있었다 — **덮으려는 규칙보다 뒤에 쓰고**, 부모 셀렉터를
  붙여 특정도를 한 단 올려 두면(`.ob-wrap .foo` 처럼) 나중에 누가 순서를 바꿔도 안 뒤집힌다.
- **`::after`/`::before` 로 만든 그라데이션 이음매가 절대배치라도 문서 높이를 먹을 수 있다**
  (실측 152px 스크롤 발생). 배경 레이어(`background-image` 다단 그라데이션)로 바꾸면 안 먹는다.

## 서버 날짜 (8/7 추가)
- **`created_at` 은 DB 에 UTC 로 저장된다.** 이걸 KST 날짜 문자열과 그냥 비교하면 9시간이 어긋나
  **하루 중복 방지가 통째로 안 걸린다**(실측: 같은 미션을 하루 두 번 내도 막지 못하고 도장이 두 번 나갔다).
  SQL 안에서 `date(created_at, '+9 hours')` 로 맞춰 비교할 것 — `api_mission.js` 의 `ymdKst()` 헬퍼가
  이미 있는데도 이번 신규 파일(`api_reward.js`)에서 SQL 비교 지점만 놓쳐서 재발했다. **새 쿼리를 쓸 때마다
  UTC 저장·KST 비교 여부를 매번 의심할 것.**

## git·wrangler 캐시 (8/7 추가)
- **`.wrangler/` 캐시를 git 에 올리면 로컬 D1 이 깨진다.** 미니플레어의 D1 실체는 `.sqlite` 본체 +
  `-shm`/`-wal` 세 파일이 한 세트인데, 이 중 일부만 커밋되면 나중에 되살릴 때 시점이 어긋나
  `database disk image is malformed` 로 죽는다. `.wrangler/` 는 통째로 무시할 것.
- **워커 소스(`workers/*/src/`, `wrangler.toml`)가 git 추적 대상인지 프로젝트 초기에 꼭 확인할 것.**
  이 프로젝트는 처음부터 한 번도 커밋된 적이 없었고, 그 상태로 몇 주를 지내다 통째로 사라진 뒤에야 드러났다.
