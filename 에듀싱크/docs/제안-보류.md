작업 중 떠오른 개선·신규 기능을 한 줄씩 적는다. **여기 적힌 것은 지시 없이는 구현하지 않는다.**

## 🔴 확정된 보류 — 나중에 할 것

### 자녀 앱 UI 구조 개편 (2026-08-02 확정 보류)
**지적:** 자녀 화면이 부모 것과 **색만 다르다.** 실제로 부모 부품을 그대로 쓰고 있다 —
`.mp-sec` 섹션 제목, 부모와 같은 카드 리듬, 「제목 → 목록 → 목록」이라는 대시보드 뼈대,
대화바는 마크업까지 공유. 급식 평가 화면 정도만 다르다.

**방향(제안):** 「오늘 카드 덱」 — 미션 하나가 화면 절반 이상을 차지하고, 끝내면 넘어가고
다음 것이 온다. 다 하면 「오늘 끝!」 한 장. **목록을 훑는다(부모) vs 한 장씩 해치운다(아이)** 로
뼈대를 가른다. 준비물·엄마 말은 덱 아래 작은 바로가기로.

**왜 지금 안 하나:** 구조를 먼저 바꾸면 기능을 붙일 때마다 껍데기를 또 손대야 한다.
기능이 다 붙고 데이터가 흐르는 걸 확인한 뒤 한 번에 갈아엎는 게 손이 덜 간다.

### 자녀 화면 엄마 대화바 (2026-08-02 임시 제거)
화면 맨 아래에 늘 떠 있어서 준비물·오늘하루를 가렸다(사장님: 「눈에 거슬린다, 추후에 넣자」).
**기능은 살아 있다** — `chatDock()`·`chatSend()`·messages API 전부 그대로고,
`childview` 끝에 한 줄만 되살리면 돌아온다(코드에 그 자리를 주석으로 표시해 둠).
부모 홈 대화바는 그대로 둔다 — 그쪽은 가리는 것이 없다.

### 「연구 직원이 쓰는 화면 같다」 (2026-08-02 지적)
자녀 홈의 질문 카드가 세로로 줄줄이 서 있어서 **설문지처럼 읽힌다.**
RPG 일일 퀘스트로 잡았는데 모양은 아직 목록이다. 위 「오늘 카드 덱」 개편과 **같이** 풀 것.
지금 따로 손대면 두 번 고치게 된다.

### 📚 학년별 권장도서 + 근처 도서관 소장 (2026-08-03 보류)
**왜 좋은가:** 폰이 대신 못 해주고, 학년별로 갈리고(우리는 학년을 안다), 독서 미션·월간 리포트라는
이미 있는 자리에 그대로 얹힌다. 「이 학년이 많이 고른 책」은 바깥에 없는 데이터가 된다.

**확인한 것(실제로 열어봄):**
- 서울시교육청 어린이도서관 「학년별 권장도서」 페이지는 **비어 있다** — 「페이지 준비중 COMMING SOON」.
  검색 제목만 보고 「학년별로 있다」고 말한 것은 틀렸다.
- 대신 같은 사이트 **「방학 권장도서」 게시판은 살아 있다**(2022~, 반기마다).
  최신 = 「2026년 여름방학 연령별 권장도서 목록(유아, 초등 저·중·고)」 2026-06-30.
  menu_idx=306 & manage_idx=2521
- ⚠ **학년이 아니라 저·중·고 3단계**(1~2 / 3~4 / 5~6). 우리 용도엔 이걸로 충분하다.
- ✅ **첨부 형식 확인 완료(2026-08-03) — HWP 가 아니라 XLSX 다. 파싱이 쉽다.**
  - 엑셀 파일 하나에 목록 전체: `/board/boardFile/download/2521/1741589/529741.do`
    (게시글 keyvalue=1741589 · manage_idx=2521)
  - **연령 4단계**: 유아 / 초등 1~2 / 3~4 / 5~6 · **총 40권**(연령별 10권) · 반기마다 갱신
  - 「해제(작품 설명)」 컬럼이 있다 — 아이에게 보여줄 한 줄이 이미 있다
  - 다운로드에 checkDownloadAllowed 스크립트가 걸려 있으나 로그인 요구는 아닌 것으로 보임
  - **한 번 긁으면 끝나는 크기다.** 1년에 80권이고 실시간 API 가 필요 없다

**도서관 소장 얹기:** 도서관 정보나루(국립중앙도서관, 무료)가 ISBN → 전국 공공도서관 소장을 준다.
학교 주소가 있으니 위치 권한도 필요 없다.
🚫 단, **「소장하고 있나」까지만.** 「지금 대출 가능한가」는 하지 말 것 — 도서관 시스템마다 제각각이라
정확도가 안 나오고, 「있다더니 없다」가 한 번 나오면 그 뒤로 아무도 안 믿는다.

**순서:** 권장도서가 먼저 돌아야 도서관을 얹을 데가 생긴다.

### 🏫 학교알리미 상세 (2026-08-03 보류)
지금 school_details 에 든 것은 학급수·학생수뿐이다. 급식 직영/위탁·방과후 프로그램·진로 통계는
학교알리미에 있고 아직 안 들어왔다. 학교 페이지가 진짜 정보를 갖게 되는 건 이걸 채운 뒤다.

### 💰 엄마 참여형 수익 모델 (2026-08-03 논의, 기능 완성 후)
**방향:** 우리가 파는 게 「정보」가 아니라 「우리 반 엄마들이 모은 것」이 되면 후발주자가 못 베낀다.
후보 셋 — ①가정통신문 품앗이(올리면 이용권 연장) ②학교 정보 기여 ③추천 초대. **①이 제일 세다.**

**수익이 나는 자리:** 한 반 30명인데 올릴 사람은 한두 명이면 된다. 그 한두 명에게 이용권을 주고
**나머지 28명이 낸다.** 지금 앱엔 돈 낼 이유가 급식·시간표뿐인데 그건 무료 앱에도 다 있다 —
통신문이 그 이유를 만든다. 기여자 몫은 비용이 아니라 미끼값이고 원가는 거의 0이다.

**⚠ 반드시 걸 것:**
- 같은 통신문은 **먼저 올린 한 명만** 인정. 안 그러면 「다 같이 무료」가 된다
- 한 달에 받을 수 있는 무료 기간에 뚜껑
- **개인정보** — 통신문에 아이 이름·반이 찍혀 있다. 그대로 올리면 반 전체에 퍼진다.
  가리거나 텍스트만 뽑아 올리는 식이어야 한다

**성패를 가르는 숫자 하나:** 통신문이 쌓인 반 vs 안 쌓인 반의 **결제율 차이.**
안 벌어지면 이 모델은 틀린 것이다. 붙일 때 그 비교가 되게 만들어 둘 것.

### ✅ 디자인 다듬기 6건 — 완료 (2026-08-03)
1. 확인 대기 세로줄 빨강 → **파랑**. 확인 대기는 «할 일»이지 «사고»가 아니다
2. 사진 틀 260 → 190px, 사진 없을 땐 120px
3. 급식 별점 — 테두리 별 + 「별을 눌러서 골라줘」. «고르는 것»으로 읽히게
4. 홈 격자 — 카드 위에 얹어 «줄»로 읽히게
5. 서랍 「가장 최근」 — 파랑으로 채워 이 화면의 주인공으로
6. 자녀 비활성 「보내기」 — 회색 확인

남은 것: 일정 화면 주인공 카드(달력이 이미 주인공이라 안 해도 될 수 있다)

### 🏷️ 앱 이름 — **당분간 「우리아이학교정보」 유지** (2026-08-03 결론)
바꾸는 값어치가 생기는 시점은 **스토어에 올릴 때**다. 그 전엔 이름이 아무것도 막지 않고,
그때 아이콘·스크린샷·설명문을 어차피 만들어야 하니 같이 정하는 게 손이 덜 간다.
지금 이름의 약점은 「기억에 안 남는다」 하나인데 **아직 사용자가 없어 손해도 없다.**

**후보(스토어 확인 완료 2026-08-03):**
| 이름 | 스토어 | 메모 |
|---|---|---|
| 하교후 | **없음** | 제일 짧고 뜻이 정확. 상표 걸릴 유명 이름도 없음. 가장 안전 |
| 하교퀘스트 | 없음 | 「퀘스트」가 들어가 자녀 화면 어휘와 이어짐 |
| 하루퀘스트 | 없음 | 자녀 화면 제목(오늘의 퀘스트)과 일치 |
| 방과후 | 단독은 없음 | ⚠ 방과후학교 운영·강사 앱들과 섞임. **우리 앱 안에 「방과후」 메뉴가 이미 있다** —
  쓰려면 그 메뉴를 「학원·돌봄」으로 바꿔야 한다 |
| 애프터스쿨 | 학원 앱 있음 | 🚫 **플레디스 걸그룹 상표.** 확인 없이 쓰지 말 것 |
| 아이하루 | 없음 | 🚫 i-하루(app.iharu)와 발음이 겹침 |
| 금쪽이 | — | 🚫 채널A 상표 |

**핵심 논거(대표):** 급식 평가·친구·과목·리포트는 **전부 학교 끝나고 하는 것**이다 —
애들은 학교에서 폰을 거의 안 본다. 그래서 «방과후»계열 이름이 뜻으로는 제일 맞다.

**바꿀 때 손댈 곳:** capacitor.config.json(appName) · index.html title · 로그인 제목 ·
워커 templates.js 의 og/공유 문구 · 앱 아이콘 · 스토어 등록 정보
**남은 확인:** 키프리스 상표(캡차 때문에 코드탭에서 못 함)

### 🔍 경쟁 앱 「i-하루」 (2026-08-03 발견)
플레이스토어 `app.iharu` · **다운로드 10+** · 4.6점 · 2026-07-21 업데이트.
「흩어져 있던 우리 학교 정보를, 앱 하나로」 — 급식·시간표·학사일정(NEIS), 날씨·미세먼지,
**도서관 소장·추천도서(정보나루)**, 진로·학과, 교육청 공지. 전부 무료.

**우리가 붙일까 했던 것(날씨·권장도서·도서관·학교알리미)이 저기 이미 다 있다.**
다만 **사용자가 사실상 없고**(10다운로드), 전부 공공 API 를 모아 붙인 것이라 진입장벽이 아니다.
저쪽은 **조회 앱**, 우리는 **부모-아이가 같이 쓰는 앱** — 자녀폰 연결·미션·별·
아이가 직접 쌓는 기록·월간 리포트는 저기 없다. 겹치는 건 재료(NEIS)뿐이다.

## 그 밖

- 급식 평가 누적 통계 — 부모 쪽 「우리 애가 잘 먹는 반찬」 주간 요약
- 자녀 약관·방침 화면은 의도적 구디자인 유지 중 — 글자 크기만이라도 키울지
- 독서(read 영역) 미션 보상 정책 — 시드 재분류 때 «보상 안 붙인다»로 갈라둔 것의 후속
- **DB성 미션 확장** — 급식 평가와 같은 틀(고르기만 → 즉시판정 → 축적 → 월 리포트)로
  오늘 기분·읽은 책 종류 등. 급식 하나가 리포트까지 끝까지 도는 걸 본 뒤에 복제할 것
- 부모 푸시 없음 — 아이가 뭘 해도 부모는 앱을 열어야 안다(월 리포트 도착 알림도 여기 걸림)
