## 환경 구축에서 걸린 것 (전부 1회성)

1. **`sdkmanager`가 종료코드 0을 내면서 아무것도 안 받았다** — `JAVA_HOME` 미설정.
   Android Studio 번들 JDK(`C:\Program Files\Android\Android Studio\jbr`, OpenJDK 21)를 잡아 해결.
   → **교훈: wrangler와 같은 유형. 종료코드 말고 결과물로 검증할 것.**
2. **에뮬레이터가 하드웨어 가속 없이는 안 뜬다** — AEHD 드라이버를 관리자 권한으로 설치(대표님 실행).
   BIOS VT-x는 켜져 있었음(i7-12700K).
3. **LDPlayer가 adb 서버(5037)를 선점하고 있었다.** 모델명을 `SM-S9280`으로 위장해 우리 AVD처럼 보였고,
   **APK가 LDPlayer에 잘못 설치됐다**(대표님 작업 중인 인스턴스. 지시대로 그대로 둠).
   → **이후 규칙: LDPlayer=5037, 우리 AVD=`ANDROID_ADB_SERVER_PORT=5038`로 분리.**
4. **한글 경로를 AGP가 거부** — `블로그수입관련\에듀싱크`.
   `android/gradle.properties`에 `android.overridePathCheck=true` 한 줄로 통과. **폴더 이전 불필요.**

## 검증 중 발견해 고친 것

### 방과후 탭바 소실 — 막다른 화면 (심각)
`.week`가 `repeat(5, 1fr)`라 칸이 `min-content`("16:00~17:30" 글자폭) 아래로 안 줄어
가로 폭이 **412 → 469px**로 삐져나갔다. 웹뷰가 페이지를 축소하면서 `position:fixed` 탭바가 사라졌다.
**들어가면 다른 탭으로 나갈 수 없었다.** 360px에서는 30%까지 벌어져 더 심했다.

→ 이후 주간 타임그리드로 전면 교체(아래)하면서 근본 제거.

### 글씨가 너무 작았다
9~11.5px가 19곳에 흩어져 있었다(`.cal .dot` 9px, 자녀칩 부가정보 10px 등).
**전 화면 하한 12px**로 올렸다. 조절은 `style.css`의 `--fs-xs`(12px) / `--fs-sm`(12.5px) 두 값만 만지면 된다.

### 터치 영역
수정 30px · 뒤로가기 26px · 문장 속 링크 14px · 서브탭 37px → **전부 44px 이상**.

### 죽은 버튼 2개
- 방과후 `＋ 일정 추가` — `onclick`이 아예 없었음
- 학교정보 `🔗 학교 홈페이지` — 핸들러 없음

### alert → 토스트 (검수 메모 5번, 미반영으로 남아 있던 것)
`#toast` 자리만 있고 `toast()` 함수가 없어 실제로는 시스템 팝업이 떴다.
함수를 구현하고 **alert 4곳을 전부 교체**했다. → 검수 메모 5건 전부 반영 완료.

### 검증 방법
전 화면 DOM 스캔 + **클릭 가능한 요소 76개 전수 클릭**(CDP `Runtime.evaluate`).
360px·412px 양쪽에서 오버플로·글자잘림·터치크기·무반응 버튼을 자동 판정.
스크립트는 세션 스크래치패드에 있음(`cdp.mjs` / `cdp360.mjs`).

> ⚠️ 판정 오탐 주의: 처음엔 `innerHTML.length`로 변화를 감지해
> "선택 클래스가 A→B로 옮겨가는" 경우를 무반응으로 잘못 잡았다. 문자열 전체 비교로 고쳤다.

## 이어서 지시받아 만든 것

### 방과후 = 주간 타임그리드
작은 칸에 우겨넣지 않는다. **가로=월~금, 세로=시간축(13~21시, 30분당 30px)**.
시간은 축에서 읽으므로 블록엔 이름만 → 글자 잘림 원인 제거.

- 빈 칸 탭 → 하단 입력 바(요일·이름·시작/종료·색)
- 블록 아래 손잡이를 끌면 끝 시각 조정(10분 스냅). 실측: 17:30 → 19:00
- **색 6종 지정** — 학원별 구분
- 길이 조절은 `app.js`의 `GRID.px` 하나

### 급식 — 기간·검색·알레르기 알람
- 주간/월간 토글. **검색 중에는 주간에 가두지 않는다**(미리 알람이 목적이므로 한 달 전체에서 찾음)
- 알레르기 18종에서 우리 아이 것 선택 → 걸리는 날 카드·메뉴가 빨갛게
- 날짜별 알람: `7/10 알람 켰어요 — 전날 저녁 8시 · 대두·밀 주의`
- 알레르기 칸은 **접이식**(펼치면 화면 절반을 먹어서). 접혔을 땐 고른 것만 요약
- **기숙사형 3끼** — 일반 학교는 끼니 탭 숨김, 조식·석식이 있으면 아침/점심/저녁 탭.
  알람도 끼니별로 따로(`날짜|끼니` 키). 웹 `templates.js`와 같은 규칙

## 워커 수정 — **배포 대기**

`ensureMeals`(index.js) · `warmMeals`(api_schools.js)의 조기반환 조건을 고쳤다.

```js
// 전
if (mc && mc.n > 0) return;              // 미래 급식이 1건이라도 있으면 재수집 안 함
// 후
if (mc?.synced >= now - 7일) return;      // 마지막 수집 시각 기준(학교당 주 1회)
```

**왜:** 한 번 채운 뒤로는 미래 급식이 전부 소진될 때까지 절대 다시 받지 않았다.
→ **8/20 개학해서 2학기 급식표가 올라와도 반영되지 않는다.**

**중간에 한 번 잘못 고쳤다가 되돌린 기록:** 처음엔 "남은 일수가 부족하면 재수집"으로 만들었는데,
**방학엔 NEIS에 급식 자체가 없어 항상 부족으로 판정 → 급식탭 열 때마다 NEIS 호출**이 된다.
(대표님 지적으로 발견. 운영 D1의 짧은 급식 창은 캐시 축소가 아니라 **방학**이 원인이었다 —
전 학교가 최초 수집일 `20260713`에서 시작하고, 끝나는 날이 학교별 방학 시작일이었다.)

**배포 안 함.** `wrangler deploy`는 "배포해" 지시 시 실행.
