### 환경에서 걸린 것 (전부 1회성, 다시 안 겪음)
1. **`sdkmanager`가 종료코드 0인데 아무것도 안 받았다** — `JAVA_HOME` 미설정.
   → 번들 JDK `C:\Program Files\Android\Android Studio\jbr`(OpenJDK 21) 사용.
   **교훈: wrangler와 같은 유형. 종료코드 말고 결과물로 검증.**
2. **에뮬레이터는 하드웨어 가속 필수** — AEHD 드라이버를 관리자 권한으로 설치(대표님 실행). BIOS VT-x는 이미 켜져 있었음.
3. **🚨 LDPlayer가 adb 5037을 선점** — 모델명을 `SM-S9280`으로 위장해 우리 AVD처럼 보였고, **APK가 LDPlayer에 잘못 설치됐다**(대표님 작업 중 인스턴스. 지시로 그대로 둠).
   → **규칙: LDPlayer=5037, 우리 AVD=`ANDROID_ADB_SERVER_PORT=5038`.**
4. 한글 경로를 AGP가 거부 → 우회 플래그 한 줄.

### 검수 방법
CDP(`Runtime.evaluate`)로 **클릭 가능한 요소 76개 전수 클릭** + 360/412px 자동 판정.
스크립트: 세션 스크래치패드 `cdp.mjs` / `cdp360.mjs` / `sweep.js`.
> 판정 오탐 주의: `innerHTML.length` 비교는 "선택 클래스가 A→B로 옮겨가는" 경우를 무반응으로 오판한다. 문자열 전체 비교로 고쳤다.

### 검수로 잡아 고친 것
- **방과후 탭바 소실(막다른 화면)** — `.week`의 `repeat(5,1fr)`가 min-content 아래로 안 줄어 폭이 412→469px로 삐져나감 → 웹뷰가 축소 → `position:fixed` 탭바 소실. 360px에선 30%까지 벌어졌다.
- **글씨** 9~11.5px가 19곳 → **전 화면 하한 12px**. 조절은 `--fs-xs`/`--fs-sm` 두 값만.
- **터치 영역** 수정 30px·뒤로가기 26px·문장 링크 14px → **전부 44px 이상**.
- **죽은 버튼 2개** — 방과후 `＋일정 추가`, 학교정보 `🔗학교 홈페이지`(둘 다 onclick 없음).
- **alert → 토스트** — `#toast` 자리만 있고 `toast()` 함수가 없었다. 구현 후 alert 4곳 교체.
  → **검수 메모 5건 전부 반영 완료.**

## 13-1. 실기기 연결 (재현용 절차)
- **개발자 모드 + USB 디버깅** → USB 연결 → 폰에서 "이 컴퓨터 허용" (지문 승인)
- ⚠️ **LDPlayer가 adb 5037을 선점**해서 폰이 안 잡혔다 → **adb 전부 kill 후 우리 SDK adb만 5038로 재기동**하면 폰이 잡힌다.
  - 폰 시리얼 `R3CX70NHLAB` / 모델 `SM-F956N`
- **무선 디버깅**도 붙임: `adb -s <usb> tcpip 5555` → `adb connect 172.30.1.94:5555`. 이후 케이블 없이.
- **앞으로 폰 작업은 `ANDROID_ADB_SERVER_PORT=5038` + 시리얼 지정**(`172.30.1.94:5555`).

## 13-2. 🔥 빌드 함정 — 구글드라이브 파일 잠금

- ⚠️ 그래서 **APK 경로가 바뀜**: `%LOCALAPPDATA%\eduthink-build\android\app\outputs\apk\debug\app-debug.apk`

# 14. 디자인 층 — UI 전면 개편 (세션 마지막)

> **대표님 원칙(이번 세션의 결론):** "제일 중요한 건 UI다. 진짜 편하게 못 쓰면 다 쓸모없다.

## 14-1. 하단 탭바 폐지 → 원형 메뉴 홈
- **탭바(홈·기록·＋·방과후·내정보) 완전 제거.** "다른 앱과 똑같다"는 지적.
- **홈 = 원형 메뉴 허브** — 큰 아이콘 9칸(급식·일정·시간표·방과후·기록·서류·알림·학교정보 + 편집).
  누르면 그 페이지로, 돌아올 땐 **상단 가운데 집 버튼(#homefab)**.
- 홈 구성 순서: 인사 → **캐러셀(지금 챙길 것)** → 원형 메뉴 → (예정: 맨 밑 대화창)
- **자동 캐러셀** — 3초마다 부드럽게 넘어감(손 안 대도). 카드: 안읽은 메시지·오늘 급식·보고서 D-day·최근 기록.
  홈 벗어나면 타이머 정지, 재진입 시 재시작.

## 14-2. 디자인 방향 확정
> 대표님: "2D라 밋밋 → 물방울/3D 느낌. 근데 **너무 유아틱 가면 안 됨**."

**유아틱을 없앤 3가지(합의):**
1. **이모지 → 선 아이콘(Tabler)** ← 이게 가장 결정적
2. **채도 낮춘 뮤트 톤** (쨍한 파스텔 금지)
3. **완전 원 → 둥근 사각(21px)** + 은은한 유리 광택(`backdrop`류 대신 inset 하이라이트 + 상단 반사)

**테마 6종 확정** (대표님이 시안 비교 후 플럼·딥그린 탈락):
| 밝은 | 진한 |
|---|---|
| 웜그레이(**기본**) · 아이보리 · 민트 · 라벤더 | 네이비 · 차콜 |
- `data-theme`으로 전환. **내정보 → 테마**에서 고객이 직접 고름.

  **테마 하나 바꾸면 급식·시간표·다이어리·기록까지 전체가 같이 바뀐다.**
- 아이보리는 "클로드 색 같다"는 지적이 있어 기본에서 내리고 선택지로 남김.
