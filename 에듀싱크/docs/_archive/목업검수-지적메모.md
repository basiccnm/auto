# 앱 목업 검수 — 지적 메모 (반영 대기)

2026-07-24, 대표님 구두 지적. **"진행하지 말고 메모만"** 지시에 따라 여기 모은다.
검수(회신26) 지적과 합쳐 10개 안팎이 되면 일괄 반영.

## 받은 지적 (5건)

1. **일정 = 다이어리 형식**으로 만든다
2. **시간표 = 셀을 눌러 손가락으로 편하게 편집**
3. **"이달의 일정"을 상단에 항상 고정**
4. (원칙) **목업에도 들어갈 요소는 전부 표시한다** — 구현 안 되어도 자리·[예정] 배지로 보여줄 것
5. **삭제 등에서 크롬 팝업(alert) 금지** — 화면 안 표시(토스트/시트)로

## 현재 목업 상태 (검수자 참고)

- 1·2·3·4는 **[예정] 배지·자리 표시까지 반영됨** — 일정탭(이달의 일정 고정 + 다이어리 달력 자리),
  시간표(셀 탭 가능 + "터치 편집 예정"), 커뮤니티 서브탭 [예정], 업로드(앨범·연속촬영 [예정])
- 5는 **미반영 상태로 중단됨** — 재인증 통과·모의결제·시간표 셀 탭에서 아직 브라우저 alert가 뜬다.
  (index.html에 토스트 자리만 만들다 멈춤 — 화면 동작에는 지장 없음)
- 검수 주소: http://localhost:8789 (하드 새로고침 Ctrl+F5 권장 — app.js 캐시)
