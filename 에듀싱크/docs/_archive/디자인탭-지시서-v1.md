# 디자인탭 작업 지시서 v1 — 블록1 "자녀기록" 목업 디자인 다듬기

작성: 2026-07-19 | 발신: 전략 세션 | 대상: Claude 디자인 세션
정본 문서: `docs/블록1-지시서-v4.md` (기능·레이아웃 스펙) · 목업: `mockups/블록1-목업-v1.html`

## 0. 역할과 산출물

- 역할: **이미 확정된 목업의 시각적 완성도를 올리는 것.** 새 화면·새 플로우를 만드는 게 아님.
- 산출물: 목업 HTML을 복사한 `mockups/블록1-목업-v1-design.html` 1개 (원본은 절대 수정 금지).
  변경한 디자인 토큰(색·타이포·간격 값)은 파일 상단 주석에 목록으로 정리할 것 — 코드탭이 이 목록만 보고 실제 앱에 이식한다.

## 1. 손대도 되는 것

- 색감 조정 (단, 기존 앱에서 추출된 토큰 체계 안에서 — 새 팔레트 금지)
- 아이콘·일러스트 (기록 썸네일 빈자리, 빈 상태(empty state) 그림, 종류별 아이콘)
- 여백·타이포 다듬기, 카드 그림자·라운드 등 질감
- 빈 상태 화면 디자인 (기록 0건일 때, 방과후 0건일 때 — 현재 목업에 없으면 추가 가능. 유일하게 "추가"가 허용되는 영역)

## 2. 손대면 안 되는 것 (전략 결정의 결과물 — 변경 제안도 하지 말 것)

- 화면 구성·순서·정보 구조 (마이페이지 5단 구성, 타임라인 3열 그리드, 주간 뷰 등)
- 모든 문구 (잠금 안내, 동의 체크, 보호 안내 등 — 법·전환율 근거로 확정된 카피)
- 기능 배치 (FAB 위치, 필터 칩 구성, 업로드 플로우 "사진→종류 탭 1번→저장")
- 광고 규칙 (①~④ 화면 광고 없음, ⑤만 최하단)
- 360px 모바일 기준 (PC 레이아웃 만들지 말 것)

## 3. 디자인 방향 (참고)

- 정체성: "부모가 쏟은 정성을 보이게 하는 거울" — 관리 도구가 아니라 기록·성장의 따뜻함. 차분하고 신뢰감 있게.
- 불안 마케팅 안 함 → 경고·긴급 느낌의 색 사용 최소화 (잠금·만료 표시도 위협적이지 않게)
- 아이 데이터 다루는 앱 → 보안·신뢰 요소(동의, 보호 안내)는 눈에 잘 띄되 무겁지 않게
- 기존 배포 앱과 한 앱처럼 보여야 함 (다크 헤더 + 라이트 콘텐츠 톤 유지)

## 4. 완료 기준

- [ ] 원본 목업과 나란히 열었을 때 구성·문구·플로우가 100% 동일
- [ ] 변경 토큰 목록이 파일 상단 주석에 정리됨
- [ ] 360px에서 깨짐 없음
- [ ] 기존 앱(급식·시간표 화면)과 나란히 봐도 같은 앱으로 보임
