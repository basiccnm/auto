## 기능 ① 학교생활 서류 — 서식 3종

화면 3개: `#docs`(상황 선택) · `#doc-form`(작성) · `#doc-preview`(미리보기)

### 상황으로 진입 — 서류 이름을 몰라도 되게

| 상황 | 서식 |
|---|---|
| ✈️ 가족여행 · 체험학습 | 교외체험학습 **신청서** + **보고서** |
| 🤒 아파서 · 결석 | 결석신고서 |
| 💬 선생님과 상담 | 학부모 상담 신청서 |

### 필드는 실제 학교 양식에서 그대로 옮겼다

원본: `에듀싱크\*.hwp` 4개 (2026학년도 서울숭미초). HWP(OLE 복합문서)에서 본문을 추출해 확인했다.

**추측으로 만들었던 것과 많이 달랐다.** 빠뜨렸던 것:
- 성별 · 주소
- **보호자 동행 확인** — "아니오"면 **허가 자체가 안 됨**
- **연속 5일 초과 시에만** 나오는 안전확인 + 상시 비상연락처
- **학습계획이 날짜별** — 한 칸이 아니라 날짜마다 한 줄

반대로 내가 넣었던 "느낀 점"은 실제 서식에 **없었다**(보고서는 「체험학습 내용」 한 덩어리).

### 진짜 값은 서식이 아니라 규칙이다

엄마들이 모르는 것들을 앱이 계산해 경고한다. **이게 "우리가 표준"이 되는 지점.**

- **연 19일 한도**(수업일수 10%) — 잔여를 막대로. 넘으면 "초과분은 미인정 결석" 경고
- **보고서 7일 기한** — `D-3` 카운트다운. 넘기면 **미인정 결석**임을 명시
- **결석신고서 5일 이내** 제출 — 넘기면 미인정 결석
- **질병 3일 이상 → 진단서 필수** (약봉투·처방전 불인정). 일수에 따라 문구가 자동으로 바뀜
- **경조사 인정 일수** — 결혼 1일 / 사망 5일·3일 / 입양 20일
- **연속 10일 초과 불가** · 연속 5일 초과 시 담임 연락 의무
- **학년별 상담 가능 시간** 자동 표시 + "야간 상담 없음"
- 미인정 결석 3일 연속 시 학교가 소재 확인(면담·가정방문) 안내

### 흐름
자동 채움(학교·학년반·이름·보호자) → 날짜·사유만 입력 → **종이 형태 미리보기** →
`🖨 출력·PDF`(**[네이티브 자리]**) → **타임라인에 기록으로 남김**

신청서만 내고 보고서를 안 냈으면 `#docs` 맨 위에 D-day 카드가 뜨고,
누르면 **신청서에 적었던 기간·장소를 그대로 물려받아** 보고서 폼으로 간다.

### 뺀 것 — 조퇴·외출증
양식은 있었지만 **뺐다(대표님 지시)**. 실제로는 전화 한 통으로 끝나고,
엄마가 데리러 가면 그냥 보내준다. 서류가 필요 없는 절차라 앱에 둘 이유가 없다.

### 개인정보(§5)

하단에 **"실제 양식 기준이지만 학교마다 다를 수 있으니 참고용"** 고정 안내 · OCR·AI 없음(요청대로)

## 기능 ② 부모 → 자녀 원터치 알림

화면 2개: `#notify`(부모 발송) · `#childview`(자녀 수신)

### 부모 쪽
- **프리셋 5개** — `4시 태권도 가` / `학원 끝나면 바로 집으로` / `오늘 비 와, 우산 챙겨` / `저녁 먹고 와` / `엄마가 조금 늦어` → 누르면 바로 발송
- 직접 입력칸 별도
- 보낸 알림 목록에 `전송됨` / `✓ 확인함` 표시
- **FCM 푸시**로 명시(SMS 아님) · `[네이티브 자리]` 배지

### 자녀 쪽 (제한 사용자)
- 받은 알림에 **`확인` 버튼** → 부모 목록이 `✓ 확인함`으로 바뀌고 토스트 `엄마에게 «봤어요»를 보냈어요`
  → **문자와 다른 결정적 차이가 화면에서 보인다**
- 볼 수 있는 것은 **알림 · 오늘 급식 · 오늘 시간표**뿐. 결제·삭제·형제 정보 없음
- **부모용 하단 탭바도 뜨지 않는다**(실측 확인)
- 부모/자녀 전환은 목업 전용 체크박스. 실앱은 로그인 역할로 분기한다고 화면에 명시

### 경계 (지시대로 안 한 것)
실제 자녀 계정·권한·아동 보호자동의(나중 build) · 학원일정 프리셋 자동화(나중 카드) ·
외부인 접촉 경로 없음(부모→자기 자녀만)

## 남은 것 / 물어볼 것

1. **보고서 리마인드를 홈에도 띄울지** — 지금은 `#docs` 안에서만 보인다. 미인정 결석으로 이어지는 사안이라 홈이 나을 수 있다.
2. **진입 위치** — 지금은 홈 카드 2개. 서류를 학교탭으로, 알림을 내정보로 옮기는 안도 가능.
3. 서식이 학교마다 다르다 — **학교별 서식 차이를 어디까지 흡수할지**는 미정. 지금은 서울숭미초 양식 기준.
4. 결석신고서 뒤쪽의 **담임교사 확인서**(학교가 작성하는 부분)는 넣지 않았다. 맞는지 확인 필요.
