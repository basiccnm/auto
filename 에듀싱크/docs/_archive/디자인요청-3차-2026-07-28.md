## 2. 그려 주셨으면 하는 것 — 6화면 + 팝업 2개

아래 순서가 곧 급한 순서입니다. **팝업은 해당 화면과 한 벌로** 주세요.

### ① 03 급식 (캡처 `03-급식.png`) — 매일 여는 화면
지금 문제:
- 화면의 절반이 **「우리 아이 알레르기」 상자**와 검색창입니다. 정작 **메뉴가 안 보입니다**
- 방학이라 식단이 없는데, 빈 상태 안내문이 3줄입니다(「~없어요」「~올렸어요」「~이에요」)
- 맨 아래 회색 안내문 「알람은 전날 저녁에 울려요 · 급식은 기간 조회(from~to)로…」 — 사용자가 알 필요 없는 내부 이야기입니다

필요한 것: 주간/월간 · 날짜별 식단(중식·석식) · **알레르기 걸린 메뉴 표시** · 끼니별 알람 · 빈 상태.
알레르기는 **메뉴를 밀어내지 않으면서** 걸린 메뉴에만 붙는 방법을 찾아 주세요.

### ② 05 시간표 (캡처 `05-시간표.png`) — **만지는 화면**
학부모가 칸을 직접 채우고 고칩니다. 보는 화면이 아닙니다.
- 교시 × 요일 격자, 칸을 눌러 과목 바꾸기 → **칸 편집 팝업 필요**
- 점심 줄
- 하교 후 개인 일정(학원 등) — 줄 추가/삭제, 학원마다 색
- 지금 13px 미만 글자 2개, 40px 미만 버튼 1개가 있습니다

### ③ 11 준비물 (캡처 `11-준비물.png`)
