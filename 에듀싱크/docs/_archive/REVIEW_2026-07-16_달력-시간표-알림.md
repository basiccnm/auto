## 4. 시간표 요일(weekday) 기반 전환  (schema.sql / index.js / templates.js)
동기: 날짜별 저장 시 전국 확장 시 ~1,100만 행 → **요일 1벌로 축약(~12배↓)**.
- **schema**: `timetables.class_date → weekday INTEGER`(1=월~5=금), `timetable_overrides.class_date → weekday`. 유니크 인덱스 재정의. 로컬 D1은 **DROP/CREATE로 재생성**(재방문 시 재수집).
- **index.js `ensureTimetable`**: 창을 `today-35 ~ today+14`로 받아 (요일·반·교실·교시)별 **최빈 과목**을 정규표로 저장. 학기(school_year+semester) 존재 시 스킵(확정·잠금). `weekdayOf()` 헬퍼 추가.
- **조회(`handleSchoolDetail`)**: `WHERE ... AND school_year=? AND semester=? ... ORDER BY weekday, period`. 학기 전환 시 자동으로 새 학기표 표시.
- **오버라이드 병합**: 키 `weekday|period`. `handleTimetableEdit`은 `class_date` 대신 `weekday` 수신. `handleChildToday`도 요일+학기 필터.
- **templates.js `realTimetableGrid`**: `class_date`→`weekday` 직접 소비(`byWeekday[w][period]`), `byDate/datesByWeekday/nearestDate` 로직 제거. 편집 셀 `data-weekday`, 저장 fetch도 `weekday` 전송.
- **검증**: 숭미초 2-1 요일 저장(월5·화5·수4·목5·금4), 렌더 25칸 `data-weekday`, 오버라이드(금1→국어) 저장·유지, 학기필터 후 기존 표시 정상.
- **검수 포인트**: 최빈 과목 축약 로직(시험·행사 배제), 학기 경계(SEM 파라미터가 날짜창 걸쳐도 격리), 오버라이드가 **학기 스코프 아님**(§7 리스크), 방학직전 워밍 시 요일 공백 가능성.

## 5. 자녀 칩(프로필 스위처) — 모든 학교에서 노출  (templates.js: `childSwitcher`, `schoolDetailPage`)
- **버그**: 기존 `${paid ? childSwitcher(...) : 등록링크}` → 자녀 없는 학교에서 등록 자녀가 안 보임.
- **수정**: `${(siblings && siblings.length) ? childSwitcher(siblings, child, school.slug) : 등록링크}`. `siblings`는 이미 학교 필터 없이 전체 자녀 로드(index.js 357행 근처).
- `childSwitcher(siblings, active, currentSlug)` — 등록 버튼이 **현재 보는 학교**로 연결.
- **콘텐츠 잠금 유지**: `paid`(=이 학교에 유효 자녀 有) 판정은 그대로 → 자녀 없는 학교는 잠김. 검증: 경기초(자녀無)에서 3자녀 칩 노출 + 🔒 잠금 + `ttGrid` 미렌더.
- **검수 포인트**: active=null(비유료 학교)일 때 expiry/하이라이트 분기, 3자녀 시 등록버튼 숨김, 1자녀 시 등록버튼=현재학교.

- **검증**(`wrangler dev --test-scheduled` + `/__scheduled` 수동 트리거): 틱당 NULL 3곳 처리(161→158→155), 그중 실데이터 학교는 **185건 수집(키 인증 정상 — 5건 아님)**, 무데이터 특수학교는 0건+스탬프(재시도 억제). sync_state 12,563개교 시딩 완료.
- 검수 포인트: 매분 sync_state LEFT JOIN 쿼리 비용(인덱스 PK, 12.5k행 — 경미), refreshSchedules의 DELETE→INSERT 원자성(batchChunked 청크 사이 실패 시 부분 상태 가능 — 다음 바퀴에 자가 치유), 프로덕션 적재는 sync_to_d1.py 경로.
