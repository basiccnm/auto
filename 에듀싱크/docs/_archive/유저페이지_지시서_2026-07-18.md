## 0. 서비스 모델 (모든 화면 관통)

### 0.1 계정 없이 시작 (owner_token)
- 회원가입 없음. 첫 방문 시 브라우저에 랜덤 토큰(`owner_token`) 쿠키 발급 → 이 토큰이 계정 키.
- 자녀·결제·알림·일정이 전부 이 토큰에 묶임.
- **소셜 로그인(선택)**: 카카오·구글·네이버. 기기가 바뀌어도 자녀·일정을 유지하기 위한 용도. 수집은 **고유식별번호+닉네임만**(이름·전화·이메일 미수집).

### 0.2 무료 / 유료 게이팅 ★ (수익 구조의 핵심)
자녀를 등록하면 **1주일 무료 체험**(자동결제 없음), 이후 유료 이용권. **베타 기간엔 전부 무료**(결제 차단).

| 기능 | 무료(비회원) | 유료(자녀 등록/체험/결제) |
|---|---|---|
| 오늘 급식 | ○ | ○ |
| 주간 전체 급식 | ✕ | ○ |
| 우리 반 시간표 | 잠금(티저) | ○ + 개인일정 추가 |
| 학사일정 | 티저(주요 일정만) | 전체 + 내 일정·알림 |
| 광고 | 노출 | 제거 |
| 커뮤니티(초등) | 읽기 | 작성 |

- **가격**: 자녀 1명 월 3,500원부터(2명 +500, 3명 +1,000 / 기간 길수록 할인). **베타 중엔 "정식 오픈 예정가"로만 표시**하고 결제 비활성.
- 유료 판정: `children.is_test=1` 또는 `trial_expires_at > now`.

### 0.3 온디맨드 데이터 로딩
- 급식·시간표는 학교를 열 때 NEIS에서 그 학교 것만 실시간으로 받아 캐시. 페이지는 즉시 뜨고 콘텐츠는 스피너 후 채워짐(`/api/school-warm` → `?w=1` 새로고침).
- **시간표는 요일 고정 = 한 번 세팅하면 끝**(실시간 아님). NEIS에 없으면 빈 격자 직접 입력 + 반 단위 공개 오버라이드.

### 0.4 상태: 베타
- 홈 로고 옆 `BETA` 배지. 결제 페이지 "베타 무료" 안내 + 결제 버튼 비활성. 광고 전부 숨김(현재).

### 0.5 디자인 시스템 (현행 톤 — 유지 기준)
- **브랜드 그린** `#2E7D5B` (강조·CTA), 딥그린 `#256A4C`, 그린배경 `#E7F1EC`.
- 잉크 `#16233B` / 보조 `#2B3648` / 뮤트 `#8A94A6`·`#6B7688`.
- 배경 `#F3F5F8`, 카드 `#fff`, 보더 `#E6E9EF`.
- 홈 히어로만 네이비 그라데이션(`#132445`→`#1C3B69`) + 그린 포인트.
- **반응형: 360px(최소 폰) 기준 완성 후 확장.** 글자 `clamp(min, vw, max)`로 상·하한. 카드·라운드(14~16px)·부드러운 톤.
- 아이콘 이모지 사용(🍚 급식 / 📅 학사일정 / 📖 시간표 / 🔔 알림).

## 1. 홈 `/`
- **히어로**(네이비): 로고+`BETA`, 로그인/가입·마이 버튼, "매달 학교 홈페이지 뒤지지 마세요" 카피, **학교 검색창**(+ 초/중/고 칩), "매일 급식 무료·가입 시 1주일 체험" 배지.
- **기능 소개** 4카드: 오늘의 급식 / 학사일정+ / 우리 반 시간표+ / 챙길 일정 알림.
- **베타 의견 보내기** 배너 → `/feedback`.
- **풋터**: 서비스 소개·이용약관·개인정보처리방침·의견 보내기 링크.
- (베타 해제 시) 광고·협찬 스택.

## 2. 검색 결과 `/search?q=&level=`
- 상단 검색 바(뒤로가기 + 학교급 필터 칩). 결과 = 학교 카드(아이콘·이름·학교급 뱃지·관할 교육청·주소) → 학교 상세로.
- 결과 없음 상태(안내·예시). 무료는 광고 노출.

## 3. 학교 상세 `/school/:slug` ★ 가장 큰 화면
헤더(학교명·요약줄 "공립·남녀공학·○○년 개교"·관할청) + **스탯 4칸**(전교생/학급수/교원수/개교) + **탭 5개**.

### 탭 구성
| 탭 | 무료 | 유료 |
|---|---|---|
| **학교정보**(overview) | 연락처(주소·전화·전화걸기) + 학년별 현황(학급수·학생수·성별, 접힘) | 동일 |
| **급식**(meal) | 오늘 급식만(조식/중식/석식 탭, 기숙사형 뱃지) | 주간 전체 급식 |
| **시간표**(timetable) | 잠금 티저(자녀 등록 유도) | 요일 격자 시간표 + 셀 탭해 수정(반 공개 오버라이드) + 개인일정(학원 등) 추가 + 교시·점심시간 설정 |
| **학사일정**(schedule) | 주요 일정 티저 | 월별 달력(이전/다음 달) + 내 일정 추가/삭제 + 일정 알림 |
| **커뮤니티**(community, **초등만**) | 글 읽기 | 1~3줄 글 작성·고정닉네임·신고(욕설 자동 마스킹) |

- **수능일** 등 전국 공통 일정은 모든 학교 달력에 ★강조(무료도 이름 노출).
- **온디맨드 워밍**: 콘텐츠 미캐시 시 스피너 → 자동 새로고침.
- **정보 오류 신고**: 학교정보 탭 하단 `<details>` 폼 → `/report`(개인정보 미수집) → 접수 감사표시.
- **자녀 등록 CTA**: 무료 화면 곳곳에서 "자녀 등록하기"(무료 1주일 체험) → `/register-child`.
- 유료는 광고 제거.

### 학교 상세 내부 인터랙션(액션 API)
- 시간표 셀 수정 `/timetable/edit`(그 반 유료 자녀 보유자만, 반 단위 공개).
- 개인 일정(시간표) `/schedule/personal`, 교시·점심 `/schedule/settings`·`/schedule/time`.
- 달력 내 일정 `/calendar/event/add|edit|delete`(알림 시각 지정 가능).
- 커뮤니티 `/community/post|nickname|report`.

## 4. 자녀 등록 플로우
1. **등록 `/register-child?school=`** — 학년·반 선택(전국 실제 학급수 기반, 반 필수). 무료 1주일 체험 안내.
2. **이중 확인 `registerConfirmPage`** — 학교·학년·반 최종 확인(오등록 방지, confirmed=1).
3. **온보딩 `/onboarding`** — 등록 완료 후 첫 안내.
- 결과: `children` 생성(trial_expires_at=+7일), owner_token 쿠키.

## 5. 자녀 정보 수정 `/child/edit?id=`
- **별명·학년만 수정**, 학교·반은 잠금(정확도 유지). 새 학년도 **승급(action=promote)** 1회 허용.

## 6. 마이페이지 `/mypage`
- **계정 카드**: 로그인됨(제공자·닉네임·로그아웃) / 미로그인(로그인 유도, 제공자 키 있을 때만).
- **만료 임박 배너**(2일 이내) → 연장 CTA.
- **자녀 카드**(각): 별명·학교·학년반, 오늘 급식 요약, 다가오는 주요일정 D-day, 이용 만료/남은일. 시간표 바로가기.
- **메뉴**: 자녀 관리 / 결제 내역 / 알림 설정 / 이용권 연장 / **베타 의견 보내기**.
- 자녀 없을 때 빈 상태(학교 검색 유도).

## 7. 자녀 관리 `/mypage/children`
- 자녀 목록(별명·학교·학년반·이용만료) + 별명·학년 수정 / 삭제. 한도(무료 1 / 유료 최대 3), 초과 시 구독 유도. 자녀 추가(학교 검색). 삭제 API `/child/delete`.

## 8. 구독·결제
- **`/subscribe`**: 자녀 수·기간·수단 선택 → 총액 자동계산. **베타: "모든 기능 무료" 안내 + 결제 버튼 비활성**(예정가만 표시).
- **`/pay`**(POST): 현재 더미 + `PAYMENTS_DISABLED=true`로 차단. 정식 오픈 시 PG 연동.
- **결제 완료 `payCompletePage`**: 금액·기간·자녀·수단·만료일 영수증 요약 → 마이페이지.

## 9. 결제 내역 `/mypage/payments`
- 결제 카드 목록(금액·기간·자녀·수단·결제일·만료일·상태) + 환불 문의 안내. 출처 `payments`.

## 10. 알림 설정 `/mypage/notifications`
- 아침 알림(급식·시간표·챙길 일정) 웹푸시 구독/해제/테스트 발송. iOS는 홈 화면 추가(PWA) 후 가능 안내. VAPID/서비스워커. API `/api/push/subscribe|test`.

## 11. 로그인 `/login`
- 소셜 버튼(env에 키 있는 제공자만 노출 — 현재 카카오·구글). "이름·이메일·전화 안 받음, 기기 바뀌어도 자녀 유지" 안내. 이미 로그인 시 상태 표시. `/auth/:provider` OAuth, `/logout`.

## 12. 베타 의견 `/feedback`
- 분류(불편·버그/기능제안/칭찬/기타) + 내용 → 제출 → 감사 화면. 개인정보 미수집. 홈·마이페이지에서 진입.

## 13. 정적/법적 페이지
- **소개 `/about`**: 히어로 + 무료/유료 비교표 + 가격표(정식 오픈 예정가 배지) + 시작 CTA.
- **약관 `/terms`** / **개인정보처리방침 `/privacy`**(소셜 수집=고유식별번호+닉네임만 명시).

## 14. 유치원 상세 `/kinder/:slug`
- 유치원 기관정보·공시(급식·통학차량·방과후). *1차 범위에서 대체로 제외 상태 — 존재만.*
