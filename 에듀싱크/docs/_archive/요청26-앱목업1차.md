# 1. 목업 — 지금 클릭해 보실 수 있습니다

```
http://localhost:8789
```

(에듀싱크 목업 포트 8789 — 8788 wrangler와 별개로 떠 있습니다)

## 위치와 성격

`에듀싱크\app\www\` — **이 폴더가 그대로 Capacitor 번들 자산이 됩니다.** 목업이 버려지지 않습니다.

- 데이터는 전부 스텁이지만 **모양이 계약 응답과 1:1**입니다. `STUB.children`은 §5.1 모양,
  `STUB.meals`는 §4.2 객체 배열(`{name, allergens[]}`), 기록은 §5.2 `period` 객체 그대로.
  API 연결 때 `STUB.xxx` → `fetch("/api/v1/…")`만 바꾸면 화면 코드는 안 바뀝니다
- 색은 전부 **회색조 구조 표시용** — 디자인 토큰은 구조 확정 후 `style.css`의 `:root` 변수만 갈아끼웁니다
- 노란 배지 <b>[네이티브 자리]</b>가 붙은 곳이 Capacitor 브리지 자리입니다(카메라·생체·FCM)

## 못박을 것 3가지 — 이렇게 반영했습니다

**① 입력 30초 (§0 급소)** — 업로드가 탭바 가운데 **가장 큰 버튼**입니다. 흐름은
`카메라 → 미리보기(재촬영/확정) → 저장` 딱 3단계이고, 종류·시기는 확인 단계에 자동 추정값으로
미리 채워져 있어 **안 고치면 탭 2번**입니다. 저장 후 "한 장 더"로 연속 촬영.

**② 자녀 전환 = 캐릭터 선택** — 상단 자녀 칩(🦊 첫째 ▾)을 누르면 **전용 전체 화면**이 뜨고,
큰 캐릭터 카드를 고릅니다. 설정 속 프로필 목록이 아닙니다. 자녀 추가도 이 화면의 "+" 카드.

**③ §4.5 잠금 자리 2종** —
- **열람 잠금**: 기록 영역(타임라인·업로드) 첫 진입 시 전체 화면 잠금이 덮습니다.
  세션당 1회(실앱: 네이티브 생체 → 통과 플래그)
- **재인증 시트**: 기록 삭제·자녀 수정·방과후 수정·회원 탈퇴 — 모든 되돌릴 수 없는 동작 앞에
  같은 바텀시트가 뜹니다(실앱: 생체/비번 → `/auth/reauth` → `X-Reauth-Token`)

# 2. 개발환경 설치

| 항목 | 결과 |
