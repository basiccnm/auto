## 미해결 / 대기

1. **회원가입 + 부모정보 대전환** (가장 큰 다음 건)
   - 부모 이름·휴대폰·주소 회원가입 시 수집(소셜도 정보 입력). 주소는 이벤트/발송용으로 다 받음.
   - 문자인증은 유료 전환 때 대행사. 가족검증(등본상 자녀만)은 블록1.5부터 필요 시 도입(지금은 준비만, 리스크 안 만듦).
   - 마이데이터는 지금 안 씀.
   - → 전략 세션이 전환 지시서 작성 후 사장님 최종 승인 → 코드탭.

2. **껍데기(앱 프레임) 재구축** — CSS 손보기가 아니라 네비게이션/레이아웃/라우팅을 뜯어고침(데이터·기능은 유지). HTS/MTS처럼 **PC 버전과 모바일 버전을 별도로**(반응형 아님). 모바일은 시간표·급식표를 크게 한 화면에 보고 뒤로가기로 확인하는 단순 구조. 착수 지시 대기.

3. **데모 데이터 계정 불일치** — "로그인 상태로 만들기(QA)"와 "데모 심기(QA)"가 서로 다른 owner_token에 심겨 채워진 화면을 아직 못 봄. 심기를 현재 로그인 세션에 하도록 수정 요청됨(회신15).

4. **법적 건** — 민감정보(학업 이미지) 질의 등은 **사장님이 별도로 일괄 진행** 지시. 전략 세션이 임의 판단 안 함. 돈/법 들어가는 건 사장님에게 물어봄.

5. **사업자 표시 값** — 대표자·주소·고객센터·통신판매업 신고번호. 유료 전환 전 법적 필수(현재 "(준비 중)").

6. **QA 계정 누적** — 검수용 계정 5개+ 쌓임. 배포 전 정리 체크리스트에 포함.
