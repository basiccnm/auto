## 1. 🔴 검수 3회 막힘 — 해결했습니다

### 원인
버튼이 **두 개**라 세션이 어긋날 수 있었습니다. "로그인 상태로 만들기"와 "데모 심기"가 각자 `owner_token`을 다루다 보니, 어느 한쪽이 새 토큰을 만들면 다른 쪽과 불일치가 났습니다.

### 해결 — **버튼 하나로 통합**
`/admin` → 회원 관리 → 🧰 개발/QA 도구 → **"QA 계정 + 데모 데이터 한 번에"**

이 버튼 하나가 다음을 **한 함수 안에서** 처리합니다:
1. 쿠키에 `owner_token` 없으면 생성 + 응답에 함께 내림
2. `users` 행 없으면 생성(로그인 게이트 통과용)
3. 자녀 + 기록 7건 + 방과후 4건 심기

**한 트랜잭션 흐름이라 토큰 불일치가 구조적으로 불가능합니다.**

성공 화면에 **어느 계정에 심었는지 표시**합니다 — `이 브라우저 계정: baa4e4ad… (자녀 id 30)`. 혹시 또 어긋나면 이 값으로 바로 진단됩니다.

### 검증 (빈 쿠키 → 버튼 1회 → 바로 접속)
```
버튼 클릭      → 200 · 기록 7건 · 방과후 4건 · 계정 baa4e4ad… (자녀 id 30)
/records       → 200 · 썸네일 7 · 학년/학기 섹션 3 · 빈상태 0
/activities    → 방과후 블록 11 · 시간축 9~22시 자동확장
```

### 중간에 잡은 버그
통합하면서 `escapeHtml`을 `index.js`에서 호출했는데 **그건 `templates.js` 내부 함수**라 500이 났습니다. 검증 중 잡아서 고쳤습니다.

## 2. 🔵 재검수 요청

**http://127.0.0.1:8788/admin** → 회원 관리 → 🧰 개발/QA 도구 → **"QA 계정 + 데모 데이터 한 번에"** 클릭 → `/records` 로 이동

**봐주셨으면 하는 것**
- 채워진 타임라인 — 3열 썸네일 · 학년/학기 섹션 3개(초3 1학기 / 초2 2학기 / 초2 1학기) · 필터 칩 동작

- **360px 모바일** — 이제 데이터가 있으니 의미 있는 확인 가능

## 3. ⚠️ 사장님 지시로 바뀐 것 (중요)

### 라이브 접속 차단됨
사장님 지시로 **workers.dev 서브도메인 노출을 껐습니다.**
- `https://eduthink-site-renderer.dndmotor1.workers.dev` → **404**
- `wrangler deploy`가 아니라 Cloudflare API 설정 변경으로 처리(배포 금지 지시 준수)
- 워커·D1·R2·크론·시크릿은 **전부 보존**. 토글 하나로 즉시 복구 가능
- 크론은 계속 돌아 학사일정 갱신 유지

### 블록1 전체가 기능 플래그로 감싸짐
`FEATURE_RECORDS` — **운영 `false` / 로컬 `true`**

| | OFF(운영) | ON(로컬) |
|---|---|---|
| `/records` `/activities` | **404** | 200 |
| 마이페이지 기록·방과후 메뉴 | 미노출 | 노출 |
| 자녀 등록 이름칸·동의체크 | 미노출 | 노출 |

메뉴만 숨기지 않고 **라우트 자체를 404로 죽였습니다.** 메뉴만 감추면 URL 직접 입력에 미완성 화면이 열립니다.
서버 검증도 조건화했습니다 — 이름·동의는 블록1 추가분이라 OFF면 서버도 요구하지 않습니다(안 그러면 기존 등록 흐름이 막힙니다). OFF 상태로 등록 테스트 통과 확인.

**앞으로 모든 신규 기능이 이 방식입니다**: 플래그 OFF로 배포 → 로컬 완성·검증 → 사장님이 배포+ON 지시할 때만 공개.

## 4. 📮 우체통 일시 중단

**사장님 지시로 우체통 세션을 끕니다.** 감시 루프를 돌리지 않습니다.

- 이 파일에 대한 회신을 주셔도 **제가 자동으로 못 봅니다**
- 사장님이 "우체통 켜" 또는 "회신 확인해" 하시면 그때 읽고 재개합니다
- 로컬 서버 **8788·8789는 계속 켜둡니다** — 검수는 언제든 가능합니다
