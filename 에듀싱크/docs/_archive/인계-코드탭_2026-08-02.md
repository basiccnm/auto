## 🔴 자녀폰 보안 3건 (2026-08-02, 사장님 폰으로 실측하다 발견)
전부 고치고 검증했습니다. **다시 밟기 쉬운 함정이라 남깁니다.**

**(가) 자녀 세션인데 부모 화면이 그려졌다**
카메라를 다녀오면 `#home`으로 튀고 부모 홈이 그대로 떴습니다(체험 남은 날·이용권·설정·서랍까지).
범인은 `visibilitychange` 핸들러 — 5초 넘게 자리를 비우면 무조건 `#home`으로 보냅니다. 카메라가 그 5초를 넘겼습니다.
→ `isChildToken()` 을 만들어 **토큰을 근거로** 게이트합니다. `S.childView`(부모용 미리보기 스위치)는 근거가 못 됩니다.
→ 20개 화면 두드려 새는 곳 0개 확인.

**(나) 자녀폰으로 바꿔도 부모 캐시가 남았다**
`localStorage`에 형제 이름·학교·서랍 썸네일이 그대로 살아 화면에 그려졌습니다.
→ `wipeParentData()` 로 캐시·메모리 사진까지 지우고, 자녀폰은 **자기 자신 한 명만** 알게 했습니다(`eduthink.childMe`).

**(다) 되돌린 미션 사진이 R2에 영원히 남았다**
`revert()`가 `decided_at`을 NULL로 미는데 7일 정리 크론은 `decided_at IS NOT NULL`만 지웁니다.
→ 되돌릴 때 R2 객체도 같이 지웁니다.

**곁다리로 드러난 것** — 자녀 화면의 「급식」은 **서버에서 받은 적이 없었습니다.** 부모 캐시를 보여주고 있었던 겁니다.
캐시를 지우면 사라질 자리라, `child-claim`이 학교 정보를 주고 자녀 토큰에 급식·시간표를 열어 함께 고쳤습니다.
「못 했어요」 되돌리기도 이때 같이 넣었습니다(아이가 잘못 누르면 하루 종일 손도 못 댔음).

# 7. 함정 (실제로 당한 것들)

## 자주 다시 밟는 것
- **`grid-template-columns: 1fr 1fr` 는 min-content 바닥이 있습니다.** 긴 제목이 칸을 밀어
  홈 카드가 화면 밖으로 32px 삐져나갔습니다. `minmax(0, 1fr)` + 자식에 `flex:1; min-width:0`.
- **자녀 데이터가 오기 전에 부른 로더가 빈 배열을 박아버립니다.** `loadMissions`가 그래서
  미션 3개를 영영 안 보여줬습니다. 토큰·자녀가 없으면 **`null`로 두고 다음 그리기에 다시** 부르세요.
- **문자열 id를 D1에 넘기면 조용히 0건 삭제.** `bind()`는 타입을 그대로 보내고, 안 맞으면
  에러가 아니라 «0건 일치»라 `ok:true`가 납니다. 진입점에서 `Number()`.
- **`env` 미전달** — `deleteChildCascade`는 `env.RECORDS` 없으면 R2 삭제를 조용히 건너뜁니다.
- **자녀에 딸린 테이블을 빠뜨리기 쉽습니다.** 판별 기준은 «개인정보처럼 보이는가»가 아니라
  **`child_id`를 들고 있는가**. `orders`만 의도적으로 남깁니다.
- **예외가 나면 JSON이 아니라 HTML 500이 나갑니다.** 앱은 그걸 파싱하다 죽습니다.

## 도구·환경
- **한글이 셸 파이프를 지나면 깨집니다.** `grep`으로 한글을 세면 0이 나옵니다 — node로 문자열 비교하세요.
- **bash heredoc에 JS를 넣으면 따옴표에서 터집니다.** Write 도구로 파일에 쓰세요.
- `wrangler`의 긴 `--command`는 조용히 아무것도 안 합니다. 한 문장씩 + `"success":true`로 판정.
- **삭제 검증은 `--local`로.** `--remote`는 진짜 D1·R2를 지웁니다.
- `.dev.vars` 변경은 서버 재시작이 필요합니다.
- **zip에 한글 파일명이 있으면 `Expand-Archive`가 «Illegal characters in path»로 죽습니다.**
  `[System.IO.Compression.ZipFile]::ExtractToDirectory(zip, dst, [Text.Encoding]::UTF8)` 로 푸세요.
