# 1. 이 앱은 무엇인가

**초등학생 학부모**가 쓰는 앱. 두 가지를 한다.

| 하는 일 | 얼마나 자주 | 성격 |
|---|---|---|
| 학교 정보 확인 (급식·시간표·학사일정) | **하루 여러 번, 10초씩** | 훑어보기 |
| 아이 기록 보관 (상장·통지표·성적표) | 학기당 몇 번, 6년간 쌓임 | 오래 남기기 |

- 데이터는 **NEIS(교육부)** 에서 자동으로 온다. 학교가 우리 앱을 안 써도 된다 — 경쟁 앱(아이엠스쿨·하이클래스)과 다른 점
- 아이 개인정보·사진을 다룬다. **가벼워 보이면 안 된다**
- 자녀 여러 명 전환 가능 (상단 칩)

# 3. 지금 쓰는 색 (이 구조는 유지해야 함)

**테마 6종이 CSS 변수만 갈아끼워 돌아간다.** 색을 하드코딩하면 테마가 깨진다.

```
--bg      바탕
--card    카드/면
--ink     글자
--muted   보조 글자
--line    경계선
--accent  강조 (버튼·선택)
--danger  경고/삭제
```

| 테마 | bg | card | ink | muted | line | accent |
|---|---|---|---|---|---|---|
| 웜그레이(기본) | `#EFEEEC` | `#FFFFFF` | `#2E2C29` | `#8A8781` | `#E3E1DB` | `#C0552F` |
| 아이보리 | `#F6F1EA` | `#FFFFFF` | `#3A2E25` | `#9B8B7B` | `#EFE6DA` | `#D98C5F` |
| 민트 | `#EAF1EC` | `#FFFFFF` | `#26332C` | `#7E948A` | `#DCE7DF` | `#3E8378` |
| 라벤더 | `#EFEDF4` | `#FFFFFF` | `#2C2836` | `#8B849B` | `#E4E0EC` | `#7159A8` |
| 네이비(다크) | `#171C2B` | `#232A3D` | `#E9ECF5` | `#9198B0` | `#2E3550` | `#7C97F0` |
| 차콜(다크) | (다크 계열) | | | | | |

**요청**: 이 7개 변수만으로 6종이 다 성립하게 그려 주세요.
색을 더 필요로 하는 디자인이면 **변수를 늘려서 제안**해 주세요(예: `--ink-2`). 하드코딩은 안 됩니다.

# 4. 반드시 지켜야 할 제약

- **폭 360px 우선.** 실측 368px(갤럭시 Z Fold6 외부화면), 펼치면 707px
- **한글.** 영문보다 길다 — 잘림을 전제로. 예: 서브탭 5개가 368px에서 5px 넘쳐 잘렸었다
- 아이콘 = **Tabler 웹폰트 서브셋**. 새 아이콘을 쓰면 빌드 스크립트를 다시 돌려야 한다(가능하니 자유롭게 쓰되 **목록을 알려 주세요**)
- 사진은 사용자가 찍은 **상장·통지표(세로 긴 종이)** 가 대부분. 가로도 있다
- 하단 대화창(자녀와 주고받기)이 홈에 **고정으로 떠 있다** — 그만큼 자리를 비워야 한다
- 상단 자녀 칩 · 학년→학기 구조 · 잠금(지문) 흐름은 유지

# 5. 우리가 정한 방향 (참고만, 더 좋은 안이면 바꿔도 됨)

**「조용한 서류함」** — 상장·통지표를 다루는 앱이니 알록달록할 이유가 없다.
장식으로 좋아 보이게 하지 말고 **덜어내서** 좋아 보이게.

1. **면을 나누지 않는다** — 카드·그림자로 묶지 말고 여백과 글자 크기로
2. **색은 두 개** — 먹 + 강조 하나. 색으로 뜻을 나누는 건 공휴일(빨강)·오늘(강조)만
3. **사진은 가장자리까지** — 기록 격자 좌우 여백 0, 크게보기 전체화면
4. **글자 네 단**(28/17/15/13) · **간격 여섯 값**(4·8·12·16·24·40) · **모서리 하나**(10px)
5. **설명하지 않는다** — 화면마다 있는 회색 안내문 제거. 안내는 빈 상태 자리에만

닮고 싶은 것: 애플 사진 · 토스 · Things 3
닮으면 안 되는 것: 알록달록한 육아 앱 · 스티커 붙은 학습 앱

# 7. 지금 화면의 문제 — 이대로 두지 말아 주세요

기능을 하나씩 덧붙이며 만들어서 **AI가 만든 티**가 그대로 납니다.
([참고](https://superdesign.dev/blog/how-to-make-ai-ui-look-less-generic) · [카탈로그](https://dev.to/kiwibreaksme/i-catalogued-every-tell-that-makes-a-ui-look-ai-generated-my-own-tool-kept-failing-the-test-n52))

- **파스텔 배경 둥근 사각형 안의 아이콘 9개**(홈) ← AI 티 1순위. 전부 없애 주세요
- **모든 것이 흰 카드** — 위계가 사라짐
- **화면마다 회색 안내문** — 「~해요」 남발
- 이모지 불릿
- 달력이 화면의 41%를 먹는데 칸에서 읽을 수 있는 정보가 없음
- 급식에서 빨간 알레르기 상자가 화면을 지배해 정작 **메뉴가 안 읽힘**
