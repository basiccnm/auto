## 2. 이번에 바뀐 것 — 재검사 대상

### A. 반 선택이 실제 학급수로 제한됨 (이전 QA 지적 #1 수정)
- **경로**: 자녀 등록 페이지(`/register-child?school=<학교>`)
- **확인**:
  1. 학년을 **고르기 전** → 반 드롭다운이 **"학년 먼저 선택"** 으로 **비활성**이어야 함
  2. 학년을 고르면 → **그 학교·그 학년의 실제 학급수만큼만** 노출
- **기대값 예시**: 서울숭미초 2학년=3반, 3학년=4반, 5학년=5반 / 경기초 전학년 4반 / 경복초 5반 / 신일고 10반
- **버그 판정**: **15반이 나오면 버그**
- **참고**: 자녀 관리 → 자녀 수정 → "진급하기" 폼의 반 선택도 동일하게 적용됨(같이 봐주세요)
- **원인이었던 것**: 학년 미선택 상태에서 폴백 15가 뜨던 것. 데이터·로직은 원래 정상이었음

### B. 학교 일정 강조 적용 (이전 QA 지적 #2 수정)
- **경로**: 학교 → 일정 탭 (달력)
- **확인**:
  - **학교 자체 일정**(방학식·운동회·수영교실 등) → **노란 별표(★) + 셀 빨간 테두리**
  - **공휴일**(제헌절 등) → **빨간 글씨** (테두리 아님 — 이렇게 구분됩니다)
  - 아무것도 없는 날 → 회색 테두리, ★ 없음
  - 오늘 → 초록 테두리
  - 달력 아래 **범례**에도 "★ 학교 일정 / 내 일정 / 공휴일(빨간 글씨)" 표기
- **기대값 예시**: 경기초 7월 → 1일 ★수영교실(4학년), 7일 ★수학경시대회, 15일 ★여름방학식, 20~24일 ★오케스트라 여름 캠프

### C. [신규] 시간표 없는 학교도 직접 채우기
- **경로**: **⑤번 계정** → **경기초 6-1(QA셋중셋째)** → 시간표 탭
- **배경**: 경기초는 학교가 NEIS에 시간표를 안 올립니다. 예전엔 "제공되지 않아요" 안내만 뜨고 아무것도 못 했는데, 이제 **빈 격자를 깔아 직접 채울 수 있습니다**.
- **확인**:
  1. **빈 격자 30칸**(월~금 × 6교시)이 깔려 있어야 함 — 초등 3~6학년=6교시, 1~2학년=5교시, 중·고=7교시
  2. 상단 안내: *"이 학교는 시간표를 공개하지 않아요. 아래 빈 칸을 눌러 직접 채워 넣으시면 돼요."*
  3. **"✏️ 시간표 수정"** → 빈 칸 눌러 과목 입력 → **저장 후 새로고침해도 유지**
  4. 채우고 나면 위 안내 배너는 자동으로 사라짐
  5. 맨 아래 **"🔄 원래대로 초기화"** → 입력분만 지워지고 다시 빈 격자로
- **대비 확인**: 같은 ⑤번 계정의 **숭미초 5-2 / 경복초 4-2**는 시간표가 **채워져 있어야** 정상

### D. 시간표 편집 (이전에 확인 못 했던 것 — 이제 가능)
- **배경**: 이전 QA 때 자녀가 전부 경기초(시간표 미제공)라 편집을 볼 수 없었습니다. 지금은 자녀를 **숭미초** 등으로 옮겨 확인 가능합니다.
- **경로**: ③④⑤ 계정 → **숭미초 자녀** → 시간표 탭
- **확인**:
  - 요일(월~금) 기반 격자로 표시됨 (날짜 없음 — 매주 반복되는 고정 시간표라 정상)
  - "✏️ 시간표 수정" → 과목 칸 눌러 변경 → 저장, **그 요일에 매주 반영**
  - 교시 칸 눌러 시간 변경 / 점심시간 변경
  - **하교 후 개인일정**(학원·방과후) 칸 입력 → **나만 보임**
  - "🔄 원래대로 초기화" → 바꾼 과목·시간 지워지고 원본 복귀
