## C. 앱 — APK 재빌드 (🔴 이게 있어야 화면이 새것이 된다)

이 앱은 화면 파일을 **APK 안에 넣어** 나간다(웹뷰지만 서버에서 받아오지 않는다).
그래서 A·B 만 하면 **서버는 새것인데 화면이 옛것**이라 상점·리롤 버튼 자체가 안 보인다.

> ✅ **자산 동기화는 이미 해 뒀다**(2026-08-07). `app/android/.../assets/public/` 의
> `app.js`·`style.css`·`themes`·`fonts` 가 `app/www` 와 **바이트 단위로 같다**(확인함).
> PC 에서는 `git pull` 하고 **빌드만** 하면 된다.

```bash
cd C:\Users\hardb\Desktop\블로그수입관련\에듀싱크
git pull origin claude/status-md-reading-gkoeee

export JAVA_HOME="/c/Program Files/Android/Android Studio/jbr"   # ⚠ 기본 Java 8 로는 실패한다
cd app/android && ./gradlew assembleDebug
```

⚠ APK 는 프로젝트 안이 아니라 **`%LOCALAPPDATA%\eduthink-build\android\app\outputs\apk\debug\`**
  에 떨어진다(`android/build.gradle` 29행이 buildDir 를 밖으로 뺐다). 거기서 복사해 온다.

### 에뮬(LDPlayer)에 넣기
```bash
adb devices                          # 안 보이면 LDPlayer 설정에서 «ADB 디버깅» 켜기
adb install -r <위 경로>\app-debug.apk
```

### ⚡ 화면만 자주 고칠 때 — 재빌드 없이 (검수 중에만)
`app/capacitor.config.json` 에 `server` 블록을 넣으면 APK 가 화면을 **PC 에서** 불러온다.
고칠 때마다 새로고침만 하면 된다.
```json
{ "server": { "url": "http://10.0.2.2:8789", "cleartext": true } }
```
- 화면 서버: `app\목업서버-시작.bat` (포트 8789)
- `10.0.2.2` = 에뮬에서 본 «PC 자신». LDPlayer 는 `10.0.2.2` 또는 PC 의 사설 IP
- ⛔ **배포 전 이 블록을 반드시 지운다.** 안 지우면 출시본이 사용자 PC 를 찾는다
- ⚠ 데이터(API_BASE)는 그대로 실서버로 간다 — 그래서 A·B 는 **여전히 필요하다**
