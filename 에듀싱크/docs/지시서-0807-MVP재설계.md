## §0 개발 착수 전 5대 기술 결합·충돌 조정 (Architecture Decisions)

1. **아키텍처** — 번들러 없는 `app.js`/`templates.js` 구조를 **그대로 유지**한다.
   React(.tsx) 전환 안 한다. 검증된 **18종 테마·홈 v4 자산을 전량 보존**하고 기능만 얹는다.
2. **모듈 분리 & 멀티 앱 릴리스**
   - **[모듈 A] 학교 정보 엔진** — NEIS 급식·시간표·학사일정 (국내 학부모 유입 훅)
   - **[모듈 B] 자녀 습관 OS 코어** — 2단계 보상 검증 · 하이브리드 미션 · 별도장 상점 ·
     아이 모드 PIN · 칭찬 리액션 → **독립 모듈화**(글로벌 단독/통합 릴리스 지원)
   - **[통합 허브] '오늘' 대시보드** — 두 모듈 상태를 합성해 렌더링
   - 릴리스 2종: 통합 앱[우리아이학교정보] / 모듈 B 단독 앱[우리아이습관OS·별도장상점(가칭)]
3. **요금제 정본** — **1자녀 6,900원 / 패밀리(2~3자녀) 12,900원.**
   서버의 옛 차등가격(2,900/2,000/1,500)은 **즉시 지운다.**
4. **결제 경로** — **인앱결제(IAP)가 정본.** 스토어 심사 방어 우선. DB 는 `payment_channel` 컬럼만 유지
5. **DB 표 이름 충돌 방지** — 이용권 `orders` 와 구분해 보상 결제는 **`reward_orders`**
6. **디바이스 대응** — 저학년=부모폰 공유([아이 모드] 토글 + 4자리 PIN, `accounts.owner_token` 연동) /
   고학년=자녀폰 전용 토큰

## §1 정체성 · 무광고 · 체험

- **정체성** — AI 감시가 아니라 **«2단계 보상 검증»으로 부모-자녀 신뢰를 잇는 실물 경제 기반 생활 OS**
- **1.2 100% 무광고** — 앱·웹 전체에서 애드센스·애드핏 등 **상업 광고 전면 제거**
- **1.3 1주일 무제한 무료 체험** — 가입 시 전 기능 조건 없이 1주일
  ⚠ 현재 코드는 **2주**다. 요금제 확정 때 같이 정한다(값의 문제이지 칸의 문제가 아니다)

## §2 요금제 · 결제

- 1자녀 **월 6,900원**(`child_limit=1`, 모바일 전용) / 패밀리 **월 12,900원**(`child_limit=3`, PC 대시보드 포함, 주력)
- **정가 앵커링** — 13,800→6,900 / 25,800→12,900 «50% 특별 출시 할인»
- **2.4 FOMO** — 1년 차 유지 후 «할인 축소 예정» 공지 → 직전에 연간 선결제 유도

## §3 2단계 보상 검증 프로그램 (Rule-Set)

- **[1차] 즉시 지급** — 공부: 시작~끝 **페이지 숫자 입력** → 별도장 1개 즉시 /
  독서: **20분 타이머 + 독서록 사진** → 즉시 지급
- **[2차] 사후 보너스** — 부모가 저녁에 채점 상태·독서록 확인 후 **[보너스 지급]** → 보너스 충전
  - 학습 효과: «대충 하면 기본 1개, 정성껏 하면 보너스까지» 를 체득시켜 자발적 정직성 형성
- **규칙** — 문제집 기본 최소 5장(10p, 부모 설정 가능) · 독서 20분+사진은 **일간 필수 퀘스트** ·
  **완독 보너스 레이드** · **거짓 인증 적발 시 그날 모든 보상 몰수**(시스템적 동의 처리)

## §4 화면 스펙 (단일 워커 `eduthink-site-renderer` · 반응형 원소스)

- 비로그인=랜딩(가치·50% 할인·체험 신청) / 360px=미션판·상점·아이모드 / 1024px+=3컬럼 대시보드

**① 실시간 상태 전광판** — [모듈 A `schedules`] + [모듈 B 미션 일정]을 **서버 시간과 매칭해 합성**.
  상단 88px 일러스트 영역 + '오늘' 카드. 상태가 [공부/숙제 중]이면 **20분 타이머 카드와 자동 연동**

**② 하이브리드 미션 세트 & 🎲 리롤** — 1세트 3개 =
  **고정 1**(필수 습관) + **추천 1**(미션 155종에서 `band`(low/mid/high)·`season` 자동 추출) +
  **부모 커스텀 1**(`parent_mission_templates`).
  `season='vacation'` 으로 **방학에도 365일 유지**.
  **🎲 리롤 1일 1회** — 카드 상단 버튼, 실수 방지 확인 모달(토스트/시트).
  체크박스 미션 외 **20분 타이머 카드**로 체류 시간 확보

**③ 실물 경제 별도장 상점** — 미션 세트 완주 시 별도장 충전 /
  부모가 **진열대 항목(미디어·게임·현금)과 주간·월간 상한**을 설정하는 폼 /
  아이가 직접 결제 → **결제 즉시 부모 앱으로 영수증 푸시**

**④ 아이 모드 + 4자리 PIN** — 상단 토글. 진입 시 **드로어·설정을 숨기고** 미션판/상점만 노출.
  복귀는 **4자리 키패드 PIN 모달** — ⛔ 브라우저 `alert` 금지

**⑤ 실시간 칭찬 리액션** — 완주 알림 수신 시 부모가 **1초 만에** 스티커(👍/❤️) 선택 →
  아이 화면에 **대형 스티커 팝업 + 별도장 수령 축하 모션**

## §6 PC 웹 대시보드 (1024px+ 3컬럼)

좌=자녀 스위처+전광판 / 중앙=미션 세트·타이머+상점 진열대 / 우=칭찬 스티커+일간 달력·아이 흔적

## §7 유료 출시 전 필수 점검

1. **푸터 법적 정보** — 대표자명·사업장 주소·고객센터 번호·통신판매업 신고번호
2. **`wrangler.toml` `DEV_TOOLS` → `"false"`** (모의 결제 공짜 이용권·`/dev/login-as` 차단)
3. **인앱 결제 연동** — 결제 완료 시 `orders`/`children` 실시간 동기화

## §8 D1 마이그레이션 (정본)

표 6개 — `parent_mission_templates` · `store_items` · `reward_orders` · `child_mode_config` ·
`reactions` · `mission_verifications`. 전부 `child_id INTEGER REFERENCES children(id) ON DELETE CASCADE`.
기존 표 확장 — `orders.payment_channel`(기본 `'inapp'`) · `orders.child_limit`(기본 1).

> ⚠️ **지시서 초안의 `ALTER TABLE children ADD COLUMN trial_ends_at` 은 넣지 않았다.**
> `children.trial_expires_at` 이 이미 있고 **코드 45곳이 쓴다.** 체험 만료일이 두 칸이 되면
> 어느 쪽이 진짜인지 아무도 모르게 된다(2026-08-07 `e30c620` 에서 제거).

## §9 파일 구조

```
modules/school_info/   [모듈 A] 급식·시간표·학사일정 (국내 전용)
modules/habit_os/      [모듈 B] 2단계 보상·미션 세트·상점·아이 모드 (단독 스핀오프 대상)
templates.js           A+B 를 '오늘' 대시보드로 합성 렌더링
app.js                 뷰 컨트롤러 · 2단계 검증 핸들러 · PIN 잠금 · 인앱결제
```

## §10 UI/UX 품질 규칙

1. **WCAG** — 다크 모드 텍스트 대비 **4.5:1 이상** 엄격 유지
2. ⛔ **브라우저 `alert` 금지** — 경고·지침·PIN 전부 앱 내 토스트/시트로
3. **360px 모바일 / 1024px+ PC** 반응형 그리드
