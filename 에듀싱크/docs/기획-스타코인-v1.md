## 한 줄 정의
**현실 미션 게임 앱.** 부모는 잔소리 대신 퀘스트를 걸고 승인만 한다. 아이는 미션을 깨서
스타코인을 벌고, 모아서 큰 것을 산다 — 어른이 노동으로 버는 것처럼.
아바타는 없다 — **아이 본인이 캐릭터다.** 잔소리가 50%만 줄어도 부모에겐 대성공.

## 01 코어 루프 (아이의 하루)
아침 세트(등교 전 마감) → 학교 정보 미션 → 방과후 학습 미션 → 데일리 퀴즈 10문제 → 저녁 세트 → 코인 적립 → 목표 게이지
- **한 번에 다 안 보여준다** — 지금 시간대 것만. 하루 종일 열 이유를 만든다
- **실패가 존재한다** — 아침 세트는 등교 전까지 확인 안 누르면 실패. 등교 시간은 우리가 안다(우리만 가능)
- **세트 = 묶음 + 낱개 동시 지급** — 개당 +1, 완주 보너스. 저학년은 순서 잠금

## 02 스타코인 경제 — 리밋이 심장
「미션 1개=★1, 하루 3개」 폐기. 큰 목표가 성립하려면 하루 회수량이 커야 한다.
**하루 리밋이 화폐 가치를 정하고 → 상품 가격표를 정한다. 리밋은 서버가 센다.**

| 수입원 | 코인 |
|---|---|
| 아침 세트(개당1+완주2) | 최대 5 |
| 학교 정보 미션 | 최대 5 |
| 데일리 퀴즈(정답+1, 만점+5) | 최대 15 |
| 학습 미션(독서·문제집) | 최대 6 |
| 저녁 세트 | 최대 5 |
| 부모 커스텀 | 최대 4 |
| **벌 수 있는 총량** | **~40** |
| **하루 리밋 🔴** | **30 (제안)** |

40 벌 수 있는데 리밋 30 → **아이가 무엇으로 채울지 고른다. 선택이 곧 게임.**

가격 앵커(예시 — 정하는 건 부모): 게임1시간 10 · 간식 10~20 · 햄버거세트 30 ·
장난감 300 · 대형 1,000 · 초대형(자전거·게임기) 10,000(1년 — 6년짜리 게임이니까)

## 03 미션 4갈래
| 갈래 | 내는 사람 | 검증 |
|---|---|---|
| 습관 미션 | 우리 카탈로그(155)에서 부모가 고름 | 완료 버튼 — 부모 개입 0 |
| 학습 미션 | 부모 | 즉시 소액 → 부모 3초 확인 → 보너스 |
| 학교 정보 미션 | 시스템 | 서버 자동(급식은 실제 메뉴 대조) |
| 데일리 퀴즈 | 시스템 | 서버 채점 — 못 속임 |
- 카탈로그 분류 전문화: **예절/교육/인성/특기/학교정보** — 부모가 보고 고른다. 없으면 커스텀
- **보상 내용은 절대 우리가 정하지 않는다.** 틀은 우리, 내용은 그 집
- 학교 정보 미션 = 아이는 개꿀, 부모는 못 듣던 학교의 하루 + 리포트 재료. **둘 다 이득인 유일한 구간**
- ✅ 재료 있음: childmealrate/childfriend/childsubject 화면 + meal_ratings/kid_friends/subject_log/report

## 04 데일리 퀴즈 — 실력이 코인이 되는 곳
- 4지선다 10문제 · 문제당 5초 · 하루 1세트 · 정답 +1 · 만점 +5 · 틀린 문제는 답 공개(코인 없음)
- 찍으면 기대값 2.5 — 아는 애와 찍는 애가 코인으로 갈린다
- 8분야: 국어·수학·과학·나라·속담·상식·스포츠·연예. 분야당 60 × 8 = **480문제로 시작**(연예·스포츠는 시즌팩 갱신)
- ＋제안: **분야별 박사 뱃지**(나라박사·속담박사) — 정답률 자동, 개발비 0
- 🔴 학년대 난이도 구분 · 연예 범위 · 저학년 8초 여부

## 05 꼼수 방어 («안 하고 누르는 애»)
- 퀴즈·학교정보: **구조적으로 못 속임**(서버가 답을 안다. 급식은 NEIS 대조)
- 학습형: 1차 즉시 소액 → 진짜는 부모 2차 보너스 — **정직이 이득인 구조**
- 부모 «아니오» → 보너스 0 + 1차 회수. 반복 적발만 몰수(대화.txt 규칙, 최후 수단)
- 습관형은 안 감시한다 — 이불 개기 속이면 집에서 들킨다. 그건 그 집의 일

## 06 상점 — 보상 + 수익이 한 화면
- **① 우리집 진열대**: 부모가 정함(무엇·몇 코인·주/월 상한) → 아이 «바꾸기» → 티켓 → «바꿔줬어요»
- **② 추천 상품(레퍼럴)**: 진열대 만드는 순간 = 구매 결심 끝난 자리. 책·문제집·기프트카드·악기.
  **부모가 직접 결제, 우리는 중간 레퍼럴만** — 재고·배송·CS 안 짐. 쿠팡 파트너스로 1단계 즉시
- 책이 1호 카테고리(독서 데이터→추천 근거, 죄책감 없는 소비, 맘카페 명분)
- ✅ 실물은 인앱결제 대상 아님(수수료 0) · 🔴 아이 화면에 원화 절대 금지(★만)
- ＋제안: **목표 게이지** — 아이가 건 큰 상품 진행률 바(★2,340/10,000)가 홈에 산다

## 07 경쟁·이벤트
- **월간 TOP10 — 우리가 직접 보상.** 리밋 덕에 공정(순위=꾸준함). 부모 부담 0
- 전체 랭킹판은 아이에게 안 보임(상위 10만 발표) · 상시 비교는 «지난달의 나»
- 문안 주의: 추첨 아님 — **성취 기준 보상**(구글 아동 경품 규제)
- ＋제안: 스트릭 🔥 · 방학 시즌 이벤트(학사일정으로 자동 감지)

## 08 아이 화면 구체화 — 모듈 B의 얼굴
**이 화면 묶음이 그대로 글로벌 단독 앱이 된다**(모듈화를 별도로 하는 이유).
학교 정보 미션만 모듈 A 데이터를 참조 — 그 연결 하나만 인터페이스로 끊는다.
- **홈 = 내 상태창**: 이름+칭호(누적 코인 구간) · 지갑 크게 + 오늘 23/30 리밋 게이지 ·
  목표 게이지 · 스트릭 🔥 · **현재 시간대 미션만**+마감 카운트다운 · 퀴즈 입장(안 했으면 반짝)
- **퀴즈 화면**: 유일하게 게임처럼 연출(5초 링 타이머·코인 날아가는 결과 연출). 다른 데는 조용히
- **미션 화면**: 세트 진행률 33→66→100 · 학습 입력은 고정 폼(독서=타이머+제목+한 줄 / 문제집=과목·시작p·끝p)
- **꾸미기**: 테마 18종(✅ 이미 있음) · 박사 뱃지·칭호(성취로만, P2) · 프로필 카드(P2) ·
  한정 테마 코인 해금 🔴 보류(코인=현실 보상 원칙이 흐려질 수 있음)

## 09 부모 화면 — 판사, 그리고 관객
손대는 곳 셋: ①세팅(가끔) ②학습 3초 확인 ③티켓 «바꿔줬어요» + 1초 칭찬 스티커(👍❤️👏).
학교 정보 답 + 월간 리포트 = **잔소리 없이 아이의 하루를 아는 것**(잔류 이유).

## 10 글로벌 — 마이다이어리 모델
앱 하나 + **언어팩**으로 전 세계. 코드는 하나, 언어팩(UI) + 로컬 DB(미션 155·퀴즈 480 = 곧 언어팩)만
갈아끼우면 나라가 하나 는다. 모듈 B 단독 앱, 학년군은 «최대 학년» 파라미터.
관문은 법(COPPA·GDPR-K·Families) — 국내 MVP 후.

## 10.5 가격 — 비싸게 보이되 싸게 시작
비교 대상은 학습지·습관 코칭(월 3~10만). **정가 앵커를 높이고**(예 19,800) 출시 할인(6,900)으로 시작,
기능 완성되면 **신규만 인상**. 실제 마진은 레퍼럴이 클 수 있음 — 구독은 진입 장벽만 아니면 됨.
🔴 정가 앵커 · 출시가 · 연간 결제
