1. 홈
· 위 = 시계 그림판, 아래 = 「오늘」 서랍 5칸(일정·급식·준비물·방과후·미션)
· 칸을 누르면 그 화면으로 이동. 앞판 높이는 화면이 커도 일정(80px 근처), 남는 공간은 칸 사이 간격으로 벌어짐
· 하단 바: 달력 · ＋(추가) · 미션

2. ☰ 드로어
· 프로필 카드에 학교/이용권/자녀폰 상태
· 자녀가 2명 이상이면 카드 아래 「첫째 ▾ 자녀 전환」 줄 하나 → 누르면 팝업 시트가 뜨고,
  시트 안에서 아이를 고르면 전환됨(몇 명이든 시트 안에서 스크롤). ＋ 자녀 추가도 시트 안에 있음

3. 달력
· 요일 머리와 날짜가 같은 요일 줄에 섬 (월요일 시작 설정이면 월부터)
· 빨간 날 = 진짜 일요일과 공휴일만 (예: 8/15 광복절)
· 날짜 꾹 누르면 일정 넣기 메뉴, 줄 누르면 그날 열기
· 메뉴 닫히는 손가락이 밑의 날짜를 눌러 새 창이 열리면 안 됨(유령클릭 방지 있음)

4. 급식  ★ 아코디언으로 바꿈(2026-08-13)
· 주간만 보임(월간 토글 없앰 — 30줄 스크롤 방지). 지난 급식은 하단 「메뉴 검색」으로
· 날짜 줄이 접혀 있고 그 옆에 그날 반찬이 한 줄 요약으로 붙음 → 5일이 한 화면에 들어옴
· 날짜 줄을 누르면 그날만 펼쳐짐(한 번 더 누르면 닫힘). 기본은 「오늘」 하나만 펼침 —
  방학처럼 오늘 급식이 없으면 맨 첫 날(개학일)이 펼쳐짐
· 왼쪽 위 「전체 펼치기 / 전체 닫기」로 한꺼번에. 실측: 전부 펼침 1248px → 전부 접음 248px
· 알림 스위치(오른쪽)를 눌러도 카드가 펼쳐지지 않음
· 검색 중에는 걸린 날이 전부 펼쳐짐(찾으러 들어온 것이라)
· 알레르기 고르기를 켜면 해당 메뉴에 표시

5. 방과후 시간표
· 빈 칸 누르면 새로 넣기 / 블록 누르면 메뉴(이동·수정·삭제)
· 「이동」 누르면 = 이동 모드(토스트: 블록을 끌어서 옮기세요). 이때 블록을 끌면 이동, 살짝 탭하면 이동 모드 유지
· ⚠ 「이동」을 눌렀는데 새 일정/수정 폼이 열리면 버그(유령클릭) — 이번에 보초 추가했음
· 이동 모드 취소 = 뒤로가기 한 번

6. 미션 (부모) — 듀오링고 테마 (미션 세계는 부모도 듀오링고)
· 맨 위: 오늘의 길 리본 + 양끝 −/＋ = 하루 별 라인(예산). 오늘 몇 개 받았는지 리본이 참
· 오늘 준 미션 카드: 줄 누르면 상세. 완료는 제자리에서 ✓ (목록이 재정렬되지 않음)
· 「확인해 주세요」: 아이가 낸 것 있을 때만 위에 뜸 — ★1~3 또는 확인만
· 타일: 🎲바꾸기(하루 1번) · 🎯고르기 · ✏️만들기 / 오늘 한 것 · 추가 증정 / 칭찬 보내기 · 이번 달
· 맨 아래 초록 버튼 = 아이 화면으로 보기(미리보기)
· ‹(왼쪽 위) = 홈(A모듈)으로 (부모는 항상 홈)

7. 미션 하나 (부모)
· 큰 아이콘 + 이름 + 칩(영역·분·★) + 「왜 이 미션인가요」 + 지난 이레 도장판
· 아직 안 한 것: 이것만 바꾸기(비슷한 별로 교체) / 오늘은 빼기 / 직접 고르기
  — 바꿀 후보가 없으면 「바꿀 만한 미션이 더 없어요」 안내가 정상
· 확인 대기: 사진(있으면) + 잘했어! 도장 찍기 / 서랍에 보관 / 다시 해볼까?
· 완료·쉬어감: 다시 해볼까? / 다시 줘볼까?

8. 미션 고르기
· 학년대 탭(저·중·고) → 추천 3개 → 영역별 목록
· 줄 누르면 담김/빼짐(오른쪽 ＋ ↔ 담김). 하루 최대 8개(서버 값) — 3개 제한 아님
· 맨 아래 「n개 담기」 누르면 오늘 미션이 그걸로 확정(이미 한 것은 안 지워짐)
· 전부 사진 미션으로만 담으면 거절됨(눌러서 보고형 하나 필요) — 안내문 뜸

9. 만들기 (우리 집 미션)
· 이름 적고 → 분(1~30) · 확인 방법(눌러서/사진/하루끝) 고르고 → 「넣기」
· 미션 화면의 「만들기」로 만들면: 카탈로그에 등록 + **오늘 목록에도 바로 들어감**
  (토스트 「오늘 미션에 넣었어요」) — 2026-08-13 검수에서 안 들어가던 것 고침
· 고르기 화면 안의 「우리 집 미션 만들기」로 만들면: 담기 목록에 체크만 되고,
  하단 「n개 담기」를 눌러야 오늘 것이 됨 (토스트 「우리 집 미션을 만들었어요」)
· 만든 것은 고르기 목록에 「우리 집」 딱지로 계속 남음 (최대 20개)

10. 오늘 아이가 한 것
· 아침/학교/방과후/오늘의미션 소속별로, 그 아래 미션 이름이 붙음
· 한 것 = 「완료 ★n」, 확인 기다리는 것 = 누르면 확인 화면으로, 안 한 것 = 「아직 · ★n」

11. 추가 증정 ＋1
· 오늘 완료된 미션마다 ＋1 버튼. 누르면 그 줄만 잠기고 즉시 「＋1 줬어요」(다른 줄은 계속 눌림)
· 한 미션에 한 번만. 하루 상한 넘으면 안 들어감(안내)

12. 상점 (부모)
· 진열대에 올리기(이름·별값·주/월 제한) / 진열대 고치기(내리기) / 내 티켓(바꿔줬어요 처리)

13. 학교정보  ★ 웹에 있던 값 전부 이식(2026-08-13)
· 주소 · 「공립 · 남녀공학 · 1981년 개교 · ○○교육지원청」 · 전화(누르면 걸림) · 홈페이지
· 숫자 4칸: 전교생 · 학급 · 교원 · 개교 / 그 아래 2칸: 연간 수업일수 · 주당 총 수업시수
· 한 줄 요약: 남 241 · 여 246 · 방과후 40개 프로그램 (참여 288명) · 돌봄교실 운영
· 학년별 현황(접이): 학년 / 학급수 + 한 반 평균 인원 / 인원 + 남녀, 맨 밑에 공시 회차
· ⚠ 이 값들은 **서버 배포 후에** 실제로 채워짐(배포 보류 중) — 지금 폰에는 빈 채로 보일 수 있음
· 웹에만 남긴 것: 「월별 일정 & 다이어리」 유도 카드(앱은 달력이 따로 있음)

14. 테마
· 첫 타일 = 「기본 파랑」(그림 없음), 나머지 그림 테마. 골라놓고 「사용」을 눌러야 적용

15. 회원가입
· 휴대폰 필수. 필수 칸이 다 차기 전엔 가입 버튼이 잠김

16. 자녀폰 연결
· 내정보/드로어에서 아이별 연결 코드 발급(6자리) → 자녀폰 「자녀폰 연결」에 입력

16-2. 서류 (체험학습 신청서·보고서 / 결석신고서 / 상담신청서)  ★ 성명 고칠 수 있게 함(2026-08-13)

17. 아이 홈 (연결 직후엔 「내 화면 고르기」가 먼저 한 번)
· 오늘의 길 리본(오늘 받은 별/라인) + 아침·학교·방과후 타일 + 엄마아빠 퀘스트 카드 + 상점 줄
· ‹ 없음(여기가 홈)

18. 오늘의 미션 (아이)
· 아침/방과후 카드에 줄로. 줄을 누르면 = 상세가 열림 (바로 완료되지 않음 — 오탭 방지)
· 상세에서 큰 「다 했어요!」 → 그 자리에서 완료 표시 + 별 + 축하 (즉시 반영)
  ⚠ 통신이 느린 순간엔 축하 후 서버 확정까지 1~2초. 「이미 처리된」이면 자동으로 서버 상태에 맞춤
· 사진 미션 줄 → 상세 → 「📷 사진 찍기」 → 카메라 화면
· 학교 미션(급식·누구랑·수업): 급식/수업이 없는 날은 그 칸이 흐려지고 「방학중」 — 못 누름(정상)
· ‹ = 아이 홈으로

19. 퀴즈 (오늘의 미션 ⚔️)
· 시작하기 → 문제 → 보기 누르면 바로 채점 표시 → 오른쪽 위 ✕ = 중간에 나가기
· 다시 들어오면 「이어서 하기 ▶ (n번부터)」 — 푼 문제는 날아가지 않음
· 배경: 시작 전 = 고른 테마 색, 푸는 중 = 보스전 주황(전 테마 공통·의도된 것)

20. 상점 (아이)
· 부모가 올린 보상만 보임. 「바꾸기」 → 별 차감 + 티켓 발급
· 진열대 비었으면 「아직 준비된 보상이 없어요 — 엄마아빠에게 부탁해봐!」 (부모 버튼 안 보임)
