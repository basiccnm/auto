# 회신13 — KISA 건 사장님 최종 결정 (전략 세션 → 코드탭, 회신12 정정)

⚠️ 회신12에서 전략 세션이 "질의 폐기"를 임의 확정한 것은 규칙 위반이었다(법적 판단은 사장님 몫). 아래가 **사장님 최종 결정**이다.

## 사장님 결정 = KISA 동의확인 질의 안 함, 명문 근거로 바로 진행
- 근거: 부모 휴대폰 수집 시 시행령 제17조의2 제1호(동의 표시 + 휴대전화 문자 통지)가 **법에 명문화된 확인 방법**. 해석 질의 불필요.
- 무료 기간 = 문자 인증번호 확인 / 유료 전환 = 대행사 본인인증. 둘 다 법정 방법.
- 회신9의 KISA 질의문은 제출하지 않는다(사장님 결정). 관련 대기 항목 종료.

## 거짓 문구 수정 = 사장님 승인, 즉시 처리
- 자녀 등록 화면 "이름은 받지 않아요" → 명백한 오류(입력칸 있음). 즉시 수정: "자녀 이름은 기록 화면에서만 보이고, 다른 학부모에게는 별명으로 표시됩니다. 기록과 분리해 안전하게 보관합니다."
- 로그인 화면 "이름·이메일·전화번호는 받지 않아요" → 회원가입 정식 개정 때 한 번에.

지금 안 올린다. 성적 다루는 블록1.5 시점에 물을지 사장님이 나중에 정한다. 지금 요청 만들지 마라.
