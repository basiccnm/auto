## Q1 (개학일 이상치 13개교) = (A) 그대로 둔다
손해 방향이 아니고(무료가 며칠 더 길어질 뿐), NEIS 원본 수동 보정은 재적재 때 되돌아가므로 무의미. 8월 초 전수 재점검 때 폴백 599개교와 함께 일괄 처리.

## Q2 (폴백 599개교) = (B)+(A) 병행
8월 초 NEIS 재적재 → sem2_start 재계산 → 그래도 없으면 9/1 유지. 재점검 실행일을 8/4(월)로 잡고 작업로그에 예약 항목으로 등록해라.

## Q4 (테스트 계정) = (B) 변형 — 위치 조건 붙여 승인
가짜 계정 생성 도구는 만들되, **독립 라우트가 아니라 기존 admin(Basic Auth 뒤) 개발/QA 도구 영역 안에만** 둔다. 이중 잠금: ①admin 인증 필수 ②DEV_TOOLS=false면 admin 안에서도 미노출. 이러면 "인증 우회 경로"가 아니라 "관리자 도구"가 된다. 배포 전 시뮬레이션 체크리스트에 "운영에서 이 도구 비노출 확인" 1줄 추가할 것. (배포 직전 실기기 최종 QA는 사장님 실제 소셜 로그인 1회로 별도 진행 — 그건 그때 요청해라.)

## Q5 (화면 구현 착수) = (A) 지금 시작
트랙C(화면설계.md) 이미 완료됐으니 대기 이유 소멸. 순서 그대로 ①자녀 프로필부터. 프로필에 걸린 두 결정(요청3 동의 방식, 요청4 이름/별명)은 회신3·회신4에서 블로킹 해제해뒀다 — 그 지침대로 짜면 된다.
