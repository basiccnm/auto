## 1. 🔴 검수가 두 번 막힌 원인을 찾았습니다

회신11에 이렇게 쓰셨습니다.
> "로그인된 QA 계정에 데이터가 없어 3열 썸네일 그리드·일정 블록 배치를 실물로 못 봤다."

**원인**: `dev-account`(로그인 상태로 만들기) 버튼이 **쿠키가 없으면 매번 새 빈 계정을 만듭니다.** 검수하실 때마다 데이터가 하나도 없는 새 계정으로 들어가신 겁니다. 제가 만든 테스트 데이터는 제 브라우저의 다른 `owner_token`에 붙어 있었고요.

실제로 DB에 QA 계정이 **5개** 쌓여 있고 대부분 비어 있습니다.

### 해결 — "데모 데이터 심기(QA)" 버튼 추가

`/admin` → 회원 관리 → **🧰 개발/QA 보조 도구** → **"데모 데이터 심기(QA)"**

지금 로그인된 계정에 한 번에 채웁니다:
| 항목 | 내용 |
|---|---|
| 자녀 | 첫째 (김서준 · 서울숭미초 3-1) — 없을 때만 생성 |
| 기록 | **7건** — 초3 1학기(상장·통지표·활동) / 초2 2학기(상장·성적표) / 초2 1학기(자격증·기타) |
| 방과후 | **4건** — 수학학원(월·수) · 영어학원(화·목) · 피아노(금) · **축구교실(토 9시)** |

**두 개 학기에 걸쳐** 심어서 타임라인 **그룹핑**이 보이고, 종류를 6가지로 흩어서 **필터 칩**이 실제로 동작하는 게 보입니다. 축구교실은 기본 축(14~22시) 밖이라 **시간축 자동 확장**이 시연됩니다.

이미 데이터가 있으면 건드리지 않습니다(중복 방지). admin Basic Auth + `DEV_TOOLS` 이중 잠금 뒤에만 있습니다.

**검증 완료**: 새 계정에 심고 확인 — 썸네일 7개 · 학년/학기 섹션 3개 · 방과후 블록 11개 · 축 확장 "9~22시".

## 2. 회신14 UX 개선 반영

빈 상태 카드 안에 **"＋ 첫 기록 올리기"** 주 버튼을 넣었습니다. 누르면 FAB와 같은 업로드 플로우가 열립니다.

- 기록이 **1건이라도 있으면 이 버튼은 사라지고** FAB만 남습니다(중복 방지 — 쌓인 뒤엔 FAB가 맞다는 지시대로)
- 검색·필터 결과가 없는 빈 상태에는 안 나옵니다("찾는 기록이 없어요"에 업로드 버튼은 문맥에 안 맞음)
- 한도 초과 상태에도 안 나옵니다(눌러도 막히니 헛걸음)
- 버튼 아래 "사진을 고르고 종류만 누르면 끝이에요" 한 줄 추가

**방과후 빈 상태 확인** — 지시하신 대로 봤습니다. 본문에 "＋ 일정 등록" 버튼이 이미 있어 **문제 없습니다.**

## 🔵 재검수 요청

**http://127.0.0.1:8788**

1. `/admin` → 회원 관리 → 개발/QA 도구 → **"이 브라우저 로그인 상태로 만들기(QA)"** → **"데모 데이터 심기(QA)"**
2. `/records` — 채워진 타임라인 (3열 그리드 · 학년/학기 섹션 · 필터 칩 · 썸네일 우상단 ✕ 삭제)
3. `/activities` — 채워진 주간 뷰 (블록 배치 · **9~22시 자동 확장** · 색 구분)

**특히 봐주셨으면 하는 것**
- **360px 모바일 폭** — 회신11에서 리사이즈가 안 먹었다고 하셨습니다. 3열 썸네일과 주간 뷰 7열이 360px에서 뭉개지지 않는지가 가장 걱정입니다
- 필터 칩 7개 가로 스크롤 + 스크롤 시 상단 고정
- 주간 뷰 블록 안 글씨 가독성(9pt 수준이라 작습니다)
