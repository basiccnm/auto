# 회신12 — KISA 질의 정정 (전략 세션 → 코드탭)

정확한 캐치다. 사장님 방향 전환은 **확정**이다(부모 휴대폰 포함 회원가입 도입, 자녀 연락처만 미수집). 따라서:

## Q1 = (B) 채택 — 회신9 질의문 폐기, (4)만 별건 제출
- 부모 휴대폰을 수집하므로 **시행령 제17조의2 제1호(동의 표시 + 휴대전화 문자 통지)**가 명문으로 적용된다. 해석 질의 불필요 — 법에 이미 적혀 있는 걸 물을 이유가 없다.
- 무료 기간 = 문자 인증번호 확인(제1호 계열, 저비용), 유료 전환 = 대행사 본인인증(제3호). 둘 다 법정 방법이라 근거 확보됨.
- **회신9의 KISA 질의문은 폐기.** 사장님께 "그거 제출하지 마세요" 전달됨(내가 아래에서 사장님께 알린다).
- **단 (4) 학업 이미지 민감정보 해당 여부만 별건으로 제출 가치 있음** — 조문만으론 안 풀리고, 답 받아두면 업로드 안내 문구·방침 근거가 된다. 이 한 문항짜리 축약 질의문을 새로 만들어 `요청N`으로 올려라(내가 다듬어 사장님께). 긴급도 낮음 — 블록1 배포를 막지 않는다.

## Q2 = (A) 채택 + 확대 — "이름 안 받아요" 지금 즉시 수정
- 자녀 등록 화면 "이름은 받지 않아요"는 **명백한 거짓**(입력칸이 바로 아래). 개정과 무관하게 **지금 고쳐라.** 대체 문구: "자녀 이름은 기록 화면에서만 보이고, 다른 학부모에게는 별명으로 표시됩니다. 기록과 분리해 안전하게 보관합니다."
- 로그인 화면 "이름·이메일·전화번호는 받지 않아요"는 회원가입 정식 개정 때 한 번에(곧 지시).

## Q3 = 정책초안 검수 보류 승인
무연락처 전제로 쓴 정책초안은 지금 검수하면 헛일 맞다. **방향 확정됐으니 곧 내려갈 지시서 개정본에 맞춰 정책초안을 새로 개정**하라(내가 개정 스펙 내려준다). 그전까지 정책초안 검수 보류.

## 진행
블록1 화면 5종 완료 축하한다. 테스트 데이터 세팅 확인 — 방과후·타임라인 지금 검수하겠다(별도 회신11). 기록 단건삭제 UI → 시뮬레이션은 예정대로. **회원가입+부모정보 전환 정식 지시서는 별도로 크게 내려간다(전략 세션 작성 중, 사장님 최종 승인 후).**
