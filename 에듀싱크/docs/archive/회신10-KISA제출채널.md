# 회신10 — KISA/개인정보 질의 제출 채널 (전략 세션 → 코드탭·사장님)

회신9에서 약속한 제출 채널 보강. 웹 확인 결과다.

## 핵심 원칙
**반드시 "서면으로 남는 답변"을 받아야 한다.** 전화 상담(국번없이 118)은 빠르지만 구두라 나중에 근거로 못 쓴다. 118은 방향 잡는 용도로만.

## 권장 경로 (서면 회신 남는 순)

1. **개인정보 포털(privacy.go.kr) 온라인 상담·질의** — 개인정보 관련 질의 접수 창구. 서면 답변이 기록으로 남는다. 사업자 질의에 무난한 1차 채널.
2. **개인정보보호위원회(pipc.go.kr) 법령해석·질의회신** — 가장 권위 있는 유권해석. 우리 질의처럼 "조문 적용 범위"를 묻는 건에 적합. 답변에 시간이 더 걸릴 수 있음.
3. **국민신문고(epeople.go.kr) 경유 민원** — 어떤 기관에 넣든 서면 답변 의무가 있어 근거로 확실히 남는다. 담당 부처로 자동 배정.

**추천 조합:** 개인정보 포털 또는 국민신문고에 회신9의 질의문 그대로 제출(서면 확보) → 급하면 118로 먼저 방향만 확인. 세 곳 다 무료.

## ⚠️ 사실 확인 한계
위 기관·창구는 실재하나, 각 사이트의 정확한 메뉴 위치·접수 양식은 수시로 바뀐다. 사장님이 접속 시 "개인정보 질의/법령해석/상담" 메뉴를 찾으면 된다. 세부 경로가 헷갈리면 전략 세션에 다시 물어라(그때 재확인).

## 사장님 액션 정리 (한 줄)
회신9의 질의문을 위 1) 또는 3) 채널에 붙여넣어 제출 → 서면 답변 오면 그 내용으로 동의 방식(㉮/㉯/㉰/인증) 최종 결정.
