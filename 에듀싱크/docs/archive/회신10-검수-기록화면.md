## ✅ 통과 (실물 확인)

- **빈 상태(자녀 없음)**: "먼저 자녀를 등록해 주세요 / 기록은 자녀별로 보관돼요" 카드. 자연스럽다.
- **자녀 등록 화면**: 회신4 지시 전부 반영 확인 —
  - 이름 입력 + "기록 화면에서만 보여요, 다른 학부모에겐 별명으로 표시" 안내 ✓
  - 별명 "첫째" 자동 채움 ✓
  - 보호자 동의 체크박스(필수) + 보호 3줄(이름 분리보관·광고 접근불가·원본까지 삭제) + 개인정보처리방침 링크 ✓
  - **학교별 개학일 실제 표시**: "서울숭미초등학교 개학(08.20) 전까지 모든 기능이 무료" — 자녀별 전환(D안) 작동 확인 ✓
  - "이용권 하나로 자녀 3명까지" 단일가 문구 ✓
  - "🎁 개학 전까지 무료" 뱃지 ✓
- admin 회원목록에 로그인 출처 뱃지(카카오/Google/토큰) 추가 확인 ✓

타임라인 썸네일 3열 그리드 실물·필터칩 360px 가로스크롤·업로드 FAB 시트는 QA 계정에 자녀+기록이 없어 화면에 안 떴다. 다음 검수 때 자녀 등록+업로드까지 세팅해 확인하겠다. (단건삭제 UI 없음은 네가 이미 알려준 대로 — ⑤ 이후 처리 OK)

## 🔴 전략 변경 예고 (사장님 결정 — 이 화면이 곧 크게 바뀐다)
사장님이 방향을 틀었다: **연락처 일절 안 받는 원칙 → 회원가입 도입 + 부모 연락처(휴대폰) 수집.** 자녀 연락처는 여전히 안 받음. 이유: 무료라도 어차피 가입자 적으니 처음부터 제대로 받고, 정식 본인인증은 유료 전환 시 대행사로.

**→ 이 검수 화면 두 곳이 현재 새 방향과 충돌하니, 곧 갈 지시 전까지는 지금 문구 유지하되 갈아엎을 준비만 해둬라:**
1. 로그인 화면: "이름·이메일·전화번호는 받지 않아요" → 회원가입 + 부모 연락처 수집으로 전면 수정 예정
2. 자녀 등록 화면: "학교·학년·반만 입력하면 결제 없이 바로" → 부모 휴대폰 문자 인증 단계 추가 예정

**정식 지시는 별도 요청/회신으로 내려간다(전략 세션이 지시서·정책까지 묶어 개정 중).** 지금 ⑤방과후는 이 변경과 무관하니 그대로 계속. 이 회신은 "곧 바뀐다" 예고이지 지금 착수 지시가 아니다.
