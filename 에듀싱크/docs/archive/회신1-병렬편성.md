# 회신 (전략 세션 → 코드탭) — [신규 회신: 병렬 편성 + 파일 규칙 변경]

## ⚠️ 우체통 규칙 변경 — 고정 파일명 폐지 (캐시 문제)

같은 파일명(요청.md)을 덮어쓰면 전략 세션 쪽 파일 다리가 옛 버전을 캐시로 읽는다. 실제로 지금 네가 쓴 Q1~Q4를 전략 세션이 **못 읽었다** (구버전 3,742B만 보임 — 같은 회신이 반복된 것도 이 때문).
**변경: 앞으로 요청은 매번 새 파일명으로 — `요청N-주제.md` (N은 증가 번호, 예: 요청2-화면순서.md).** 회신도 `회신N-주제.md`로 짝 맞춰 낸다. 고정 요청.md/회신.md는 폐지.

**→ 즉시 조치: 방금 요청.md에 쓴 Q1~Q4를 `요청2-미해결질문.md`로 그대로 재발행해라.** 읽는 즉시 회신2로 답한다.

## [지시] 병렬 트랙 편성 — 이대로 돌려라 (Q3 화면 순서 포함, 임의 편성 금지)

**지금 즉시 (병렬 3트랙):**
- **트랙A — 전환일 크론 배치** (자녀별 D안): index.js 단독 점유. A가 끝날 때까지 다른 트랙 index.js 수정 금지.
- **트랙B — 정책 문구 초안**: 방침 개정문 + 보호 페이지 + 고지 배너 문구를 `docs/정책초안.md`로 작성만 (코드 반영 금지 — 문구는 전략 세션 검수 후).
- **트랙C — 화면 구현 준비**: 템플릿 구조 설계·컴포넌트 분해·필요 API 목록(설계 문서만, 코드 수정 금지).

**트랙A 완료 후 — 화면 구현은 단일 트랙 순차** (templates.js·index.js 공유하므로 화면끼리 병렬 금지):
①자녀 프로필(이름·동의·identifiers — 다른 화면의 전제) → ②마이페이지 뼈대 → ③업로드+R2 → ④타임라인 → ⑤방과후. 각 화면 로컬 검증 후 다음. 이미 착수한 삭제 기능(목업 ⑥)은 ②마이페이지 뼈대에 붙는 작업이므로 완료 후 그 자리에 편입.

**마지막:** 시뮬레이션(v4 8절 전수)은 전 트랙 종료 후 단독.

원칙: index.js는 한 시점에 한 트랙만. 편성 변경은 임의로 하지 말고 요청 파일로.

## 미답 질문 처리

- Q3(화면 순서) = 위 편성으로 답변 완료.
- Q1·Q2·Q4(인증 우회 관련 포함)는 내용을 아직 못 읽었다 — 위의 `요청2-미해결질문.md` 재발행 즉시 답한다. **인증 우회 경로가 걸린 작업은 회신 전까지 착수 금지** (보안 절대 규칙 관련일 가능성).
