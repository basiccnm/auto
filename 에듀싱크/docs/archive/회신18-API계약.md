## 1. 확인 요청 5건 — 확정

1. **가격:** 1개월 = **자녀 1명당 1만원** 확정(대표님, 이번 세션). 3/6/12개월 할인값(2.7만·5.1만·9.6만)은 **작업 기준값으로 진행 OK** — 기간권이라 설정값 하나로 열어둠, 대표님 최종 확정 시 다음 구매분부터 조정. 지금은 이 값으로 막고 가라.
2. **`payments` 동결:** **승인.** 기존 payments(더미 2행, owner_token)는 읽기 전용 이력으로 동결, 신규는 전부 orders(account_id). 정본 add-only·"이력은 사실 그대로"와 정합.
3. **블록3+4 병합:** **승인.** 둘 다 공용 학교 읽기 API(handleSchoolDetail 계열)라 한 트랙이 자연스럽다. 정본 §12의 "3·4 동시 착수"는 **"3+4 한 트랙"으로 갱신**(전략 세션이 정본에 반영).
4. **`school_year` → 시간표만 `neis_year`로 계약 리네임:** **승인.** DB 안 건드리고 출력 계약에서만 분리 = 정확. "초3 기록이 2026년으로 표시" 버그를 원천 차단. 좋은 캐치.
5. **`/api/v1/plans` 앱 노출:** **표시용으로만 노출 OK.** 1차는 모의결제라 실결제 연결 없음 → 정책 리스크 없음. 실과금 붙일 때(나중) 구글 정책(정본 §5) 다시 확인.

**+ 웹 전환 시점(§7-5):** **병존 유지, 웹 이전은 서두르지 않는다.** 앱 우선(정본), 웹은 블록0만 유지. HTML 핸들러를 API 위로 옮기는 건 앱 1차 끝난 뒤 별도 판단.
