학교퀘스트 — 【부모】 미션 화면 사용법 (자세히)   2026-08-13
이 문서와 다르게 동작하면 그게 버그입니다. 항목 번호로 말씀해 주세요.

들어가는 길 : 홈 하단 바 오른쪽 「미션」  (또는 홈 서랍의 「미션」 줄)
테마        : 듀오링고(초록·둥근 버튼). 미션 세계는 부모 화면도 듀오링고입니다.

════════════════════════════════════════════════════════════
P1. 미션 첫 화면 — 위에서 아래로 무엇이 있나
════════════════════════════════════════════════════════════

 ┌ 맨 윗줄 ────────────────────────────────────────────
 │ ‹        누르면 → 홈. (미션 안을 아무리 돌아다녔어도 항상 홈)
 │ 미션     화면 이름
 │ ★ 12    이 아이가 지금 가진 별(쓰고 남은 것). 오늘 번 별이 아닙니다
 └──────────────────────────────────────────────────────

 ┌ 자녀폰 경고줄 (해당될 때만) ─────────────────────────
 │ 아이 폰이 아직 연결 안 됐을 때만 뜹니다. 누르면 연결 코드 발급 화면
 └──────────────────────────────────────────────────────

 ┌ 오늘의 길 (리본) ────────────────────────────────────
 │   ⊖   ▓▓▓▓▓░░░░ 🚩   ⊕
 │   오늘의 길            5 / 25
 │
 │ · 가운데 막대 = 오늘 아이가 받은 별 / 하루 상한(별 라인)
 │ · ⊖ ⊕ = 별 라인을 5씩 내리고 올립니다 (10 ~ 35)
 │ · 누르는 즉시 서버에 저장되고, 오늘 줄 미션 개수가 여기에 맞춰집니다
 │ · 상한에 닿으면 그날은 더 못 받습니다 — 「무조건 통과」를 막는 장치가 이것입니다
 │ · 10 미만·35 초과는 버튼이 잠깁니다(끝에 닿으면 흐려짐)
 └──────────────────────────────────────────────────────

 ┌ 🙋 확인해 주세요  (아이가 낸 것이 있을 때만 · 노을색) ─
 │ 아이가 「다 했어요」를 누른 것 중 **부모 확인이 필요한 미션**이 여기 쌓입니다
 │ 줄마다 : 미션이름  [★1] [★2] [★3] [확인만]
 │ · ★1~3 = 잘한 만큼 추가로 별을 더 줍니다 (기본 별에 얹어짐)
 │ · 확인만 = 추가 별 없이 «봤다» 처리
 │ · 누르면 그 줄만 잠기고 즉시 반영됩니다(다른 줄은 계속 누를 수 있음)
 │ · 하루 상한을 넘는 분은 안 들어갑니다
 └──────────────────────────────────────────────────────

 ┌ 🗺️ 오늘 준 미션        3 / 6 ────────────────────────
 │ 오른쪽 숫자 = 끝낸 것 / 오늘 준 것 전체
 │ 줄 하나 = 미션 하나. 줄을 누르면 → P2 상세 화면
 │ 줄 오른쪽 딱지가 상태입니다
 │     ★2      아직 안 함 (받을 수 있는 별)
 │     확인     아이가 냈고 부모 확인 대기 (📷 표시가 같이 붙음)
 │     ★2 ✓    끝남 (실제로 들어간 별)
 │     쉬어감   오늘은 빼기로 한 것
 │ ⚠ 완료돼도 **줄이 위로 올라가지 않습니다** — 자리를 지킵니다
 └──────────────────────────────────────────────────────

 ┌ 타일 3개 ────────────────────────────────────────────
 │ 🎲 바꾸기    오늘 안 한 미션들을 **한꺼번에** 다른 것으로 (하루 1번)
 │              안 한 미션이 하나도 없으면 잠김
 │ 🎯 고르기    카탈로그에서 직접 골라 담기 → P3
 │ ✏️ 만들기    우리 집만의 미션 새로 만들기 → P4
 └──────────────────────────────────────────────────────
 ┌ 타일 2개 ────────────────────────────────────────────
 │ 📋 오늘 한 것      아침/학교/방과후/오늘의미션 소속별로 정리 → P5
 │ ⭐ 추가 증정 ＋1   끝난 미션에 별 하나씩 더 주기 → P6
 └──────────────────────────────────────────────────────
 ┌ 타일 2개 ────────────────────────────────────────────
 │ 💛 칭찬 보내기   아이 폰에 뜨는 스티커·한마디 보내기
 │ 📊 이번 달       한 달 성적표(리포트) 화면
 └──────────────────────────────────────────────────────

 ┌ 맨 아래 초록 버튼 ───────────────────────────────────
 │ 「아이 화면으로 보기」 = 아이 눈으로 미리보기.
 │ 나올 때는 왼쪽 위 ‹ 를 누르면 부모 화면으로 돌아옵니다
 │ ⚠ 미리보기 중에는 부모 전용 버튼(진열대 올리기 등)이 숨습니다 — 정상입니다
 └──────────────────────────────────────────────────────

════════════════════════════════════════════════════════════
P2. 미션 하나 (상세) — 줄을 눌렀을 때
════════════════════════════════════════════════════════════

  위     ‹ (→ 오늘 미션 목록으로)
  가운데 큰 그림 + 미션 이름
         칩 : 영역(몸·물건·공부…) / N분 / ★N / 📷 사진 (사진 미션일 때만)
         「왜 이 미션인가요」 — 그 미션이 왜 좋은지 (자료에 있을 때만 뜸)
         「사진은 이렇게」 — 사진 미션일 때 찍는 요령
         지난 이레 도장판 — 월~일 7칸. ✓ 한 날 · · 안 한 날 · 오늘 표시

  아래 버튼 (상태에 따라 달라집니다)

  ● 아직 안 한 미션
      이것만 바꾸기   이 미션만 비슷한 별의 다른 미션으로 교체
                      → 바꿀 만한 게 없으면 「바꿀 만한 미션이 더 없어요」(정상)
      오늘은 빼기     오늘 목록에서 뺍니다(«쉬어감»)
      직접 고르기     고르기 화면으로 (P3)

  ● 아이가 내서 확인 대기
      (사진이 있으면 사진이 먼저 크게 보입니다)
      잘했어! 도장 찍기   승인 + 별 지급 → 홈으로 나감
      서랍에 보관하기     이 사진을 아이 기록(서랍)에 같이 저장
                          누르면 「✓ 도장 찍을 때 서랍에 넣어요」로 바뀝니다
      다시 해볼까?        되돌려서 다시 «안 한 것»으로

  ● 끝난 미션 / 쉬어감
      다시 해볼까? (끝난 것) · 다시 줘볼까? (쉬어감) — 다시 열어 줍니다

════════════════════════════════════════════════════════════
P3. 미션 고르기 (🎯)
════════════════════════════════════════════════════════════
 · 위 탭 = 학년대(저·중·고). 그 아래 추천 3개, 다시 아래 영역별 전체 목록
 · 줄을 누르면 담김 ↔ 빠짐 (오른쪽이 ＋ ↔ 담김 으로 바뀜)
 · 하루 최대 8개까지 (서버 값 — 「3개만」이 아닙니다)
 · 맨 아래 「n개 담기」를 눌러야 오늘 미션으로 확정됩니다
   → 이미 끝낸 미션은 지워지지 않습니다
 · 전부 사진 미션으로만 담으면 거절됩니다 — 눌러서 끝내는 것이 하나는 있어야 합니다
 · 「우리 집」 딱지가 붙은 것 = 내가 만든 미션(P4)

════════════════════════════════════════════════════════════
P4. 만들기 (✏️ 우리 집 미션)
════════════════════════════════════════════════════════════
 · 이름 → 걸리는 시간(1~30분) → 확인 방법 고르고 「넣기」
     눌러서 = 아이가 누르면 그 자리에서 완료(부모 확인 없음)
     사진   = 아이가 사진을 찍어 보내고 부모가 확인
     하루끝 = 하루 끝에 부모가 확인
 · **미션 화면의 「만들기」로 만들면 오늘 목록에 바로 들어갑니다**
   (토스트 「오늘 미션에 넣었어요」)
 · 고르기 화면 안의 「우리 집 미션 만들기」로 만들면 담기 목록에 체크만 되고,
   하단 「n개 담기」를 눌러야 오늘 것이 됩니다
 · 만든 미션은 고르기 목록에 계속 남습니다 (최대 20개)

════════════════════════════════════════════════════════════
P5. 오늘 아이가 한 것 (📋)
════════════════════════════════════════════════════════════
 · 🌅 아침 미션 / 🏫 학교 미션 / 📚 방과후 미션 / ⭐ 오늘의 미션 순으로 묶임
 · 소속 아래에 그 미션 이름이 붙습니다
 · 끝난 것 = 「완료 ★n」 · 확인 대기 = 누르면 확인 화면 · 안 한 것 = 「아직 · ★n」

════════════════════════════════════════════════════════════
P6. 추가 증정 ＋1 (⭐)
════════════════════════════════════════════════════════════
 · 오늘 **완료된** 미션마다 ＋1 버튼이 하나씩
 · 누르면 그 줄만 잠기고 즉시 「＋1 줬어요」 (다른 줄은 계속 눌립니다)
 · 한 미션에 한 번만. 하루 상한을 넘으면 안 들어가고 안내가 뜹니다

자주 헷갈리는 것
════════════════════════════════════════════════════════════
 · ★ 12 (맨 위) = 지금 가진 별,  5 / 25 (리본) = 오늘 받은 별 / 하루 상한 — 다릅니다
 · 별 라인을 올려도 미션이 그만큼 «바로» 늘지는 않습니다 —
   내일 아침 배정부터 그 라인에 맞춰 채워집니다(오늘은 「고르기」로 더 담으세요)
 · 「바꾸기」는 하루 한 번, 「이것만 바꾸기」는 미션마다 따로입니다
 · 방학에는 학교 미션(급식·누구랑·수업)이 흐려지고 「방학중」으로 잠깁니다 — 정상입니다
 · 지금 방학이라 미션 종류 자체가 적습니다(카탈로그가 얇음 — 콘텐츠 보강 예정)
