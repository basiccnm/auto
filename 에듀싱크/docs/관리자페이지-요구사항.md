## 알아 둘 것

- **관리자 변경은 워커 배포가 필요하다** — 대표님 「배포해」 없이는 실화면에 안 나온다
- 지금 회원 목록은 `users` 테이블만 본다 → `accounts`(email·status·created_at·last_login_at) 와
  `auth_methods`(identifier = 로그인 아이디) 를 같이 읽어야 5·6번이 된다
- 관리자는 **대표님 한 분**이다 — 표준이 권하는 IP 기록보다 **«왜 했나»(사유)**가 훨씬 중요하다

## 2026-08-09 실측으로 밝혀진 것

- **계정 데이터는 멀쩡했다** — `accounts` 10건 전원 이메일 있고 전부 아이디·비밀번호 가입.
  옛 토큰 계정(`users`)은 **0행**이다. 「아이디가 없다」로 보인 건 **화면이 안 읽어서**였다.
- **이용권 조정은 이미 있다**(`/admin/members/adjust`). 없는 건 «사유»와 «기록»이다.
- 관리자 화면 실물을 처음 봤다(대표님 스샷). 회원 9행 · 결제 전원 「없음」.

## 🧭 중·고등학교판을 따로 낸다 (2026-08-10 새벽 대표님 방향)

**시작점** — 「미션은 초등학교용이야. 중고등학교에 이런 미션을 안 넣을 건데?
그럼 가격이 틀려야 되잖아」 → 「다른 걸 붙여야 하는 거잖아」.

### 왜

이 앱의 **상품은 미션·별도장**이고 학교정보(급식·시간표·학사일정)는 그걸로 데려오는 **훅**이다.
중·고에 미션을 안 넣으면 훅만 남는다. 훅에 6,900원을 받으면 그건 급식 앱 값인데
급식 앱은 무료가 널렸다 → **중·고는 «값을 받을 물건»이 따로 있어야 한다.**

### 무엇을 붙이나 (초안 — 미확정)

| | 초등 | 중·고 |
|---|---|---|
| 상품 | 미션 · 별도장 · 상점 | **시험 D-day · 수행평가** / **생기부 대비 기록**(독서·봉사·대회·동아리) |
| 훅 | 급식 · 시간표 · 학사일정 | 같음 |
| 값 받는 근거 | 「잔소리 없는 부모」 | 「3년치가 쌓인다」 — 학종 때문에 모아야 한다 |

### 어떻게 만드나 — **서버·DB 하나 · 앱 둘** (대표님 확정 2026-08-10)

> 「어차피 껍데기는 복사를 해야 한다고. 그러고 수정을 해서 따로 제작을 하는 거고,
>  DB는 그대로 사용을 하겠지」

- **서버·D1 은 그대로 하나.** 계정·자녀·인증·급식·시간표·학사일정·결제 전부 공유한다.
  서버는 이미 아이의 **학교급을 안다** — 앱만 갈아 끼우면 된다.
- **앱은 둘.** 스토어 등록 둘 · 아이콘 둘 · 가격 둘 · 화면 둘. 중·고판은 마음껏 뜯어고친다.

#### 🔴 복사 **전에** 한 번만 갈라 둘 것

지금 `app/www/app.js`(약 11,600줄) 안에 **화면과 밑바닥이 같이** 들어 있다 —
토큰 저장 · `api()` · 라우터 · 급식 파싱 · 로컬 캐시가 다 그 파일이다.
이대로 복사하면 「껍데기만 복사」가 아니라 **밑바닥까지 복사**된다.

```
app/core/    토큰·api·라우터·급식파싱·저장   ← 두 앱이 같이 쓴다(고치면 양쪽 반영)
app/www/     초등 화면·카드·드로어           ← 복사해서 중·고판으로
```

> ⚠ **근거**: 2026-08-10 폰 실기에서 잡은 심각한 결함 여덟 개가 **전부 이 밑바닥**에 있었다
> (첫 아이가 서버에 안 올라감 · 미가입 등록 · 리롤이 폰 안 번호를 보냄 · 안전영역 · 토큰 갱신).
> 복사본이 있었으면 여덟 개를 **열여섯 번** 고쳐야 했고, 한쪽만 고치는 날이 반드시 온다.

#### 이미 «표»로 되어 있어 갈아 끼우기 쉬운 것

- **드로어 메뉴** — `drawerView()` 의 `GROUPS` 가 `[아이콘, 이름, 동작, 뱃지]` 배열이다.
  중·고판은 「보상」 줄을 통째로 바꾸면 끝.
- **미션 세계가 A 에 붙은 자리는 6곳뿐** — 홈 미션 카드 3 · 하단 ★ · 서랍 「보상」 그룹 · 코치마크.
  서버도 `api_mission.js` · `api_reward.js` · `api_quiz.js` · `school_missions.js` 로 이미 갈려 있다.
- **홈 카드는 아직 표가 아니다**(네 카드가 따로 쓰여 있다) → 드로어처럼 표로 빼면 같은 방식.

### 이미 되어 있는 것

- **이용권이 자녀별**이다 → 아이마다 학교급이 다르니 **아이 단위로 값을 다르게** 매길 수 있다
- **교시 시각이 학교급별**로 갈렸다(2026-08-10) — 초 40분 / 중 45분 / 고 50분

### 남은 결정 (낮에)

1. 중·고 요금 — 무료(훅만) / 별도 상품 / 안 받음
2. 중·고 상품 확정 — 시험·수행평가인가, 생기부 기록인가, 둘 다인가
3. 스토어를 둘로 낼지, 한 앱 안에서 학교급으로 갈지
4. **대학교는 범위 밖** — NEIS 에 급식도 시간표도 없다


### A 선을 다시 그어야 한다 — 「공통」 안에 초등 냄새가 섞여 있다

> 「준비물 이런 거 다 없애야 하니깐 어차피 수정을 해야 해」

| A (진짜 공통) | 초등 전용 | 중·고 전용 |
|---|---|---|
| 계정 · 자녀 · 학교정보(급식·시간표·학사일정) · 달력 · 서랍(기록) · 서류 · 대화 · 설정 | 미션 · 도장 · 상점 · 아이모드 · **준비물** · 커뮤니티(반모임) | 시험 D-day · 수행평가 · 생기부 기록 |

**준비물·커뮤니티가 지금 A 에 있는데 초등 것이다.** 안 걷어내면 중·고판에
「내일 준비물 완료」 카드가 그대로 뜬다. **낮에 A 선부터 확정할 것.**
