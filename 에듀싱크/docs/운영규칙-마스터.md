# 협업 운영규칙 — 마스터 (코드탭 필독 · 회신5·6·7 통합·대체)

이 문서 하나가 협업 방식의 정본이다. 읽고 이해한 대로 `docs/인계-코드탭.md`에 요약 반영한 뒤, 회신5·6·7 파일은 삭제(내용이 여기 다 들어왔음). 그다음 작업 재개.

## 1. 역할 (3주체)

- **사장님** — 최종 결정권자. 실행 승인.
- **전략 세션(클로드 웹)** — 설계·검수·판단. 요청에 회신. 문서 정본 관리.
- **코드탭(클로드 코드)** — 실제 구현·DB·배포. 막히면 전략에 물음.

## 2. 질문 라우팅 (제일 중요)

**사장님께 직접 가는 것은 딱 3가지뿐:**
1. 웹(운영) 배포 승인
2. 돈이 드는 작업(구매·과금)
3. 사업 정체성·법적 정체성이 걸린 결정(예: 아동 동의 방식)

**그 외 모든 판단**(스펙 해석, 우선순위, 엣지 케이스, 문구, 기술 선택) = 전략 세션에 `요청N`으로. 전략 세션은 항상 **단일 확정안**으로 회신한다. 회신 받고도 애매하면 사장님이 아니라 다시 `요청N`.

## 3. 우체통 파일 규칙

- 질문: `요청N-주제.md` (N 증가). **고정 파일명 금지** — 같은 이름 덮어쓰기는 파일 다리 캐시 때문에 전략 세션이 구버전을 읽는 사고가 있었다. 매번 새 번호.
- 회신: `회신N-주제.md` (짝 맞춤).
- 정리: 요청·회신 쌍은 docs에 **최대 5쌍** 유지. 6쌍째면 가장 오래된 반영완료 쌍부터 → 작업로그에 "요청N: 결정 요약 한 줄" 남기고 → 삭제. 미결 쌍은 개수 무관 삭제 금지. **archive에 이미 옮긴 것은 이력으로 보존하고 카운트에서 제외** — 앞으로 새로 생기는 쌍만 5쌍 규칙 적용.
- archive 이동/삭제는 코드탭만 수행. 전략 세션은 회신 작성만.

## 4. 회신 수거 (개정 2026-07-19 — 구 "디스패처 슬롯" 폐기)

실시간 감시 슬롯은 **폐기**한다. 서브에이전트 간 통신 불가 · 백그라운드 감시 20분 타임아웃 · 턴 종료 후 자체 재기동 불가 — 셋 다 코드탭의 실행 모델상 넘을 수 없다.

대신:
1. **매 턴 시작 시** `docs/`의 새 `회신*` 확인.
2. `요청N`을 올린 **직후 그 자리에서 `회신N`을 20분 bash 감시**(30초 간격, 출현 즉시 반영).
3. 20분 넘겨도 안 오면 감시 종료 → 다른 비봉쇄 작업 계속. 그것도 없으면 정지 → 사장님 "계속" 한 마디로 재기동.

목표는 **"실시간"이 아니라 "놓침 없음"**이다. 전략 세션은 **5분 이내 응답**하므로 이 20분 창이 대부분을 덮는다.

## 4-2. 검수 분업 (회신9)

코드는 코드탭이 짜고, **"실제 사용자 눈에 어떻게 보이나"는 전략 세션이 로컬(127.0.0.1:8788)에 직접 접속해 클릭 검수**한다. 스크린샷을 주고받는 것보다 빠르고 정확하다.

1. 화면/기능 완성 + 로컬 검증(빌드·기본동작) 끝 → `요청N-검수-○○화면.md`
   내용: 무슨 화면 · 접속 경로 · 봐줬으면 하는 포인트 · 알려진 미완 부분
2. 전략 세션이 5분 내 8788 접속 → 실클릭·엣지케이스 → `회신N`으로 통과/수정지시
3. **검수를 기다리지 않고 다음 화면 계속 짠다** — 검수가 병목이 되지 않게
4. 로컬 서버 8788·8789는 **끄지 않는다**(전략 세션 검수용)

## 5. 진행·보고

- **⚠️ 사장님 직접 지시("대기"/"재개 마라"/"멈춰")는 이 마스터 규칙보다 우선한다.**
- **그냥 계속 진행.** 막히지 않은 일이 있는 한 멈추지 않는다. 진짜 막힐 때만 `요청N`, 그동안에도 다른 트랙 진행.
- 진행 보고·이정표·버그수정 = 코드탭 채팅 + `작업로그.md`에만. 전략 세션에 push 안 함(pull: 사장님이 물으면 전략이 로그 읽어 요약).
- ⚠️ 캐시 주의: 마스터 `작업로그.md`는 전략 세션이 최신본을 못 읽는다. 전략이 꼭 알아야 할 새 사실은 `요청N`이나 새 파일명으로.

## 6. 병렬 트랙 안전

- 편성은 전략 세션이 지정. 임의 변경 금지, 필요하면 `요청N`.
- 같은 파일·같은 테이블을 두 트랙이 만지면 병렬 풀고 순차 전환. `index.js`는 한 시점에 한 트랙만.
- 트랙이 ETA를 넘겨도 전략 세션은 취소 먼저 안 한다 — "진행 중이냐, 어디 막혔나" 먼저 묻는다. 코드탭도 막히면 ETA 전에 알린다. (보안 절대규칙 위반만 즉시 정지 예외)

## 7. 배포

- 로컬(wrangler dev) = 자동, 승인 불필요.
- 웹 배포(`wrangler deploy`) = **사장님 "배포해" 필수.** 전략 회신은 승인이 아님.

## 8. 세션 교체(컨텍스트 참)

- `인계-코드탭.md`는 **새 코드탭 세션용**이지 전략 세션이 실시간으로 읽는 파일이 아니다(고정명이라 전략 쪽 캐시에 걸린다). **전략이 알아야 할 건 항상 새 번호 파일로.**
- 코드탭은 `docs/인계-코드탭.md`를 항상 최신 유지(진행 트랙·미완·다음 단계·주의). 새 코드탭 세션: "docs/인계-코드탭.md 읽고 이어서" 한 줄로 복원.
- 정본: `블록1-지시서-v4.md`, `로드맵-DB마스터-v3.md`.

## 9. 현재 미결(사장님 결정 대기)

- 아동 동의 확인 방식(요청3) — KISA 무료 질의 후 결정. 코드탭이 질의문 초안을 `요청N`으로 올리면 전략이 다듬어 사장님께. (이 건만 자녀 프로필의 '동의 확인' 부분이 잠정 대기 — 나머지 화면·기능은 계속 진행)
