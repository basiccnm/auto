## 🔴 1. DB 동시 작업 — 덮어쓰기 사고 위험

SQLite는 **파일 하나**다. 두 세션이 각자 읽어서 각자 쓰면
**나중에 쓴 쪽이 앞의 작업을 통째로 날린다.**

**규칙:**
- DB를 **쓰기 전에** 다른 세션이 작업 중인지 확인
- 쓰기 작업은 **짧게, 한 번에** 끝낸다 (오래 열어두지 않기)
- 작업 후 **뭘 바꿨는지 이 문서 맨 아래 변경 로그에 남긴다**

**역할 분담(권장):**
| 세션 | 주 담당 |
|---|---|
| 쇼츠 세션 | `_shorts/` · 영상 · `menus` 원가 검증 |
| 레시피 세션 | `dish_def` · `dish_def_ingredient` · 레시피 본문 |
| 공통(충돌 지점) | **`ingredients`** ← 둘 다 건드림. 여기가 제일 위험 |

## 🔴 2. 원가는 **도매(매장 납품가) 기준**으로 확정 (2026-07-21)

`menus` 테이블에 원가가 **두 개**다:

| 컬럼 | 뜻 |
|---|---|
| `est_cost` / `cost_ratio` | 장보기 원가 = **소매** |
| `store_cost` / `store_ratio` | 매장 원가 = **도매** ★ |

**프랜차이즈 원가를 다룰 땐 `store_cost`(도매)를 쓴다.**

근거: 제로비(실측 채널)의 교촌 허니콤보 원가 7,793원 vs
우리 도매 7,516원(**3.5% 차이**) / 우리 소매 9,801원(26% 차이).
→ 도매가 현실에 맞다.

## 🔴 8. 집 레시피와 매장 원가를 나란히 놓을 때 (2026-07-21)

**한쪽만 업소용 단가면 비교가 깨진다.**

실제 사고: 집 레시피 기름값을 **1,060원(업소용 블렌드 7,361/L)** 과 비교했다.
1,060은 BBQ가 18L 말통으로 받는 값인데, 집에서 마트에 사는 값과 나란히 놓은 것이다.
같은 소매 기준으로 다시 재니:

| 같은 소매 기준 | 기름값 |
|---|---|
| 집에서 EV+해바라기 반반 섞어 튀김 | 1,716원 |
| 해바라기유 144ml + 올리브유 30ml 마무리 | **1,127원** |

→ 589원 싸다. 장보기로 보면 차이가 더 크다(전엔 올리브유 1.5L 3만원↑, 이제 작은 병 하나).

**규칙: 비교하는 두 값은 반드시 같은 기준(둘 다 소매 or 둘 다 도매)이어야 한다.**

## 🔴 7. 제로비 대조는 "소스 없는 메뉴"로만 한다 (2026-07-21)

도매 기준을 확정한 근거가 **제로비 허니콤보 7,793원 vs 우리 7,516원(3.5%)**이었다.
그런데 `sauce_honey`를 실거래가로 내리자 우리 값이 **6,898원(-11.5%)**으로 벌어졌다.

**차이의 원인은 소스 하나다.** 그리고 여기엔 답이 없다:
- 교촌 허니소스는 **본사 전용 제조**라 시중에서 살 수 없다. 우리도, 제로비도 실제 납품가를 모른다.
- 제로비도 결국 **시판 소스로 대체해 추정**했을 가능성이 크다. 그쪽 숫자도 추정이다.

**그래서 앞으로:**
- **대조 기준을 소스 없는 메뉴로 옮긴다** — 후라이드처럼 닭·기름·파우더만 드는 메뉴가 검증에 적합하다
- 소스가 큰 비중인 메뉴(허니콤보·양념류)는 **대조 근거로 쓰지 않는다**
- 영상에서도 소스 비중이 큰 메뉴는 "본사 전용 소스는 확인 불가" 문구를 더 크게 넣는다

## 🔴 6. 기름 원가 — 매장과 집을 다르게 계산한다 (2026-07-21 확정)

### 왜 문제가 됐나
BBQ는 올리브유를 **18L 말통 20만원 = 11,111원/L**에 받는다.
근데 집에서 마트에 사면 **20,217원/L**로 거의 두 배다.
그대로 계산하면 **"집에서 만들면 8,040원 > 매장 6,944원"** — 집이 더 비싸게 나온다.

### 해결 — 조리법 자체를 바꾼다
집에서는 **기름을 두 번에 나눠 쓴다.**

```
1차:  일반 식용유로 튀긴다        ← 기름이 많이 드는 단계
2차:  올리브유로 살짝 마무리 튀김   ← 향만 입히는 단계
```

비싼 올리브유를 **조금만** 쓰게 되어 원가가 내려간다.
올리브유는 고온에 오래 두면 향이 날아가므로 **마지막에 입히는 게 요리로서도 맞다.**

| | 매장(BBQ) | 집 |
|---|---|---|
| 방식 | 블렌드(EV50:해바라기50) 한 번에 | 식용유 1차 → 올리브유 2차 |
| 기름 원가 | 144ml × 7,361/L = **1,060원** | 식용유 약 120ml + 올리브유 소량 |

> ⚠️ **2차 올리브유 사용량(ml)은 아직 미정.** 대표 확인 대기.
> 정해지면 `dish_def_ingredient`에 반영할 것.

### 흡수분만 원가에 넣는 이유
튀김 기름은 **한 번 쓰고 버리지 않는다.** 1.5L 부어도 닭이 먹는 건 144ml뿐이고
나머지는 솥에 남아 다음 튀김에 또 쓴다. **1.5L를 전부 원가에 넣으면 과대계상.**
→ 원가는 **흡수분만**, 붓는 총량은 **조리법에만** 적는다.
→ 레시피 페이지에 **"기름은 여러 번 재사용합니다"** 한 줄 넣을 것.

## 참고: BBQ 올리브유 실측 (2026-07-21, 대표 현장 정보)

BBQ는 **엑스트라버진 50% + 해바라기유 50% 블렌드**로 튀긴다. (100% 올리브유 아님)

| | 업소용 18L | 환산 |
|---|---|---|
| 엑스트라버진 | 20만원 | 11,111원/L |
| 해바라기유 | 6.5만원 | 3,611원/L |
| **블렌드(50:50)** | | **7,361원/L** |

치킨 1마리 흡수분 144ml 기준 = **1,060원**

> ⚠️ 이 값은 **대표가 준 실측치다. 여기에 계수를 또 곱하지 말 것.**
> (한 번 ÷0.8 해서 부풀렸다가 지적받고 되돌림)
