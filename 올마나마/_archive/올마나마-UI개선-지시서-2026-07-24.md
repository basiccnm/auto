> **Claude Code용.** 클로드웹에서 실서비스(_dist 백업본) 전 페이지를 스캔·진단하고,
> 대표님이 목업(A안/B안/최종안)을 비교해 **"최종안 — 콜라보"로 확정**한 결과다.

## 0. 작업 규칙 (위반 금지)

1. **배포 금지.** 로컬 프리뷰(8801)까지만. 대표님이 화면 확인 후 "배포해" 지시하면 그때 배포.
2. 시작 전 DB·코드 백업. 색·폭·네비·전역태그는 **`scripts/theme.py` 단일 출처**에만 쓴다. 생성기에 값을 다시 박지 말 것.
3. `gen_preview_html.py`의 HEAD는 f-string이 아니라 `.format()` 템플릿 — 기존 `/*THEMEVARS*/`·`/*WRAPCSS*/` 플레이스홀더 방식을 따를 것.
4. **애드센스 심사 중.** 광고 개수·위치 변경 금지(§4-4 빈 라벨 처리는 예외 — 개수 변화 없음).
5. 완료 기준: 생성기 전부 재실행 → `healthcheck.py` 전 항목 통과 → 360/768/1920 실측 스크린샷 확인.
6. 데이터·계산·SEO(JSON-LD·canonical·sitemap)는 **건드리지 않는다.** 이번 작업은 표시 계층 + §4의 표기 버그만.

## 1. 디자인 토큰 — `theme.py` CSS_VARS 교체

라이트 모드 (다크 모드는 기존 다크 값을 유지하되 accent만 #ff8a5c → 그대로 둬도 됨):

```
--ink:    #191f28   (본문 글자 — 기존 #1a1d21보다 살짝 블루블랙)
--muted:  #6b7280   (유지)
--faint:  #9aa2ad   (신규 — 각주·라벨용)
--line:   #eceef1   (기존 #e8eaed → 미세 조정)
--bg:     #f7f8fa   (기존 #f5f6f8 → 미세 조정)
--card:   #fff      (유지)
--accent: #f4511e   (기존 #ff6b35 → 채도 정리. 그라디언트는 #f4511e→#ff8a50)
--accentsoft: #fff2ec
--up: #e5484d  --dn: #2f6fed   (등락 전용)
--herofrom: #fff0e6  --heroto: #ffe3d2   (홈 히어로 웜톤 그라디언트 배경)
```

### 색 사용 규칙 (이번 개선의 핵심 — 주황 남용 정리)
- **accent를 쓰는 곳은 4곳뿐**: ① 로고 배지 ② 핵심 원가율 수치(게이지·%) ③ CTA 버튼(그라디언트) ④ 네비/칩 active
- 표의 가격 숫자, 리스트 가격, 재료 단가표 숫자 → 전부 `--ink` (bold + `font-variant-numeric:tabular-nums`)
- 등락 표시만 `--up`(▲빨강)/`--dn`(▼파랑)
- 그라디언트(#f4511e→#ff8a50)를 쓰는 곳: 홈 히어로 카드 배경(herofrom→heroto 연한 버전), 레시피 메인 입구 카드, "만드는 법" 등 주요 CTA 버튼. **그 외 금지**

## 2. 글꼴 — Pretendard 도입 (체감 개선 1순위)

- `HEAD_TAGS`에 추가:
  `<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/dist/web/variable/pretendardvariable-dynamic-subset.min.css">`
- body font-family를 `'Pretendard Variable',Pretendard,-apple-system,'Apple SD Gothic Neo','Malgun Gothic',sans-serif`로 (theme.py 한 곳에서)
- 타이포 조정: 페이지 h1 = 모바일 22px/800 · PC 26px/900, letter-spacing -0.02em. 보조 라벨 하한 12.5px(11~12px 고정값들 상향). 숫자 컬럼은 tabular-nums.

## 3. 컴포넌트 개선

### 3-1. 헤더·네비 (전 페이지)
- 이모지 버튼(🔗 공유, 🌙 다크) → **인라인 SVG 아이콘**으로 교체 (목업의 검색·달 아이콘 참조). 기능은 유지.
- 섹션 제목의 이모지(🧾📊💡🏆📈👨‍🍳 등) 전부 제거. 필요하면 SVG 점 아이콘.
- **네비 현재 위치 표시**: 현재 페이지 항목에 `.on` (배경 --ink, 글자 흰색 pill). 생성기가 페이지 종류를 아니까 렌더 시 주입.
- 모바일: 기존 pill 스크롤 유지 + "마라탕 재료원가" → **"마라탕 단가표"**로 축약.
- **PC(≥840px): 네비를 화면 전체에 펼치지 말 것**(flex:1 제거). 로고 오른쪽에 좌측 정렬로 붙이고, 오른쪽 끝에 검색 인풋(230px) 고정. 한 줄 60px 헤더. (목업 PC 홈 참조)

### 3-2. PC 레이아웃 — 2단 구성 (본문 절반 공백 해소)
- 홈·메뉴상세·마라탕 단가표: PC에서 `grid-template-columns: minmax(0,1fr) 320px` 2단.
  - 홈 사이드: 오늘 움직인 재료 / 원가율이란? / 광고
  - 메뉴상세 사이드: "집에서 만들면" 카드 / 이어서 볼 것 / 광고 (sticky top 16px)
  - 마라탕 단가표: 본문을 카테고리 2열 카드로 폭 채움 (현재 채소 탭이 왼쪽 절반만 씀)
- 홈 하단 관련서비스(채널·학원정보·약국): 전폭 3장 세로 나열 → **PC 3열 그리드**
- WRAP_CSS의 폭 체계(모바일 520/PC 960/BP 840)는 유지. 2단은 그 안에서.

### 3-3. 홈 첫인상 (B안 웜톤 적용 자리)
- 히어로: `linear-gradient(140deg, var(--herofrom), var(--heroto))` 라운드 20px 카드, 제목 "내가 시킨 그 메뉴, **원가가 얼마일까?**"(강조만 accent), 검색창을 히어로 안에.
- 입구 3개: 레시피 = 그라디언트 채운 메인 카드, 브랜드/시세 = 흰 카드. (목업 참조)
- 메뉴 카드: 원가율 **얇은 게이지 바(6px)** + "재료비 N원 · N%" 한 줄. PC 리스트 행에는 게이지를 중앙 컬럼으로.

## 4. 잘못된 부분 수정 (표기 버그 4건)

1. **홈 "실시간 재료 가격 07.16 대비" 멈춤** — 시세 페이지는 07-21 기준인데 홈 위젯만 옛 날짜. 홈 위젯 데이터 소스가 어디서 끊기는지 조사(수집 크론 vs 렌더 시점) 후, 시세 페이지와 같은 기준일을 쓰게 통일. 날짜는 하드코딩 금지 — 데이터에서 산출.
2. **재료 종수 불일치** — 홈 "재료 261종" vs 시세 "352종". DB 카운트로 자동 산출해 한 값으로.
3. **"수익" 용어 통일** — 홈 원가 리스트의 "수익 8,595원 · 78.9%" → **"나머지"**로. (메뉴 상세의 "남는 돈이 아닙니다" 원칙과 충돌. 사이트 전체에서 '수익'이라는 단어 검색해 전수 교체)
4. **빈 광고 라벨** — 애드핏 미로드 시 "광고" 라벨/빈 박스가 남지 않게: 기존 MutationObserver가 `.on` 클래스를 주는 구조이니, 라벨 포함 컨테이너 전체를 `.on`일 때만 표시.

## 5. 작업 순서

```
1. 백업 (코드 .bak / DB 불필요 — DB 안 건드림)
2. theme.py: CSS_VARS·GNAV·HEAD_TAGS(폰트) 수정 + PC 헤더/2단 공통 CSS 추가
3. 생성기 4개에서: 이모지 제거, 네비 active 주입, 홈 히어로/입구/카드, PC 2단, §4 버그 4건
4. 생성기 전부 실행 → build_dist.py → healthcheck.py 전 항목 통과
5. 로컬 8801 프리뷰 → 360/768/1920 스크린샷 8종 페이지(홈·레시피목록·레시피상세·카테고리·브랜드·메뉴상세·시세·마라탕) 눈으로 확인
6. 대표님 확인 요청 → "배포해" 지시 후 배포
```

수정거리가 더 나오면 하나씩 고치지 말고 목록으로 모아 일괄 처리(전역 규칙).
