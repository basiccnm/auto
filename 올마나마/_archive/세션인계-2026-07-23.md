## ⚠️ 다음 세션이 주의할 것

1. **마라탕 메뉴/브랜드가 아직 DB의 `menus`·`brands`에 없다.** 지금까지 한 건 "재료 풀"만 준비한 것 — 실제 마라탕 1인분 메뉴(브랜드+가격+재료배합)는 아직 안 만듦. 다음 단계로 가능
2. 흑목이·백목이는 **마른 상태 구매가**다. 레시피에 넣을 때 불림 배수(흑목이 8배, 백목이 5배) 적용해야 함 — 메모리 파일 `maratang-mokyi-rehydration-ratio.md` 참고
3. **완자류는 "코리아" 브랜드 우선**이라고 대표님이 명시함 — 나중에 다른 브랜드로 바꾸지 말 것
4. 새우 원가는 폭이 넓다(1,556~2,111원/100g) — 별도결제 항목이라 정확한 단가 확정 안 함, 필요시 추가 조사
5. **네이버 쇼핑 API 종료(7/31 24:00)**가 여전히 살아있는 마감이다 — 이 세션에서 손 못 댐, 남은 날짜 다시 셀 것
6. 현장 앱은 마켓봄과 별개의 종합 식자재 카탈로그(가공식품/농산물/수산물/축산물/비식품/CK제품/기타, 수천 품목) — 필요할 때마다 검색해서 쓰면 됨. 앱 내 한글 검색 입력은 클립보드 붙여넣기(X버튼으로 지우고 → 탭 → 붙여넣기 → 엔터)로 됨, `input text`는 크래시남
