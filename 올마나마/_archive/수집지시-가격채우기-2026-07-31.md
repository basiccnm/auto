## 0. 반드시 지킬 것

**⓪ 수집 방법·순서는 `수집순서-확정로직.md` 를 따른다.** 웹 API → 렌더 DOM → 스마트오더 →
앱(APK→API→화면) → 블로그 순서고, 화면 판독은 detect() 판정 없이 시작하지 않는다.
스샷 하나하나를 비전으로 읽는 것 금지. 스크립트는 서랍(97개)에서 먼저 찾고 새로 만들지 않는다.


1. **JSON 규격은 기존과 동일하다.** 이미 넣은 파일(`bhc.json`, `kyochon.json` 등)을 그대로 따른다.

```json
{"brand":"도미노피자","slug":"dominos","source":"https://web.dominos.co.kr/","collected_at":"2026-07-31",
 "cats":[{"name":"피자","parent":null,"ext_id":"1"},{"name":"프리미엄","parent":"피자","ext_id":"1-1"}],
 "menus":[{"name":"슈퍼시드 리얼불고기","price":25900,"price_source":"homepage",
           "weight_raw":"L 445g","origin_raw":"돼지고기:국내산","allergy_raw":"","compose_raw":"",
           "detail_url":"","image_url":"","ext_id":"P001","cats":[["피자/프리미엄",0]]}]}
```

2. **탭 이름·탭 순서·탭 안의 진열 순서는 브랜드 홈페이지 그대로.** 우리 입맛대로 묶지 않는다.
   같은 메뉴가 「추천」과 「치킨」 양쪽에 나오면 **양쪽 다** 담는다 — 브랜드가 그렇게 밀고 있는 것이다.
   `cats` 의 두 번째 값이 그 탭 안에서의 자리(0부터)다.

3. **UI 글자를 메뉴로 담지 마라.** 오늘 15곳에서 이런 것들을 걷어냈다:
   `close` · `KOR` · `웹사이트` · `닫기버튼` · `copyright gabia.inc` · `Logo` · `banner` · `MORE +` ·
   `24시간 동안 열지않음` · `모두 닫기` · `NEWS` · `Q A` · `franchise`
   **카테고리 이름도 메뉴가 아니다** — `메인메뉴`/`세트메뉴`/`사이드메뉴`, `덮밥 돈까스`/`우동 면류`.
   👉 DOM 이 비면 담지 말고 **네트워크 탭에서 자체 API 를 찾아라.** bhc 는 그렇게 6개→113개가 됐다.

4. **가격은 홀 매장가.** 배달앱 가격은 배달비가 얹혀 있어 쓰지 않는다.
   홈페이지에 없으면 `price: null` 로 두고 넘어간다 — **가격 0은 실패가 아니다.**
   단품과 세트가 따로면 **따로 담는다**(버거에서 계속 문제가 됐다).

5. **사이즈·옵션이 있으면 `이름 (사이즈)` 로.** 피자 L/M, 아이스크림 싱글레귤러/파인트 등.
   가격이 사이즈로만 갈리면 화면에서 자동으로 접어준다 — 담을 때는 **전부 담아라.**

6. **고기가 들어가면 원산지(`origin_raw`)까지.** 국산/브라질산은 값이 2.5배 차이다.
   중량(`weight_raw`)이 홈페이지에 있으면 같이 담는다.

7. **홈페이지에 가격이 없어도 «매장 주문사이트» 에는 있는 경우가 많다.**
   또래오래가 그렇다 → https://toreore.wmpoplus.com/store/59597 (대표 확인)
   `wmpoplus` 같은 프랜차이즈 공용 주문 플랫폼을 브랜드명으로 한 번 찾아봐라.
   ⚠️ 이건 **배달가일 수 있다.** 그럴 땐 `price_source` 에 `"store_order_site"` 로 적어 둔다.

8. 막히면 **Chrome 말고 앱(APK)** 쪽을 먼저 본다. 그래도 안 되면 **메뉴 이름만** 받고 나온다.

### ② 또래오래 — **주문사이트에 가격이 다 있다**
공식 홈페이지엔 가격이 없지만 **매장 주문사이트에는 나온다.** 대표가 직접 확인해 준 경로다:
👉 https://toreore.wmpoplus.com/store/59597
브라우저로 열어서 메뉴·가격을 받아라. 지금 DB 는 35개 중 34개가 채워져 있는데,
**값이 맞는지도 이 페이지로 대조**해 달라.
⚠️ 매장별 주문사이트라 **배달가일 수 있다.** 홀가와 다르면 `price_source` 에
`"store_order_site"` 라고 적어 두면 등록 세션이 판단한다.

## 되돌아올 때

JSON 을 `data/brand_menu_list/` 에 두면 등록 세션이 아래로 확인·반영한다.

```
python scripts/brand_status.py                                     # 미반영 JSON 목록
python scripts/brand_menu_import.py data/brand_menu_list/X.json    # 미리보기
python scripts/brand_menu_import.py data/brand_menu_list/X.json --apply
python scripts/publish.py --apply --menu-only
```
