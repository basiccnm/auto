## 1. 🔴 절대 지킬 것

### ① 지시 없이 실행하지 마라

대표님이 **가장 크게 화내는 지점**이다. 전역 CLAUDE.md 규칙 0에 자세히 있다.

- "이거 이상하네" = **고치라는 뜻이 아니다.** 목록에 적고 멈춰라
- "~해야 할 것 같은데" = 생각 중인 것이다
- 화면·파일을 보여주는 것 = 맥락 공유일 뿐이다
- **"해줘·해·처리해·고쳐·돌려"** 같은 명령형이 있을 때만 실행한다

### ② DB를 무작정 덮지 마라

> "비교하면서 DB를 변경해야지 무작정 변경은 XXX" — 대표님

**반드시 이 순서를 지킬 것:**

```
1. 조사만 한다 (DB 안 건드림)
2. "지금 값 vs 새 값" 비교표를 보여준다
3. 승인을 받는다        ← 여기까지 DB는 그대로다
4. 백업을 뜬다          ← 손대기 전에 먼저
5. 승인받은 것만 반영한다
6. compute_line_costs.py → healthcheck
```

### ③ 지어내지 마라

근거를 못 찾으면 **"못 찾았습니다"라고 말하고 멈춰라.** 그럴듯한 숫자를 만들면 안 된다.

실제 사고 예: 재료명이 `마라탕 소스/사골육수`로 두 성격이 묶여 있었는데, 이름만 보고 마라탕 값 12,000원을 **순대국밥 17개 메뉴에 먹였다.**

**판단 보류 중인 것 (추측으로 바꾸지 말 것):**
- 피치세트 M의 닭 900g — 공식에 양 표기 없음
- 피자 L의 재료별 배분 — 총 중량만 공식 근거 있음

→ 이 둘은 **대표님 결정이 있어야 움직인다.** 3절 2순위 표에도 올려뒀다.

### ④ 백업 없이 DB를 만지지 마라

모든 변경 스크립트는 이렇게 시작한다:

```python
b = os.path.join(BAK, "eolmanama_" + datetime.datetime.now().strftime("%Y%m%d_%H%M%S") + "_작업명.db")
shutil.copy2(DB, b); print("백업:", os.path.basename(b))
```

`data/backup/`에 현재 124개가 쌓여 있다(어제 것만 25개 넘음). 파일명 뒤에 작업명이 붙어 있어 되돌리기 쉽다.

### ⑤ 배포 전 healthcheck는 필수

```
python scripts/healthcheck.py     ← "전 항목 통과" 나와야 배포
```

실패하면 **고치고 나서** 배포한다. 어제 이걸로 3번 잡았다(도매>소매 역전, 조리법 문장 불일치, 재료명 오매핑).

## 2. 가격을 다룰 때의 원칙

### 소매·도매는 각각 조사한다 (계수 금지)

```
소매(manual_price)    = 소포장 실제가   (마트·소량)
도매(wholesale_price) = 업소용 대용량가 (18L·10kg·박스)
```

**`도매 = 소매 × 0.8` 같은 계산을 하지 마라.** 규격이 바뀌면 가격대가 통째로 달라진다.

### 배율이 크면 "물건이 다른 건 아닌지" 먼저 의심

참기름이 5.3배 벌어져서 규격 차이인 줄 알았는데, 집은 참기름 100%·가게는 **향미유**였다. 같은 이름이라도 등급·배합이 다르면 **재료를 갈라라.**

### 검색어는 좁게 나눠라

"다대기"로 뭉치면 쫄면장·냉면양념이 섞여 흩어짐 141%가 나온다.
→ **국밥 양념장 / 쫄면 양념장 / 순대국 양념장**으로 나눠 검색하면 대역이 잡힌다.

### 흩어짐이 곧 확신도다

| 흩어짐 | 뜻 | 조치 |
|---|---|---|
| 10~20% | 시세 확실 | 반영해도 됨 |
| 80%+ | 품목 정의가 흔들림 | **반영 말고 검색어부터 좁혀라** |

### 최저가를 그대로 쓰지 마라

같은 물건일 때만 최저가다. 실제로 걸린 것들:

- 곱창 소스 → **소시지 충진기·콩고물**이 최저가
- 드레싱 → **유통기한 임박 특가** 1,000원
- 컵 → 우리는 "컵+뚜껑+빨대"인데 **자판기 종이컵 8원**
- 피자소스 → 같은 오쉐프인데 2kg이 3kg보다 싼 이상값

### 재료명에 제품명·용량을 남겨라

> "나중에 다시 가격 검증하려면 상품명을 알아야지" — 대표님

- ✅ `금양 꼬소롬 후라이드파우더 5kg (교촌타입)`
- ❌ `치킨 후라이드파우더`

사이트 화면에도 이 이름이 그대로 나간다. **고객에게 정보를 주는 것**이다.

### ⛔ 일회용품은 건드리지 마라

테이크아웃 컵·젓가락 등은 **배달 자재**라 재료 원가와 성격이 다르다.

정확히는 — DB에 `테이크아웃 컵+뚜껑+빨대` **하나만 110원으로 들어 있다.**
**그대로 둬라.** 지우지도, 시세 재조사 대상에 넣지도, 새 일회용품을 추가하지도 마라.
(위 "최저가를 그대로 쓰지 마라"의 컵 8원 사례는 *이래서 조사를 안 한다*는 근거지, 다시 조사하라는 뜻이 아니다.)

## 4. 작업 방법

### 배포는 이걸로

**`갱신배포.bat`** 더블클릭 (프로젝트 루트)

```
1  시세만 갱신         KAMIS 수집 + 원가 재계산
2  화면만 다시 만들기   DB를 직접 고친 뒤
3  검사만              healthcheck
4  전체 + 배포         1~3 하고 olmanama.com 에 올림
```

수동으로 한다면 이 순서다:

```
python scripts/collect_kamis_all.py       ← 시세를 새로 받을 때만 (.bat 1번)
python scripts/compute_line_costs.py      ← DB 고쳤으면 필수
python scripts/gen_dishes.py
python scripts/gen_preview_html.py
python scripts/gen_prices_page.py         ← 빼먹기 쉽다. 안 돌리면 prices.html이 옛날 파일
python scripts/build_dist.py
python scripts/healthcheck.py             ← 통과해야 배포
cd workers/site-renderer && npx wrangler deploy
```

이 순서는 `scripts/update-deploy.ps1` 내용과 같다. **둘 중 하나를 고치면 다른 쪽도 맞춰라.**

> **`gen_sitemap.py`·`gen_og.py`는 이 파이프라인에 들어 있지 않다.**
> 의도적 제외인지 누락인지 확인 못 했다. 사이트맵·OG 이미지를 갱신해야 할 일이 생기면
> **혼자 파이프라인에 끼워 넣지 말고 대표님께 먼저 물어라.**

### ⚠️ 건드리기 전에 알아야 할 것들

**`.bat`에 한글을 넣지 마라.** cmd가 `goto` 위치를 바이트로 세다가 어긋나 깨진다(3번 실패했다). 한글은 `scripts/update-deploy.ps1`에 두고, `.bat`은 ASCII 런처로만 쓴다.

**`.ps1`은 UTF-8 BOM으로 저장해야 한다.** BOM 없으면 PowerShell 5.1이 ANSI로 읽어 한글이 깨지고 파싱 에러가 난다.

**한글 문자열 검사는 파이썬으로 해라.** PowerShell `.Contains('한글')`이 인코딩 때문에 false를 반환한다. 이것 때문에 "섹션이 통째로 없다"고 잘못 보고한 적 있다.

**로컬 서버를 띄웠으면 `build_dist.py` 전에 반드시 꺼라.** `_dist` 폴더를 잡고 있어서 빌드가 실패한다.

**KAMIS를 돌리면 도매>소매 역전이 생긴다.** `collect_kamis_all.py`에 자동 교정을 넣어뒀으니 실행 결과에 `역전 교정 N종`이 찍히는지 확인해라.

## 5. 대표님 스타일

- **답변은 짧게.** 표·선택지를 길게 나열하지 마라. 3~5줄, 질문은 한 줄
- **시각 사고형이다.** 글로 설명하지 말고 **화면·비교표**로 보여줘라
- **수정 요청은 모아서.** 하나씩 고치면 검토 흐름이 끊긴다. 목록에 적고 10개쯤 모이면 일괄 처리
- **"기다려·잠깐"이 나오면 즉시 멈춰라.** 하던 생각을 마저 실행하지 마라
- **대표님이 "이거 이상한데" 하면 일단 사실로 놓고 검증부터 해라.** 어제 지적받은 것은 거의 다 실제 오류였고, 틀린 쪽은 대부분 나였다. 반박하거나 해명부터 하지 말고 **열어서 확인한 뒤** 결과를 보고해라

## 6. 어제 내가 틀린 것 — 같은 실수 반복하지 마라

> ### 8건의 공통점: **확인 없이 단정했다.**
> 하나도 "몰라서" 틀린 게 아니다. **열어보면 5초면 알 것을 안 열어보고** 그럴듯한 설명을 붙였다.
> 의심되면 실제로 열어보고, 못 열면 모른다고 말해라. 아래는 그 8건이다.

1. **마라탕 소스를 순대국밥에 먹였다** — 재료 이름만 보고 넣었다
2. **미트박스를 소매로 뭉갰다** — 도소매 위치를 무시했다
3. **제품명을 지웠다** — 나중에 재검증이 불가능해진다
4. **업소용 단가와 소매를 섞어 비교했다** — 기준이 다른 값을 나란히 놓았다
5. **컨텍스트가 38% 남았는데 "다 찼다"고 했다** (두 번)
6. **PowerShell로 한글을 검사해 잘못된 결론을 냈다**
7. **lazy 로딩 이미지를 "깨진 이미지"로 오판했다**
8. **참기름 5.3배를 규격 차이로 설명했다** — 물건이 달랐다
