## 1. 🔴 가장 중요 — 이번에 새로 세운 원칙

### ① 소매·도매는 계수로 만들지 말고 각각 조사한다

지금까지 `도매 = 소매 × 0.7~0.85`로 만들어왔는데 **이게 틀렸다.**

```
소매(manual_price)    = 소포장 실제가   (마트·소량, 집에서 만들 때)
도매(wholesale_price) = 업소용 대용량가 (18L·10kg·박스, 매장 원가)
```

규격이 바뀌면 가격대가 통째로 달라진다. 계수는 **같은 규격 안에서** 유통 마진을 조정하는 값이지 규격을 건너뛰는 환산 도구가 아니다.

**배율은 품목마다 제각각이라 하나로 못 묶는다** (실측):

| 품목 | 소포장 ÷ 업소용 |
|---|---|
| 당면 | 2.2배 |
| 국밥 양념장 | 1.9배 |
| 쌀 | 1.8배 |
| 식용유 | 1.3배 |
| 버거 번 | 1.1배 |

### ② ⚠️ 배율이 크면 "물건이 다른 건 아닌지" 먼저 의심할 것

참기름이 5.3배로 벌어져서 규격 차이인 줄 알았는데 **아니었다.**
- 집 = 참기름 100%
- 가게 = 일반기름에 참깨향을 섞은 **향미유** (100%를 쓰면 원가가 안 나온다 — 대표 확인)

같은 이름이라도 등급·배합이 다르면 **다른 재료로 갈라야 한다.** 치즈도 같은 이유로 체다 슬라이스 / 모짜렐라로 쪼갰다.

### ③ 검색어를 좁게 나눠야 시세가 잡힌다

"다대기"로 뭉쳐 검색하니 쫄면장·냉면양념이 섞여 **흩어짐 141%**로 못 썼다.
대표 지시대로 **국밥 양념장 / 쫄면 양념장 / 순대국 양념장**으로 나눠 검색하니 대역이 딱 잡혔다.
(그리고 국밥과 순대국은 시판 제품이 애초에 겸용이라 하나로 묶어도 됐다)

### ④ 검색 결과의 "흩어짐"이 곧 확신도다

값이 촘촘하면(10~20%) 시세가 확실하고, 넓게 퍼지면(80%+) 품목 정의가 흔들린다는 뜻이다.
**흩어짐이 크면 반영하지 말고 검색어부터 좁힐 것.**

### ⑤ 최저가를 그대로 쓰면 안 되는 경우

- 곱창 소스 검색 → **소시지 충진기·콩고물**이 최저가로 잡힘
- 드레싱 → **유통기한 임박 특가** 1,000원
- 피자소스 → 같은 오쉐프인데 2kg이 3kg보다 싼 이상값
- 컵 → 우리 재료는 "컵+뚜껑+빨대"인데 **자판기 종이컵 8원**이 잡힘

**대표 원칙은 "실제 받을 수 있는 최저가"지만, 그게 같은 물건일 때만이다.**

### ⑥ ⛔ 일회용품은 건드리지 않는다

테이크아웃 컵·젓가락 등은 **배달 자재**라 재료 원가와 성격이 다르다. 대표 지시로 제외.

## 5. 🔴 시세 수집(KAMIS) — 원인과 조치

**증상:** 홈 우측 `📈 실시간 재료 가격` 카드가 통째로 비어 있었다.

**원인 3단계**

1. **코드가 무조건 "최신 2개 날짜"를 비교**했는데, KAMIS는 도매시장 시세라 **토·일엔 경매가 없어** 6~8건만 들어온다. 하필 주말 두 날이 잡혀 겹치는 재료가 4종뿐이었다.
   → **재료별로 값이 있는 최근 두 시점**을 각각 찾아 비교하도록 고침.
2. **마지막 정상 수집이 07-16**이라 이력이 재료당 1건뿐이었다.
   → `collect_kamis_all.py` 실행해서 68종 갱신(07-21 기준).
3. **주말 값이 튀어** 계란이 -42%로 표시됐다(일요일 7,042원 → 평일 4,081원. 07-15엔 4,254원이라 일요일 값이 이상치).
   → **수집 건수 20건 미만인 날은 비교에서 제외**. 요일이 아니라 건수로 걸러 공휴일도 커버.

**⚠️ 그리고 KAMIS를 돌리면 도매>소매 역전이 생긴다.**
KAMIS는 `manual_price`만 갱신하고 `wholesale_price`는 안 건드린다. 소매가 내려가면 예전 계수로 만든 도매가가 그대로 남아 역전된다(7건 발생).
→ **`collect_kamis_all.py`에 자동 교정을 넣어뒀다.** 실행 결과에 `역전 교정 N종`으로 찍힌다.

## 6. 작업 편의 도구 (새로 만듦)

### `갱신배포.bat` (프로젝트 루트) — 더블클릭

```
1  시세만 갱신         KAMIS 수집 + 원가 재계산
2  화면만 다시 만들기   DB를 직접 고친 뒤
3  검사만              healthcheck
4  전체 + 배포         1~3 하고 olmanama.com 에 올림
```

- 4번은 **healthcheck 통과해야만** 배포로 넘어간다
- 배포 직전 **"정말 배포할까요? (y)"** 한 번 더 묻는다

### ⚠️ 왜 .bat과 .ps1로 나눴는지 (건드리기 전에 읽을 것)

- **`.bat`에 한글을 넣으면 cmd가 `goto` 위치를 바이트로 세다 어긋나 깨진다.** 실제로 세 번 실패했다.
- 그래서 `.bat`은 **ASCII만** 두고, 실제 로직은 `scripts/update-deploy.ps1`에 있다.
- **`.ps1`은 반드시 UTF-8 BOM으로 저장**해야 한다. BOM 없으면 PowerShell 5.1이 ANSI로 읽어 한글이 깨지고 파싱 에러가 난다.

## 9. 대표님이 짚어주신 것 중 기억할 것

- **미트박스는 '도소매'** — 소매와 도매 사이. 소매로도 도매로도 쓰지 말 것 (내가 "미트박스=소매"라고 고치자 한 걸 대표가 되돌림)
- **모두닭집엔 닭 원육이 없다** — 551건 전부 부자재. 닭은 미트박스에서
- **치킨 원산지가 원가를 2.5배 가른다** — 국산 13,200 vs 수입 5,300. 가마로 순살은 **태국산**(매장 표시판 확인)
- **쌀은 지역·품종별 편차가 크다.** 밥이 중요한 업체 빼면 **국산 햅쌀 최저가**를 쓴다. 미국산 칼로스는 일식집 정도
- **신선우유는 유통기한 때문에 온라인 유통이 없다** — 네이버에 잡히는 건 멸균뿐
- **재료명에서 제조사·용량을 지우지 말 것** — 나중에 가격 재검증이 불가능해진다
- **사이트에 제품명을 보여주는 게 고객에게 정보 제공**이다
- **DB 변경 전에 비교표를 보여줄 것** — 무작정 덮으면 안 된다

## 10. 내가 이번에 틀린 것 (같은 실수 반복 방지)

1. **마라탕 소스 12,000원을 순대국밥 17개 메뉴에 먹였다** — 재료 이름이 `마라탕 소스/사골육수`로 두 성격이 묶여 있었는데 이름만 보고 넣었다. 대표가 "마라탕소스랑 사골육수는 다른 거"라고 잡아줬다.
2. **미트박스를 소매로 뭉갰다** — 도소매 위치를 무시하고 "미트박스=소매"로 구조를 바꾸자고 했다.
3. **제품명을 지웠다** — `금양 꼬소롬 후라이드파우더` → `치킨 후라이드파우더`로 줄였다가 되돌렸다.
4. **업소용 단가와 소매를 섞어 비교했다** — 황금올리브 기름값을 1,060원(업소용 블렌드)과 1,127원(소매 EV)으로 비교하고 "올랐다"고 보고했다. 대표가 "전은 이미 섞은 건데"라고 지적.
5. **컨텍스트가 38% 남았는데 "다 찼다"고 했다** — 두 번.
6. **PowerShell로 한글 파일을 검사해서 잘못된 결론을 냈다** — `.Contains('프랜차이즈 비교')`가 인코딩 때문에 false를 반환해 "섹션이 없다"고 판단. **한글 검사는 파이썬으로 할 것.**
7. **lazy 로딩 이미지를 "깨진 이미지 21개"로 오판했다.**
8. **참기름 5.3배를 "규격 차이"로 설명했다** — 실제로는 100% vs 향미유로 물건이 달랐다.
