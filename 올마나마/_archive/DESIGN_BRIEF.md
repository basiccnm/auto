# 얼마남아 — 화면 디자인 브리프 (전 페이지)

> Claude Design에 이 파일을 넣고 "이 정보에 맞춰 모바일 화면을 그려줘"라고 요청.
> 모든 데이터는 실제 DB 값. 최종 갱신 2026-07-18.

---

## 0. 사이트 개요

프랜차이즈 인기 메뉴의 **원가**를 보여주는 모바일 정보 사이트. 이름 "얼마남아" = "얼마 남나?"(마진).

- 규모: **브랜드 87 · 메뉴 349 · 요리(dish) 35 · 재료 262 · 발행 페이지 488**
- 두 가지 원가 기준이 공존 (헷갈리면 안 됨):
  | 축 | 기준 | 쓰는 곳 |
  |---|---|---|
  | **매장 원가율(도매 공급가)** | "판매가 대비 재료비 몇 %" | 브랜드 메뉴 페이지 |
  | **소매가(집에서 만들면)** | "집에서 만들면 재료비 얼마" | 요리사전 |
  | **재료 단가** | 재료 1kg/1개 시세 | 재료 시세 페이지 |

## 1. 디자인 시스템 (공통)

- **모바일 우선 — 360px(최소폰) 기준으로 먼저 완성**, 큰 화면은 유동 확장. **가로 스크롤 절대 금지**
- 글자: `clamp(하한, 유동, 상한)` — 화면비에 그대로 끌려가지 않게 상·하한 명시
- 색:
  - 포인트(accent) **주황 `#ff6b35`** (그라디언트 `#ff6b35→#ff9558`)
  - 글자 `#1a1d21` / 보조글자 `#6b7280` / 라인 `#e8eaed` / 배경 `#f5f6f8` / 카드 흰색
  - 등락: **오름 빨강 `#dc2626` ▲ / 내림 파랑 `#1a56b0` ▼ / 보합 회색 —**
- 카드형 UI, 둥근 모서리(12~16px), 얇은 회색 테두리
- 상단 고정 헤더: 로고 "얼마남아" + 작은 부제 "내가 시킨 그 메뉴, 원가 얼마?"
- 하단 공통 고지: 추정치·소매가 기준·브랜드 무관·쿠팡파트너스·공공데이터 출처 문구

## 3. 페이지별 상세

### ① 홈 `index.html`  🔴 재설계 대상

**현재 구성:** 히어로 → 검색창 → 오늘의 재료 시세 위젯(7종) → 입구 버튼 3개 → 원가율 높은 메뉴 top6

**입구 3개 (순서·이름 확정):**
1. 🍽️ **요리로 찾기** (맨 위, 주황 큰 버튼) — "짜장면·김치찌개… 집에서 만들면 얼마?"
2. 🏬 **브랜드로 찾기** — "치킨·피자·버거 등 13개 · 브랜드 87곳"
3. 📈 **재료 시세** — "매일 바뀌는 시세 · 재료 262종"

**🔴 새 요구사항:**
- **"원가율 높은 메뉴"** → 버튼/탭. 누르면 **리스트 5개** + **"전체 보기"**(전체 순위 페이지)
- **"원가율 낮은 메뉴"** 섹션 신규 — **리스트 5개** + **"전체 보기"**
- 높은순 ↔ 낮은순 **토글/탭**으로 나란히 두면 좋음

### ④ 브랜드 상세 `brand_{id}.html`

**목적:** 브랜드 로고 + 공정위 통계 + 메뉴 목록(원가율 뱃지).
**요소:**
- 로고 이미지, 공식 홈페이지 링크
- 📊 **공정위 가맹 통계**: 전국 가맹점 수 · 가맹점당 평균 연매출 (2023 공정위)
- 메뉴 카드 목록: 메뉴명 / 판매가 / 매장원가 / 원가율%
**예 (교촌치킨):** 전국 1,365개 가맹점 · 평균 연매출 7.5억
- 교촌오리지날 20,000 / 원가율 36.1%
- 허니콤보 26,000 / 37.4%
- 레드콤보 26,000 / 38.1%
- 반반오리지날 21,000 / 34.3%

### ⑤ 메뉴 상세 `menu_{id}.html`  (핵심 랜딩, 349개)

**목적:** "이 메뉴 원가가 얼마인가"를 한눈에. 검색어 "브랜드 메뉴 원가"로 유입되는 pSEO 랜딩.

**구성 (위→아래):**
1. 빵부스러기 `업종 › 브랜드` + 브랜드 로고·공정위 통계
2. `<h1>` "{메뉴} 원가"
3. **lead 문장**: "{브랜드} {메뉴}, 판매가 {가격}. 재료비 {매장원가}으로 판매가의 {원가율}%입니다."
4. **원가 카드** (가장 중요):
   - 판매가 크게
   - **원가율 막대 1개** (재료비 vs 나머지)
   - "나머지 {금액}에는 임대료·인건비·배달수수료·본사 로열티. **남는 돈이 아닙니다**"
   - 시세 등락 표시
   - 🏠 집에서 직접 만들면 {소매 재료비}
5. `<details>` "이 숫자는 어떻게 계산했나요?" (접힘)
6. `<details>` "🧾 재료 N가지 자세히 보기" (접힘) — 재료표: 재료명 · 양 · 도매가 · 소매가, 축/농/수/가 아이콘, 재료별 쿠팡 "복사" 버튼
7. 👨‍🍳 집에서 따라만들기 (레시피 단계)

**실제 예 (교촌 허니콤보):** 판매가 26,000 / 재료비(도매) 9,729 · 37.4% / 나머지 16,271 / 집밥 10,550
재료: 닭 정육(윙·봉) 1kg · 튀김가루 180g · 식용유(흡수분) 142ml · 치킨무 1세트 · 허니소스

> 🔴 사용자 지적: 카드가 아직 층이 많음 → **2겹 이하로 더 단순화** 여지.

### ⑦ 요리 상세 `dish_{slug}.html`

**목적:** 집에서 만들면 재료비 + 프랜차이즈 판매가 비교.
**구성:**
- "{요리}, 집에서 만들면 재료비 {금액}" (소매 기준)
- 표준 레시피(서빙 단위) · 재료표(소매가)
- **프랜차이즈 비교표**: 이 요리를 파는 브랜드별 판매가 vs 우리 재료비
- 시판 밀키트/소스 추천(쿠팡)
**예:** 부대찌개 재료비 13,445원 · 6곳

### ⑧ 재료 시세 `prices.html`  🔴 재설계 대상

**목적:** 원가 계산에 쓰는 **재료 262종 단가를 전부** 보여준다.

**🔴 현재 문제:** 첫 화면이 **가격 없는 이름 칩 262개 무더기**(세로 2,400px) → 시세 페이지인데 시세가 안 보임. 이걸 없애야 함.

**🔴 새 요구사항:**
- **"오늘 움직인 재료" 위젯 제거** 가능
- **262종 전체를 "가격 보이는 리스트"로** — 이름만 있는 칩 벽 ❌ → `재료명 · 소매가 · 등락` 행
- 상단 **분류 필터**(칩/탭): `전체 262` / `축산 51` / `농산 32` / `수산 13` / `가공 166` / `🛒 시판 22` / `🔄 매일시세` — "농수산물·공산품 전체 시세 보기" 느낌
- **검색창**
- 행 클릭 → **상세**: 큰 가격 + 매장 도매가(추정) + 이 재료 쓰는 메뉴 수 + 그 재료 비중 큰 메뉴 top3 링크

**재료 행 데이터 (실제 예):**
| 분류 | 재료명 | 소매가 | 종류 |
|---|---|---|---|
| 축산 | 소불고기용 쇠고기(호주산 냉동) | 16,000원/kg | 고정단가 |
| 농산 | 신선 채소 | 2,442원/kg | 🔄 매일시세 ▲+5.7% |
| 수산 | 생연어 필렛 | 22,000원/kg | 고정단가 |
| 가공 | 버거 번 | 400원/개 | 고정단가 |
| 시판 | 청정원 로제 스파게티소스 600g | 시판 | 고정단가 |

**요약 통계(상단):** 오름 N · 내림 N · 보합 N

## 5. 절대 지킬 것 (검증 완료된 부분 — 디자인만 손댈 것)
