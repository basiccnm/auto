## 1. 대표가 정한 규칙 (반드시 지킬 것)

### 판매가는 **홀 매장가**다
- 배달앱 가격은 **배달비가 얹혀 있다.** 실측: 맘스터치 **배달 = 매장 + 2,000원**
  (14개 중 12개가 정확히 +2,000. 셔틀딜리버리와 대조)
- 배달 사이트는 **검증용으로만** 쓴다. 가격 출처로 쓰면 원가율이 실제보다 낮아진다
- 59쌀피자 사이트는 「매장 방문 시 가격입니다」라고 **직접 밝힌다** — 이런 건 그대로 쓴다

### 세트 가격
- **맘스터치**: 세트 = 단품 + **2,500원**(음료+감자튀김). 대표 확인. 상세와 일치
- **버거킹**: 펜타치즈와퍼 단품 9,700 → 세트 11,900 = **+2,200원**.
  ⚠️ **다른 버거로 검증 안 했다.** 고정인지 모른다. 확인 전엔 일괄 적용 금지
- 세트는 **메뉴마다 상세를 눌러야** 나온다(100번 탭). 차액이 고정이면 계산이 훨씬 싸다

### 앱 가격의 「~」 표시
- `5,200원 ~` 의 물결표는 **단품 최저가**다. 세트를 고르면 그 이상
- 우리 원가율은 **단품 기준**이라 이 값이 맞다
- `app_menu_read.py` 가 note 에 「단품 최저가」로 남긴다

### 앱 정가 vs 앱 할인가
- 버거킹 앱은 한 메뉴에 값이 둘이다: `15,300원 / 10,700원`
- **큰 값이 정가**, 작은 값이 앱 할인가(한시적, 앱 주문 전용)
- **정가를 쓴다.** 할인가를 판매가로 쓰면 원가율이 부풀려진다
- note 에 「정가 X · 앱할인가 Y」로 둘 다 남긴다

### 경로 추측 금지
- 엔드포인트를 조합해 찔러보지 않는다 (2026-07-16 공공데이터 API 14개 추측 → **IP 차단**)
- **화면이 실제로 부르는 주소만** 쓴다. 문서(`데이터소스와스크립트.md`)에 있으면 그걸 쓴다
- 오늘도 같은 실수: 본도시락 코드를 `BF102`로 **추측**했다가 본죽 메뉴 87개를 잘못 넣었다.
  정답 `BF104` 는 문서에 **이미 적혀 있었다**

### 보고 규칙
- **DB 에서 센 숫자만** 보고한다. 화면에 출력된 건 「읽힘 N개(미저장)」로 구분해서 쓴다
- 오늘 「버거킹 가격 23 ✅」로 적었는데 `--apply` 를 안 붙여 **저장이 안 돼 있었다.**
  확인 없이 완료 표시를 한 것이 문제였다

### ② 앱이 띄우는 웹 주소 (앱이 껍데기인 경우)

APK 를 받아 설정 파일에서 `WEBVIEW_URL` 을 찾는다.

```
adb pull $(adb shell pm path <패키지>) app.apk
# assets/app.config (Expo) · strings.xml · JS 번들에서 WEBVIEW_URL / BASE_URL 검색
```

- **설빙** = Expo 앱. `assets/app.config` 에 `"WEBVIEW_URL": "https://sapp.sulbing.com"`
  → **폰도 에뮬도 필요 없다.** 그 주소를 브라우저로 열면 끝
- 스크립트: `scripts/brand_webview_tabs.js`(브라우저에서 탭 클릭) + `scripts/brand_webview_apply.py`(저장)
- ⚠️ Nuxt/Next 같은 SPA 는 탭 전환이 **클라이언트 라우팅**이라
  헤드리스 `--dump-dom` 으로는 **첫 탭만** 받는다(설빙 146개 중 13개만 나왔다).
  **브라우저에서 탭을 실제로 눌러야** 한다

## 4. 오늘 만든 스크립트

### 저장 계층 (공통)
- **`scripts/menu_price_store.py`** — 모든 가격 저장의 단일 출입구
  - `price_source`(official / naver_search / naver_place / human) · `price_note`
  - `samples_json`(지점별 표본) · `n_samples` · `agreed` · `prev_price` · `price_changed_at`
  - **`decided_at` 이 있으면 자동 수집이 건너뛴다** (사람 판단 보호)
  - `decide(samples, need)` — 3곳 중 2곳 일치면 채택, 다 다르면 중앙값 + 「지점별 차이 있음」
  - `N_STORES = {"맥도날드": 1, "버거킹": 1}` — **직영이라 전국 동일**인 곳만 1지점

### 메뉴판 정리
- **`menu_tab.py`** — 표준 탭 **단일 출처**

  - ⚠️ 업종 폴백은 **주력이 뚜렷한 업종만.** 한식·분식은 메뉴가 섞여서 넣지 않는다
- **`menu_tab_apply.py`** — 위 규칙을 DB 에 적용 (원본은 `category_raw` 에 보존)
- **`menu_board_clean.py`** — 메뉴가 아닌 줄 제거 + **꼬리표만 떼서 살리기**
  (「블랙시크릿오리지날 제품 이미지」 → 「블랙시크릿오리지날」. 통째로 지우면 진짜 메뉴가 사라진다)
- **`momstouch_set.py`** — 맘스터치 버거 세트 = 단품 + 2,500원
