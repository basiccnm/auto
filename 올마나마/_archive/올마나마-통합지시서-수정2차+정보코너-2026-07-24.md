# A부. 2차 수정 (대표 피드백 + 클로드웹 검토)

## §A1. "나머지" → "수익" 용어 확정 (대표 결정)
- 메뉴 상세의 "나머지 16,974원" → **"수익 16,974원"**, 홈의 "재료비 빼면 N원" → **"수익 N원"**. 혼재 표현 전부 "수익"으로 통일.
- 안내 문구를 눈에 띄게: "이 수익은 **순수익이 아닙니다.** 여기서 임대료·인건비·배달수수료·본사 로열티를 냅니다." — 원가 카드 안 강조 박스.
  - 강조 스타일 A/B 두 안(ⓐ accentsoft 주황 박스+볼드 ⓑ 빨간 계열 텍스트)을 로컬에 만들어 대표 선택. 빨강은 시세 ▲와 혼동 여지 있어 ⓐ 권장.
- 원가 카드 레이아웃: 금액을 양옆으로 벌리고 아래로 내리지 말고 **카드 안 표 형태로**:
  ```
  판매가        26,000원
  재료비(34.7%)  9,026원
  수익          16,974원   ← 게이지 바 유지
  ```

## §A2. 레시피 상세 — 재료 그리드 통합
- 메인/야채/양념 **그룹별로 그리드를 끊지 말고 한 그리드에 연속 배치.** 그룹 구분은 카드 안 색점+라벨(메인=주황, 야채=초록, 양념=회색).
- 그룹 우측 상단 소계 금액 제거 — 특히 "야채 19,482원" 같은 장보기 소계는 1인분 재료비(1,922원) 옆에서 오해 유발. 합계는 하단 바 하나만.
- 카드 3번째 줄 "진간장 500ml 3,006원" → **"500ml 3,006원"** (재료명 반복 제거 — 카드 제목에 이미 있음). 좁은 폰 줄바꿈으로 카드 높이 널뛰는 문제 해결.
- DB 원본 재료명(제조사·용량)은 수정 금지 — 표시 계층에서만 자를 것.

## §A3. 레시피 메인재료 그룹 데이터 교정 (승인 절차 필수)
- 확인된 오분류: 떡볶이에서 **어묵→'양념·소스'**, **고춧가루→'야채'**. 메인은 떡+어묵이어야 함.
- 기준: ① 메뉴명·요리 정체성 재료 = 메인 ② 향신·조미(고춧가루·간장·설탕·마늘) = 양념 ③ 야채 = 실제 채소만
- **74종 전수 스캔 → "요리명/현재 그룹/제안 그룹" 비교표 → 대표 승인 후** dish_def_ingredient 반영. 승인 전 DB 변경 금지. 원가 합계 무변화 확인.

## §A4. 레시피 목록 길이
- 74종 전체 출력(모바일 5,300px) → **초기 20개 + "더보기" 버튼.**
- **링크는 정적 HTML로 전부 유지, 숨김은 CSS로만.** JS로 링크 생성 금지(SEO). 필터·정렬 변경 시 더보기 카운트 리셋.

## §A5. 시세 페이지 — 마라탕 단가표 방식으로
- 한 재료 = 한 행(2줄) 구조 → **마라탕 단가표식 촘촘한 표(이름|가격|등락), PC 2열.**

## §A6. 메뉴 상세 — "데이터 보정 중" 노란 박스

# B부. 정보 코너 신설 (대표 확정안)

## 개념
- 이름: **"정보"**. 글 작성자는 운영자뿐(게시판 아님, 댓글·로그인·서버 불필요) → **기존 정적 생성 구조 그대로.**
- 목적: ① 쇼츠·인스타 카드뉴스의 상세 버전 수납 ② 검색 유입("배달 즉시할인" 등) ③ 애드센스 "자동생성 비중" 리스크 희석(사람 팩트 기반 글)
- **채널 분업: 쇼츠·인스타·카드뉴스 = 훅 하나만 간단히 / 사이트 글 = 전체 + 자세한 설명.** "자세한 건 사이트에서"로 유도. (인스타는 프로필 링크 가능 — 유튜브 설명란은 전화번호 인증 후)

## §B1. 구조
- 소스: `_posts/*.md` (front-matter: 제목·날짜·갈래·연관 쇼츠/카드뉴스·관련 내부링크)
- 생성기: `gen_posts.py` 신설 → 목록 `info.html` + 글 `info_{slug}.html`. theme.py 토큰·WRAP_CSS·P2_CSS 그대로 사용.
- 갈래(칩 필터): `배달앱 / 외식 구조 / 원가 / 재료 상식` — 레시피 목록과 같은 칩 패턴.
- GNAV에 **"정보"** 추가. **"마라탕 단가표"는 유지**(마라탕 쇼츠 캠페인 종료 시 네비에서 제거 예정 — 주석으로 남길 것).
- 신설 페이지 SEO: title에 검색어형 제목, meta description, canonical, **Article JSON-LD**, sitemap 등록. healthcheck 검사 대상에 포함.
- 광고: 기존 규칙 동일(하단 애드핏 1개, `.on` 옵저버 포함). 심사 중 광고 증설 금지.
- 글 템플릿: 제목 → 요약 한 줄 → 본문(소제목 2~4개) → **관련 내부링크 박스**(해당 메뉴 원가·시세·마라탕표) → 출처·추정치 고지.

## §B2. 발행 워크플로우 (운영 규칙으로 문서화할 것)
```
쇼츠/인스타/카드뉴스 1건 발행 → 그 편 대본+현장 팩트로 글 1개 초안(AI)
→ 대표 검수(1~2분, 숫자·현장정보 확인) → md 확정 → gen_posts → healthcheck → 발행
```

- 글의 가격 숫자는 사이트 DB 수치와 일치시킬 것(어긋나면 신뢰 훼손). 근거 없는 숫자는 "못 찾음"으로 보고하고 멈춤.
