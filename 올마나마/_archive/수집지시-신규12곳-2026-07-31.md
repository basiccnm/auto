## 왜 이 12곳인가

(`수집중단-삭제브랜드-2026-07-31.md`). **가맹점 수가 아니라 검색량이 기준이다.**

⛔ **여기 없는 브랜드를 마음대로 추가하지 마라.** 발견하면 이름만 보고한다.

## 이 12곳에서 특히 조심할 것

1. **베이커리 3곳(파리바게트·뚜레쥬르·던킨도너츠)은 품목이 수백 개다.**
   전부 받되, 카테고리(식빵·케이크·도넛·음료 등)를 **홈페이지 그대로** 나눠 담을 것.
   가격이 없으면 이름만 받아도 된다.
2. **뷔페 4곳(빕스·애슐리·매드포갈릭·서가앤쿡)은 «메뉴 가격» 이 아니라 «이용 가격» 이 핵심**이다.
   - 빕스·애슐리: **평일 점심/저녁·주말 요금**이 따로다. 성인/청소년/아동도 나뉜다
     → 메뉴명을 `평일 런치 (성인)` 처럼 적고 가격을 넣는다
   - 매드포갈릭·서가앤쿡: 단품 메뉴판이 있다. 일반 브랜드처럼 받으면 된다
3. **고깃집 3곳(명륜진사갈비·하남돼지집·고반식당)은 1인분 중량이 중요하다.**
   `weight_raw` 에 «180g» 같은 표기를 꼭 담고, **돼지·소 원산지(`origin_raw`)** 도 확인한다
4. **노브랜드버거는 단품/세트를 반드시 나눈다** — 버거에서 계속 문제가 됐다

## 되돌아올 때

JSON 을 `data/brand_menu_list/` 에 두면 등록 세션이 확인·반영한다.
**신규 7곳은 이미 DB 에 브랜드로 등록돼 있다**(비공개). slug 를 위 표대로 쓰면 그대로 들어간다.
메뉴판이 채워지면 등록 세션이 공개로 전환한다 — 빈 페이지를 라이브에 올리지 않기 위해서다.

```
python scripts/brand_status.py
python scripts/brand_menu_import.py data/brand_menu_list/vips.json --apply
python scripts/publish.py --apply --menu-only
```
