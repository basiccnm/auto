## 3. 어제 정한 원칙

1. **도매 = 업소용 대용량 실판매가 / 소매 = 소포장 실판매가.** 계수로 환산하지 않는다
2. **쿠폰가는 안 쓴다** — 할인에 할인이라 상시가만 쓴다
3. **거래처 상호는 사이트에 안 낸다** — `업소 실거래` `업소용 식자재몰` `온라인 소매` 로 표기.
   공공데이터(KAMIS·축평원·참가격·관세청)는 신뢰 근거라 그대로 남긴다
4. **가짜 데이터는 절대 안 넣는다** (스크래퍼 교란 목적이라도). 손님도 같이 속는다
5. **AI 크롤러는 차단** — 인용돼도 클릭이 안 오니 데이터만 뺏긴다
6. **공개/비공개 경계**: 메뉴 원가율·레시피·재료 시세는 공개(검색 유입), 원가계산기는 로그인

## 4. 어제 밟은 함정 (같은 실수 반복 금지)

| 함정 | 내용 |

| **한도 날조** | 쿠팡 한도를 "시간당 10회"로 적고 `(확인)` 주석까지 달았다. **실제는 분당 50회.** 문서로 확인하고 적을 것 |

| **schema.sql 오편집** | 컬럼을 엉뚱한 테이블(dish_ingredients)에 넣었다. 줄 위치 확인 후 편집 |

## 8. 육류 등급·원산지 — 어제 결론

### 문제
`소고기 양지` 하나에 값이 3~4배 갈린다. 지금은 15,200원/kg 하나로 뭉뚱그려 어느 쪽이든 틀린다.
```
한우 1++    35,000원/kg
한우 2등급   28,000원/kg
호주산 냉동   12,000원/kg
미국산 냉동    9,000원/kg
```

### 결론
- **소고기는 등급·원산지로 나눈다. 야채는 안 나눈다** (야채는 등급보다 시기가 지배)
- 나누는 방식은 **B안(등급 컬럼)** 이 유력 — 계산기에서 "우리는 호주산 써요"를 고를 수 있어야 하므로.
  단 DB 구조와 원가 계산 로직을 손봐야 한다. 최종 결정은 아직
- **수집처는 미트박스** — 상품명에 `[국산]` `한우거세 2등급`이 박혀 있어 목록만으로 갈린다.
  오늘얼마 앱은 원산지가 **태극기 이미지**라 목록 덤프로는 안 잡힌다(154건 중 국산 표기 1건뿐)
- 순서: **국산 먼저 확정 → 나머지가 수입 → 수입은 상세로 확인**

### 어제 확인된 유통 구조 (대표님 설명)
- 경매가는 **그날 값이 아니다.** 물량이 유통을 거쳐 며칠 뒤 반영된다
- **식자재마트·슈퍼** = 대량 선매입 → 값이 잘 안 움직인다 ← **우리가 지금 쓰는 값**
- **식당 도매** = 마트보다 싼 곳을 찾으니 경매에 민감, 그날그날 바뀐다
- **소매** = 움직이나 유통량이 많아 완충
→ 야채·고기를 "정확히" 맞추는 건 불가능하다. 어느 단계 기준인지가 본질이다

## 9. 원가계산기 — 방향 확정

### 왜 이게 1순위인가

## 10. SEO — 노릴 검색어와 담당 페이지

### 왜 이게 지금 제일 중요한가
GA4 7일 기준 **Organic Search 2건**뿐이다. 반면 조회수 1위가 "프랜차이즈 메뉴 원가"(66회)라
**메뉴 이름으로 오는 수요는 확인**됐다. 재료 시세로 오는 사람은 거의 없다(10회).
→ 재료별 페이지 348장은 **유출 차단이 주목적**이고, SEO 기대는 낮게 잡을 것.

### ① 도구형 — 지금 비어 있다. 최우선
`계산기`를 노리는 페이지가 **하나도 없다.** 원가계산기를 만들면 이 검색어들을 다 가져간다.

| 검색어 | 의도 |
|---|---|
| **음식원가계산기** · 음식 원가 계산기 | 도구를 찾는 사람 |
| **메뉴 원가 계산기** · 메뉴 계산기 | |
| **음식점 계산기** · 음식점 원가계산기 | 사장님 |
| **식당 원가계산기** · 요식업 원가계산 | 사장님 |
| **메뉴 도매 계산기** · 도매가 계산기 | |
| 원가율 계산기 · 재료비 계산기 | |
| 레시피 원가 계산 · 원가 계산 엑셀 | 대체재를 찾던 사람 |

→ **담당: `/calculator` (미제작)**
   제목 예: `음식점 원가계산기 — 메뉴 재료비·원가율 바로 계산 · 올마나마`
   ⚠️ 계산 기능 자체는 로그인 뒤에 둬도, **페이지와 설명은 공개**해야 색인된다.
   로그인 벽 뒤에 통째로 넣으면 검색에서 사라진다.

### ② 메뉴형 — 이미 유입이 있다. 강화
`교촌 허니콤보 원가` `빅맥 원가` `싸이버거 원가` 처럼 **브랜드+메뉴+원가**.
→ 담당: `menu_*` 378장. 이미 돌고 있으니 제목·설명을 이 형태로 맞출 것.

파생 검색어도 노릴 것:
- `치킨 원가` `피자 원가` `버거 원가` → `cat_*`
- `교촌치킨 원가율` `맘스터치 원가` → `brand_*`
- `원가율 높은 메뉴` `원가율 낮은 메뉴` → `ranking.html`

### ③ 집밥형 — 검색량은 크나 경쟁도 크다
`짜장면 만들기 재료비` `탕수육 집에서 원가` → `dish_*` 74장.
레시피 블로그와 경쟁하므로 **"재료비 얼마"** 각도로만 차별화한다.

