## A. DB / 데이터

1. 원산지 정리 — 태국산 닭발이 국산으로 등 오분류 바로잡기
2. 카테고리 마트/쿠팡식 재분류 — 치킨무·계란·신선해조류 등 오분류 (계란은 유제품/계란, 해조류는 수산)
3. 중복 병합 — 닭/닭도체, 감귤/귤/귤(일반), 느타리/느타리버섯, 무=무우
4. 껍데기 제거 — 과실류·과일과채류·버섯류·기타버섯류·신선해조류 등 KAMIS 통계값
5. 수산물·곡물도 분류·원산지 점검
6. 불필요 재료 — 삭제 말고 리스트로 뽑아 확인 (닭발 등 쓰는 건 남김)
7. 소매/도매 각각 실제값으로 — 경매가가 소매에 때워진 것, 통짜 0.7 추정 정리
8. 김(Kamis) vs 김 가격차 — 병합, 기준 통일
9. 등급 있는 것(소고기 등) A등급·B등급 표기
10. 도매값 제대로 추정 (어설프게 말고)
11. 가공수산으로 넣기 — 생연어필렛·흰살생선필렛·자반고등어·참치속·깍둑참치·스파이시참치·마른멸치·고등어필렛·볶음멸치·황태포·해물믹스
12. 정육 오분류 — 오돌뼈등심→돼지고기
13. 갑각류 — 새우젓→소스, 새우살→수산가공
14. 제품명에 "도매" 붙은 것 다 삭제
15. 해물믹스(20곳 사용) 분리 — 새우·오징어·홍합으로
16. ★ 삭제·분리할 때는 그 재료 쓰던 메뉴 재료도 같이 교체 (원가 안 깨지게)

## D. 요리 상세

28. 세로 재배치 — 제목 → 원가 요약 → 재료 → 하단 전체폭 레시피
29. 제목 = 원가 각도 "○○ 원가, 집에서 해먹으면 N원? (레시피)"
30. **재료 = 최소 구매(포장) 단위가 메인**, 1인분 사용량은 부가 (지금은 반대로 돼 있음 → 뒤집기)
31. 만드는 법(조리) = 1인분 기준
32. 만드는 법 = 단계별 카드 6개 말고 **카드 하나에 6단계 쭉**
33. 사진 3장(재료·조리·완성) 배치 (콜라보) — 페이지에서 어울리게
34. 재료표 = 새 레시피 재료 전부로 교체 + DB 매핑 (레시피 재료 = 재료표 100% 일치)
35. 우측 고정 = 쿠팡(레시피 재료) → 광고 → 브랜드 비교
36. 저장 버튼(레시피 카드 이미지, 단계 진행표시) + 공유 버튼(링크)

## E. 콘셉트 / 홈

37. "요리" → "레시피"로 명칭·성격 변경
38. 프랜차이즈 비교 테이블 우측 이동
39. 원가율 순위 제거 (B2B용으로 분리)
40. 홈 네비 4기둥 — 재료 · 브랜드 · 레시피 · 식단표
41. 식단표 = 유입 엔진 (달력·아점저 → 클릭 → 레시피 → 쿠팡)
42. 브랜드 원가 = 미끼 (놀래켜서 레시피로)

## F. 레시피 생성 (파이프라인)

43. 텍스트 말투 = 깔끔한 친근체 ("~하세요·~해주세요")
44. 사진 = 그냥 3장(재료·조리·완성), 배치는 올릴 때 코드가
45. 배경 요리별로 어울리게 (원목 고정 금지), AI 티 줄이기(실사감)
46. 재료 사진 = 실제 준비했을 때 현실적 상태 (손질·다진·시판 상태)
47. 조리 사진 = 실제 조리 중 (튀김=기름·가스불, 볶음=웍, 국물=냄비)
48. 인분 = 재료 최소 구매 단위 인식 (1인분어치만 못 사면 4~5인분)
49. 저장 카드 = 단계 진행표시("제작→추출→배치→출처"), 출처·라이선스 문구
50. 즐겨찾기·공유 버튼 강화, OG 미리보기
