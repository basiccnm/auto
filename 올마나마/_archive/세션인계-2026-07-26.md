### ⚠️ 이름 바꿀 때 조용히 깨지는 4곳 (실제 발생)
1. `dish_def.match_pattern` — 요리↔메뉴 매칭 정규식(gen_dishes 매핑 수 줄면 이것)

4. **재료명** 바꾸면 `price_<이름>.html` 고아 파일 남음 → 삭제 후 `gen_sitemap` 재실행

rename API가 2·3은 자동 처리한다. 1·4는 손으로 확인.

## 2. 밀키트·냉동 — 자동매칭 폐기, 사람 검수로 전환

**자동매칭은 쓰레기였다**: 421건 중 **50%가 중복**(한 상품이 최대 14개 메뉴에 붙음). 원인은 키워드 폴백(`"양념 치킨 냉동"`)이 여러 메뉴에 같은 결과를 준 것.

그래서:
- 라이브 배너 **끔** (`gen_preview_html.py`의 `SHOW_MEALKIT = False`)
- `scripts/mealkit_review_build.py` — 캐시(API 0회)로 메뉴별 후보 6개 생성 → `data/research/mealkit_review.json`
- 관리자 `/mealkit`에서 사람이 고르면 `menu_mealkit`에 저장 → **그게 정본**
- 검수 끝나면 `SHOW_MEALKIT=True` + 카드가 `menu_mealkit`을 읽게 바꾸고 배포

**후보 품질 확보한 것**
- **정품 우선 4단 정렬**: 정품+로켓 → 정품+일반 → 대체+로켓 → 대체+일반
- **경쟁 브랜드 배제** — BBQ 메뉴에 굽네·BHC 안 뜬다 (69건 걸러짐)
- 쓰레기 0건 — 기프티콘·금액권·포카칩·소프트콘·욕실화·훈연칩·충전기 등
- 브랜드 공식 제품 수집 완료(89브랜드 검색) — "BBQ 자메이카 통다리 바비큐" 같은 공식몰 상품이 실제로 있다

**남은 것**: 후보 없는 103개 메뉴는 추가 검색 필요. 검수 자체는 사람 클릭.

## 5. 밟은 함정 (반복 금지)

| 함정 | 내용 |
|---|---|
| **검색부터 하면 섞인다** | 식봄은 **카테고리(nid) 우선**, 검색은 카테고리에 없을 때만 폴백. 검색으로 편하게 가려다 오매칭 남발(염지닭 검색→대부분 염지제) |
| substring 매칭 | "쌀"이 햇쌀푸드에, "콩"이 콩나물에, "배"가 무료배송에 걸린다. 짧은 단어 부분매칭 금지 |
| 교차종 오염 | 소갈비 잎에 "멕시코 돼지갈비"가 섞여 있었다. 종 차단 필터 필수 |
| 소포장 /kg 뻥튀기 | 220g 오렌지 → 7,500원/kg. `pack_kg>=1`로 업소용만 |
| 다른 세션 서버 죽이기 | `python.exe` 3개를 죽였는데 그중 다른 세션 프리뷰 서버가 있어 그쪽 빌드가 깨졌다. **포트 확인하고 내 것만 죽일 것**(8803=관리자, 8809=다른 세션) |
| 빌드 중단 = _dist 유실 | `_dist` 잠금으로 rmtree 실패 후 파일이 915→801개로 줄었다. 실패하면 **`rm -rf _dist` 후 클린 재빌드** |
| CF 엣지 캐시 | 배포해도 옛 페이지가 계속 보인다(`CF-Cache-Status: HIT`). 쿼리스트링 캐시버스팅도 안 먹힘 → **대시보드에서 Purge**(CF API 토큰 없어 코드로 못 함) |
| 1015 자폭 | 라이브 검증을 연달아 하면 우리 IP가 막힌다. 검증 사이에 2~3초 간격 |
| 고아 페이지 | 재료명·메뉴명 바꾸면 옛 슬러그 파일이 `_dist`에 남는다. 이번에 9개 정리(무·배추·쌀·양배추 KAMIS 4 + 브랜드명 슬러그 5) |
