# 얼마남아 — UI / 화면 수정사항 (2026-07-20)

대표님이 스샷으로 짚어준 화면 문제 정리. 데이터(DB) 문제와 별개로 **레이아웃·표시** 수정만 모음.

---

## 1. 이모티콘

- **요리 목록 카드: 기본 접시(🍽️) 이모티콘 제거.** 지금 절반 이상이 고유값 없는 접시라 구분도 안 되고 의미 없음. 목록에선 아예 빼고 깔끔한 텍스트 카드로.
- 상세 페이지 섹션 이모티콘도 절제 (섹션마다 여러 개면 산만) — 섹션당 1개 이내 또는 제거.

## 2. 재료 시세 (시세표 페이지)

- **갱신주기 → 숫자 뱃지.** 지금 "고정/자동갱신" 글자 대신 `1일` / `30일` 뱃지 + 색(매일=초록, 월갱신=회색). 신뢰도가 한눈에.
- **레시피 사용 재료에 마크.** 실제 요리에 쓰는 재료 앞에 표시(dish 매핑으로 자동). "이건 진짜 쓰는 재료" 구분.
- **필터를 두 축으로 분리.** 지금 `축산물/농산물/수산물` + `시판/자동갱신`이 같은 줄에 섞여 헷갈림.
  - 품목축: 정육 · 채소 · 과일 · 수산 · 유제품/계란 · 면/떡 · 양념/소스 · 가공/냉동 (마트·쿠팡식)
  - 갱신축: 자동갱신(매일) · 고정/참고가
  - 두 축을 나란히 두지 말고 분리.

## 3. dish 페이지 — 재료 위치 & 레시피 위치 (핵심)

현재: 왼쪽에 재료+원가, **오른쪽 좁은 칸에 "집에서 따라 만들기"** → 레시피를 길게 못 씀(4단계로 갇힘).

수정: **세로 한 줄기로 재배치**
```
[상단]      원가 요약 (판매가 vs 재료비 · 원가율)
[중간]      재료 상세 (도매가 / 소매가)
[하단·전체폭] 집에서 따라 만들기  ← 넓게, 길게 (재료그룹·단계설명·팁·FAQ)
[우측·고정]  쿠팡 상품            ← 스크롤 내내 따라다니며 노출
```
- 레시피를 좁은 우측칸에서 **하단 전체폭으로** 내려 길게 (SEO·모바일 유리).
- **쿠팡은 우측 고정**(sticky) — 스크롤해도 계속 보이게.
- **레시피 유무로 페이지 모드 분기**: 있으면 "집에서 만들기", 없으면(아메리카노 등) 그 자리에 "쿠팡 제품 추천".

## 4. 요리 목록 화면 ("요리로 찾기")

지금: 68종 전체를 한 번에 나열, 정렬 기본 "재료비 낮은 순", "0곳 판매" 섞임 → 요리 늘수록 무너짐.

수정:
- **카테고리 진입 우선** — 전체 다 뿌리지 말고 카테고리 안에서.
- **검색 상단 고정** — 많아지면 검색이 주 통로.
- **기본 정렬 = 판매처 많은 순** — 유명·대중 요리 위로. "0곳 판매"는 뒤로/숨김.
- **모바일 2열 + "더 보기"** — 무한 나열 금지.
- **비조리 메뉴(아메리카노·음료류) 요리 목록에서 제외** — 브랜드 원가에는 유지. (레시피 유무로 자동 분기)
