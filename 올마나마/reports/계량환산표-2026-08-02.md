# 계량 환산표 — 레시피 본문용 (2026-08-02 · 리서치 반영판)

> 🔴 **레시피 본문에만 쓴다.** 재료 목록(구매용)에는 넣지 않는다 — 거기는 g·팩이 맞다.
> 대표: *"레시피 본문에만 두면 되지 재료에 둘 필요가 있어? 그건 우리 구매하는 건데"*
>
> 목적: **위아래로 안 움직이고 레시피만 보고 요리할 수 있게.**

---

## 1. 🔴 핵심 — 같은 「1큰술」이라도 무게가 2배 넘게 차이 난다

같은 숟가락으로 떠도 재료마다 다르다. **밀도 차이**다.

| 재료 | 1큰술 | 액체 대비 |
|---|---:|---|
| **고추장·된장** | **30g** | **2배** ← 질퍽해서 많이 떠진다 |
| 소금 | 18g | 1.2배 |
| 물·우유·간장·식초 | 15g(=15ml) | 기준 |
| 버터 | 14g | |
| 설탕 | 12.5g | |
| 밀가루 | 8~9g | 0.6배 ← 가볍다 |
| 전분 | 7.5g | 0.5배 |
| 고춧가루 | 7g | 0.5배 ← 제일 가볍다 |

> 대표: *"고추장이나 질퍽한거는 엄청 많이 떠져"* — 맞다. 30g이다.
> **「15g = 1큰술」로 뭉뚱그리면 고추장은 반만 들어가고 고춧가루는 두 배 들어간다.**

---

## 2. 부피 기준 (도구)

```
계량스푼 1작은술 =  5ml
계량스푼 1큰술   = 15ml
계량컵  1컵     = 200ml
종이컵          = 180ml   ← 꽉 채우면 200이지만 흘리지 않게 담으면 180
```

**⚠️ 「1컵」과 「종이컵 1」은 다르다.** 20ml 차이 난다.
본문에는 **「종이컵 1」이라고 못박아 쓴다** — 계량컵 없는 집이 많다.

### 밥숟가락은 기준으로 쓰지 않는다
규격이 없어 20~25ml로 제각각이고, 가루는 「수북이 1개 ≈ 1큰술」인데 액체는 「2개 ≈ 1큰술」이라
재료에 따라 또 달라진다. **본문에 「밥숟가락」이라는 말은 안 쓴다.**
(대표: *"거의 양은 비슷해 그냥 적당히 해"* — 그래서 **큰술로만 적고** 밥숟가락 환산은 안 넣는다)

---

## 3. 재료별 환산 — 이 표대로 적는다

### ① 액체 — 물·간장·식초·맛술·기름·우유·액젓
```
 5ml = 1작은술
15ml = 1큰술
30ml = 2큰술
90ml = 종이컵 ½
180ml = 종이컵 1
```
부피=무게로 봐도 된다 (15ml ≈ 15g).

### ② 장류·질퍽한 것 — 고추장·된장·쌈장·다진마늘·물엿·마요네즈
```
15g = 큰술 ½      ← 액체의 절반만 담긴다
30g = 1큰술
60g = 2큰술
```
🔴 **여기가 제일 많이 틀리는 자리다.**

### ③ 가루 — 밀가루·전분·튀김가루·부침가루
```
 3g = 1작은술
 8g = 1큰술
100g = 종이컵 ⅔
150g = 종이컵 1
```

### ④ 고춧가루 — 가루 중에서도 더 가볍다
```
 2g = 1작은술
 7g = 1큰술
```

### ⑤ 소금·설탕 — 무겁다
```
소금  6g = 1작은술 · 18g = 1큰술
설탕  4g = 1작은술 · 12g = 1큰술
```

### ⑥ 알갱이 — 참깨·통후추·깨소금
```
2g = 1작은술 · 6g = 1큰술
```

### ⑦ 환산하지 않는 것
- **개수로 세는 것** — 계란 1개 · 두부 ½모 · 대파 1대 → 그대로
- **100g 넘는 고기·채소** — `돼지등심 300g` 을 「종이컵 1½」로 쓰면 오히려 헷갈린다 → **g 그대로**

## 4. 본문 쓰는 형식

```
❌  전분을 넣고 버무려주세요
❌  감자전분 100g을 넣고              ← 양은 있지만 가늠이 안 된다
✅  감자전분 100g(종이컵 ⅔)을 넣고
✅  고추장 30g(1큰술)을 넣고
✅  고춧가루 7g(1큰술)을 넣고
```

- **재료명 + g/ml + (가늠 단위)** 순서
- 가늠 단위가 어색하면 넣지 않는다 (§3-⑦)
- **한 단계에 쓰는 재료를 다 적는다** — 위로 올라갈 일이 없어야 한다

### 잘 쓰인 본보기 — 탕수육 (이미 이 수준)
```
2. 감자전분 100g, 달걀 50g, 물 150ml를 섞어 튀김옷을 만들어주세요
4. 감자전분 15g과 물 30ml를 섞어 전분물을 만들어주세요
```
전분이 **튀김옷 100g · 소스 15g** 으로 갈려 있다. 이게 기준이다.

|---|---:|
| ✅ 대부분 단계에 양이 있음(60%+) | **0개** |
| ⚠️ 일부 단계에만 | 32개 |

부대찌개는 재료 17종인데 5단계 전부 양이 없다. 마라탕도 10종에 0개다.
**74개 전부 다시 써야 한다.**

레시피가 부실한 것은 **제대로 된 레시피를 리서치해서 우리 말로 바꾸고 양을 정확히 넣어 다시 쓴다**(대표 지시).
