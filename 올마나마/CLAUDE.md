| `/` 대시보드 | 메뉴·재료 수, 메뉴명 검사 미처리, 밀키트 검수 진행률. 할 일은 주황색 |
| `/menus` 메뉴 | 메뉴명·판매가 수정. `menu_name_audit` 제안을 클릭 한 번으로 적용 |
| `/ingredients` 재료 | 도매가 수정(근거 필수). 필터: 추정근거 / 원산지티어 / 미사용 |
| `/mealkit` 밀키트·냉동 | 메뉴별 쿠팡 후보 고르기. × 로 후보 삭제, 해당없음 처리 |

**신설 테이블** (`scripts/admin_store.py` SCHEMA):
`menu_mealkit`(사람이 고른 밀키트) · `mealkit_rejected`(×로 지운 후보) · `menu_name_audit`(메뉴명 검사 결과)

### ⚠️ 메뉴명·재료명을 바꿀 때 같이 봐야 하는 곳
이름만 바꾸면 조용히 깨지는 게 있다(2026-07-25 실제 발생):
1. **`dish_def.match_pattern`** — 요리↔메뉴 매칭 정규식이 옛 이름을 가리키면 연결이 끊긴다(gen_dishes 매핑 수가 줄면 이것)
2. **`menus.recipe_steps`** — 레시피 본문에 메뉴·재료명이 글자로 박혀 있다
3. **`menu_ingredients.composition`** — "○○ 곁들임" 같은 라벨에도 메뉴명이 들어간다
4. **재료명 변경 시 `price_<이름>.html` 고아 파일** — 슬러그가 이름 기반이라 옛 파일이 남는다. 삭제 후 `gen_sitemap` 재실행
   (rename API는 2·3을 자동 처리한다. 1·4는 손으로 확인)
