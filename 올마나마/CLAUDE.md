## 전역 태그(GA·애드센스·검증 메타) 넣는 곳

- 현재 들어있는 것: GA4(`G-SZ4HE98GLC`) · 애드센스(`ca-pub-9423286569078244`) · 네이버 사이트확인 메타 · 파비콘 링크들
- ⚠️ `gen_og.py`·`fetch_logos.py` 등에도 `FAVICON` 문자열이 있지만 그건 **브랜드 로고 파비콘**이라 의미가 다르다. 건드리지 말 것.

## 🆕 본문 폭(레이아웃) 넣는 곳 — 2026-07-24 신설

**`scripts/theme.py` 의 `WRAP_CSS` 상수 하나.** 생성기 4개가 전부 이걸 가져다 쓴다.

- 이전에는 `.wrap`/`.top .in`의 max-width가 생성기 4곳에 각각 박혀 있어서 PC 폭이 960/1060/700으로 제각각이었다 → 페이지 이동 시 가로폭이 튀고 GNAV만 본문보다 넓게 삐져나옴
- 현재: **모바일 520 / PC 960**, 브레이크포인트 840px 통일
- **폭을 바꾸려면 여기만 고친다.** 생성기에서 `.wrap`/`.top .in` max-width를 다시 쓰지 말 것
- ⚠️ `gen_preview_html.py`의 `HEAD`는 f-string이 아니라 `.format()` 템플릿이라 `/*WRAPCSS*/` 플레이스홀더 + `.replace()`로 주입한다(`/*THEMEVARS*/`와 같은 방식)

## 🛠 관리자 백엔드 (2026-07-25 신설) — 또 만들지 말 것

```bash
python scripts/admin_server.py        # → http://127.0.0.1:8803
```

**로컬 전용(127.0.0.1).** 수정은 `data/eolmanama.db`에 즉시 저장되고 재생성·재배포에도 살아남는다.

| 화면 | 하는 일 |
|---|---|
| `/` 대시보드 | 메뉴·재료 수, 메뉴명 검사 미처리, 밀키트 검수 진행률. 할 일은 주황색 |
| `/menus` 메뉴 | 메뉴명·판매가 수정. `menu_name_audit` 제안을 클릭 한 번으로 적용 |
| `/ingredients` 재료 | 도매가 수정(근거 필수). 필터: 추정근거 / 원산지티어 / 미사용 |
| `/mealkit` 밀키트·냉동 | 메뉴별 쿠팡 후보 고르기. × 로 후보 삭제, 해당없음 처리 |

**신설 테이블** (`scripts/admin_store.py` SCHEMA):
`menu_mealkit`(사람이 고른 밀키트) · `mealkit_rejected`(×로 지운 후보) · `menu_name_audit`(메뉴명 검사 결과)

### ⚠️ 메뉴명·재료명을 바꿀 때 같이 봐야 하는 곳
이름만 바꾸면 조용히 깨지는 게 있다(2026-07-25 실제 발생):
1. **`dish_def.match_pattern`** — 요리↔메뉴 매칭 정규식이 옛 이름을 가리키면 연결이 끊긴다(gen_dishes 매핑 수가 줄면 이것)
2. **`menus.recipe_steps`** — 레시피 본문에 메뉴·재료명이 글자로 박혀 있다
3. **`menu_ingredients.composition`** — "○○ 곁들임" 같은 라벨에도 메뉴명이 들어간다
4. **재료명 변경 시 `price_<이름>.html` 고아 파일** — 슬러그가 이름 기반이라 옛 파일이 남는다. 삭제 후 `gen_sitemap` 재실행
   (rename API는 2·3을 자동 처리한다. 1·4는 손으로 확인)
