# 레시피 다시 쓰기

## 왜

지금 74개 요리 중 **양이 대부분 적힌 레시피가 0개**다(2026-08-02 실측).
42개는 아예 없고 32개는 첫 단계에만 있다. 그래서 **위 재료 목록으로 올라가야만** 요리가 된다.

> 대표: *"사람들이 레시피를 보면서 재료 모르니깐 위에 보면서 할 순 없어"*
> *"레시피 안에 재료를 또 다시 한번 글로 적어둬야 해"*

**재료 목록은 「사기 위한 것」이고, 레시피 본문은 「만들기 위한 것」이다.** 목적이 다르니 둘 다 필요하다.

---

## 규칙 (어기면 다시 쓴다)

### 1. 각 단계에 재료명 + 양을 다 적는다
```
❌  전분을 넣고 버무려주세요
❌  감자전분 100g을 넣고              ← 양은 있지만 가늠이 안 된다
✅  감자전분 100g(종이컵 ⅔)을 넣고
```
그 단계에서 쓰는 재료는 **하나도 빠짐없이** 이름과 양을 적는다. 위로 올라갈 일이 없어야 한다.

### 2. 계량은 `reports/계량환산표-2026-08-02.md` 를 따른다

🔴 **같은 1큰술이라도 무게가 4배 차이 난다.** 뭉뚱그리지 말 것.

| 재료 | 1큰술 |
|---|---:|
| 고추장·된장·다진마늘·물엿 | **30g** |
| 소금 | 18g |
| 물·간장·식초·맛술·기름 | 15g(=15ml) |
| 설탕 | 12g |
| 밀가루·튀김가루 | 8g |
| 전분 | 7.5g |
| 고춧가루 | 7g |

```
계량스푼 1작은술 5ml · 1큰술 15ml
종이컵 180ml        ← 「종이컵 1」이라고 못박아 쓴다
계량컵 1컵 200ml     ← 「1컵」과 종이컵은 20ml 다르다
```

⛔ **「밥숟가락」이라는 말을 쓰지 않는다.** 규격이 없어 20~25ml로 제각각이고,
가루는 「수북이 1개 ≈ 1큰술」인데 액체는 「2개 ≈ 1큰술」이라 재료마다 또 달라진다.

⛔ **환산하지 않는 것** — 계란 1개·두부 ½모·대파 1대는 그대로.
100g 넘는 고기·채소는 「종이컵 1½」로 쓰면 오히려 헷갈리니 **g 그대로**.

### 3. 조리 단계를 갈라 재료를 배정한다

같은 재료가 두 단계에 걸치면 **양을 나눠 적는다.** 이게 되어야 화면에서 단계별로 묶을 수 있다.

```
2. 감자전분 100g(종이컵 ⅔), 달걀 50g(1개), 물 150ml를 섞어 튀김옷을 만들어주세요
4. 감자전분 15g(2큰술)과 물 30ml(2큰술)를 섞어 전분물을 만들어주세요
```
전분이 **튀김옷 100g · 소스 15g** 으로 갈려 있다. 이게 기준이다.

### 4. 우리 말로 바꾼다
리서치한 레시피를 **그대로 베끼지 않는다.** 표현을 우리 말투로 바꾸고 양을 우리 재료 기준으로 맞춘다.
- 존댓말 `~해주세요` 로 통일
- 한 단계는 두 문장 이내
- 불 세기·시간을 넣는다 (`중불에서 2분간`)

### 5. 우리 DB 재료와 맞춘다
`dish_ingredients` 에 있는 재료를 쓴다. 본문에만 나오고 재료 목록에 없는 재료가 생기면
**그 재료를 목록에 추가해야 한다** — 없는 재료로 요리하게 두지 않는다.
반대로 목록에 있는데 본문에 안 나오면 그것도 문제다. **양쪽이 맞아야 한다.**

---

## 6. 인분 기준 — 요리 성격대로 두되 **명시**한다

⛔ 전부 1인분으로 통일하지 않는다. 1인분만 끓이는 감자탕은 없다.
```
밥·면·1인 요리   1인분      김밥(1줄) · 돈까스 · 칼국수 · 쌀국수 · 콩국수
국·탕·찌개       2인분      감자탕 · 갈비탕 · 김치찌개
통으로 파는 것    그 단위     족발 700g · 빙수 1그릇
```
- DB `dishes.serving` 이 정본이다. **재료 양이 이 기준에 묶여 있다**
- 리서치한 레시피가 4인분이면 **우리 기준으로 환산**해서 쓴다 (4인분 → 1인분이면 ÷4)
- 본문 첫머리나 제목에 기준을 **반드시 명시**한다

---

## 7. 🔴 리서치 — 브라우저로 원본을 직접 읽는다

**만개의레시피는 `WebFetch` 로 403 이 난다.** PC(`www.`)·모바일(`m.`) **둘 다** 막힌다.
⚠️ **속도 때문이 아니다.** 1회 호출에도 즉시 403 이고, 요청 과다면 429 가 나야 한다.
   **자동 수집 도구 자체를 거부**하는 것이라 천천히 불러도 안 열린다.

→ **브라우저 도구로 열면 본문이 그대로 나온다** (2026-08-02 확인)
```
mcp__Claude_Browser__navigate    → https://m.10000recipe.com/recipe/<번호>
mcp__Claude_Browser__get_page_text
```

🔴 **모바일(`m.`) 주소를 쓴다.** PC 판보다 낫다 —
   조리순서에 **번호가 붙어** 나오고, 광고·추천 레시피 잡음이 적어 파싱이 쉽다.

```
⛔ WebFetch 로 시도하고 403 났다고 포기하지 마라
⛔ 검색 결과 요약만 보고 쓰지 마라
⛔ 2차 출처(블로그 정리글)로 우회하지 마라 — 원본이 열리는데 우회할 이유가 없다
✅ 브라우저로 m.10000recipe.com 을 열어 읽는다
```

### 같은 요리라도 **여러 개를 본다**
> 대표: *"한 군데서만 받지 말고 만개도 여러 가지가 있을 거 아니야. 동일해도 여러 개를 체크해"*

- 한 요리에 **최소 3개 레시피**를 직접 열어 읽는다
- 양이 「1팩·1봉지·2개」처럼 무게가 아닌 경우가 많다 → **여러 개를 대조해 g 을 잡는다**
- 인분이 제각각이다 → 전부 **우리 기준으로 환산한 뒤** 비교한다

### 대조표를 남긴다 (초안 파일에 필수)
```
| 출처 | 인분 | 돼지고기 | 간장 | 설탕 | … |
|---|---|---|---|---|---|
| A(URL) | 4인분 | 600g | 4큰술 | 2큰술 |
| B(URL) | 2인분 | 300g | 2큰술 | 1큰술 |
| C(URL) | 4인분 | 500g | 3큰술 | 2큰술 |
| **우리(1인분)** | 1인분 | **150g** | **15ml** | **12g** |
```

### ⛔ 출처가 없으면 버린다
> 대표: *"확인이 안 되면 어디서 어떻게 얻는 게 좋은지 확인하고, 출처 없으면 다 무시해"*

원본을 못 읽었으면 **그 레시피는 쓰지 않는다.** 기억이나 추측으로 채우지 않는다.
3개를 못 채우면 못 채운 대로 적고 «출처 부족» 으로 표시한다.

## 하는 순서

1. `dishes.recipe_steps` · `dish_ingredients` · `dishes.serving` 을 읽어 현재 상태를 본다
2. **브라우저로 원본 레시피 3개 이상을 직접 열어 읽는다** (§7)
3. **대조표를 만든다** — 출처별 재료·양을 우리 인분 기준으로 환산해 나란히 놓는다
4. 위 규칙대로 다시 쓴다
5. **검수** — 아래 표로 자가점검
6. 결과를 **파일로** 낸다(`reports/레시피초안/`). 홈페이지에 바로 넣지 않는다

## 검수표 (한 요리마다)

| 검사 | 기준 |
|---|---|
| 각 단계에 재료명 | 그 단계에 쓰는 재료가 다 적혀 있나 |
| 각 단계에 양 | g/ml 이 적혀 있나 |
| 가늠 단위 | 큰술·종이컵이 붙어 있나 (환산하지 않는 것 제외) |
| 환산 정확 | 고추장 30g=1큰술 · 고춧가루 7g=1큰술 로 맞나 |
| 단계 분리 | 소스가 따로면 갈라져 있나. 겹치는 재료의 양이 나뉘어 있나 |
| 재료 일치 | 본문 재료 = 목록 재료 (한쪽에만 있는 게 없나) |
| 말투 | 존댓말 · 한 단계 두 문장 이내 · 불 세기와 시간 |

⛔ **DB 에 바로 쓰지 않는다.** 초안은 파일로 내고, 사람이 확인한 뒤 반영한다.
