## 2. 앱에 없거나 못 고른 10종

| 재료 | 사유 |
|---|---|
| 푸주 | 검색 결과 0건 — 앱에 없다 |
| 쌀 | 상위에 찰흑미만. 일반 백미는 더 내려가야 나옴 |
| 배추 | 상위가 전부 양배추·김치. 신선 배추는 상위에 없음 |
| 고구마·오이 | 상위가 전부 가공품(유탕·샐러드·피클) |
| 파프리카·피망 | **앱에 냉동만 있다.** 생물 취급 안 하는 듯 |
| 삼겹살 | 검색이 엉뚱한 결과를 반복해서 냄(판두부·알배기배추). 앱 검색 쪽 문제로 보임 |
| 해물모듬·두부피 | 규격이 우리 것과 달라 보류 |

→ 상위 10건만 읽어서 생긴 한계다. **스크롤해서 더 읽으면 대부분 해결된다.**

## 3. 확인된 함정 (다음에 또 밟는다)

1. **검색 결과 0건이면 앱이 추천상품을 대신 깐다** — 그대로 두면 엉뚱한 상품이 그 재료 시세로 둔갑
2. **가격 순서가 카드마다 다르다** — `9,660원 / 2,500원 / 28%` 처럼 값이 하나 더 낀다.
   순서로 집지 말고 **할인율(%) 앞뒤**로 정가·판매가를 읽어야 한다
3. **총 건수만 보고 판단하면 앞 검색의 상품이 그대로 잡힌다** — 목록이 두 번 연속 같을 때까지 폴링
4. **부분문자열 함정** — `배추`가 **양**배추를, `옥수수`가 옥수수**전분**을 잡는다
5. **용도 표기를 가공품으로 오해하지 말 것** — `판두부(부침찌개겸용)`의 '부침·찌개'는 용도지 다른 물건이 아니다
6. **소포장이 섞이면 원/kg가 튄다** — 깻잎 20g짜리가 46,500원/kg으로 잡혔다. 업소용은 대용량 쪽을 봐야 한다
