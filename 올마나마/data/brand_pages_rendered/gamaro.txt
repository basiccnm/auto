HTTP 오류 404.0 - Not Found
 찾고 있는 리소스가 제거되었거나, 이름이 바뀌었거나, 일시적으로 사용할 수 없는 상태입니다.
 가능성이 높은 원인:
 지정한 디렉터리 또는 파일이 웹 서버에 존재하지 않습니다.
 URL을 잘못 입력했습니다.
 URLScan 등의 사용자 지정 필터 또는 모듈에서 파일에 대한 액세스를 제한합니다.
 가능한 해결 방법:
 웹 서버에서 콘텐츠를 만드십시오.
 브라우저 URL을 검토해 보십시오.
 실패한 요청에서 이 HTTP 상태 코드를 추적하는 추적 규칙을 만드십시오. 실패한 요청에 대한 추적 규칙을 만드는 방법을 자세하게 보려면 여기
를 클릭하십시오. 
 자세한 오류 정보:
 모듈 IIS Web Core
 알림 MapRequestHandler
 처리기 StaticFile
 오류 코드 0x80070002
 요청한 URL https://www.gamaro.co.kr:443/menu/
 실제 경로 d:\hosting\gamaro.co.kr\menu\
 로그온 방법 익명
 로그온 사용자 익명
 추가 정보:
 이 오류는 파일이나 디렉터리가 서버에 존재하지 않는다는 것을 의미합니다. 파일이나 디렉터리를 만든 다음 다시 요청해 보십시오.

HTTP 오류 403.14 - Forbidden
 웹 서버가 이 디렉터리의 내용을 표시하지 못하도록 구성되었습니다.
 가능성이 높은 원인:
 요청된 URL에 대해 기본 문서가 구성되지 않았으며 서버에서 디렉터리 검색 기능이 사용되지 않습니다.
 가능한 해결 방법:
 디렉터리 검색 기능을 사용하지 않으려면 기본 문서가 구성되어 있고 파일이 존재해야 합니다.
 IIS 관리자를 사용하여 디렉터리 검색을 사용하도록 설정하십시오. IIS 관리자를 엽니다.
 [기능] 보기에서 [디렉터리 검색]을 두 번 클릭합니다.
 [디렉터리 검색] 페이지의 [작업] 창에서 [사용]을 클릭합니다.
 사이트 또는 애플리케이션 구성 파일에서 configuration/system.webServer/directoryBrowse@enabled 특성이 true로 설정되었는지 확인하십시오.
 자세한 오류 정보:
 모듈 DirectoryListingModule
 알림 ExecuteRequestHandler
 처리기 StaticFile
 오류 코드 0x00000000
 요청한 URL https://www.gamaro.co.kr:443/brand/
 실제 경로 d:\hosting\gamaro.co.kr\brand\
 로그온 방법 익명
 로그온 사용자 익명
 추가 정보:
 이 오류는 URL에 문서가 지정되지 않았고 웹 사이트나 애플리케이션에 기본 문서가 지정되지 않았으며 웹 사이트나 애플리케이션에 대해 디렉터리 나열 기능이 사용되지 않는 경우 발생합니다. 서버 콘텐츠의 보안을 유지하기 위해 이 설정이 사용되지 않도록 설정했을 수 있습니다.
