- 내용 확정됨: A집(할인5000,옵션부풀림) vs B집(할인2000,옵션정상). 옵션 붙일수록 B집이 싸진다
  - 치즈피자 13,900(양쪽 같음) / 콤비 +4,000(A) vs +2,000(B) / 토핑2개 +4,000(A) vs +2,000(B)
    → 소계 A 21,900 · B 17,900 → 할인 A −5,000 · B −2,000 → **결제 A 16,900 · B 15,900 (차이 1,000)**
  - ⚠️ 2026-07-24 정정: 원래 "토핑2개 **동일**"이라고 적혀 있었는데 **틀린 기록**이었다.
    토핑이 같으면 B집 결제액이 17,900이 되어 같은 줄의 15,900과 안 맞는다.
    정본은 `remotion/src/cards/card_anchor.js`의 `calc` — 화면 숫자는 전부 거기서 계산해 온다
  - 타파법 2가지(카드엔 안 밝히고 사이트로 유도): ①기본만이면 할인 큰 집 ②옵션 붙이면 옵션 싼 집
- 카드 7장: ⓪표지(썸네일) ①훅 ②문제 ③옵션표 ④결과 ⑤이유 ⑥유도(→olmanama.com)
- **올마볼 3D**(`OlmaBall3D.jsx`) — SVG로 직접 그린 노란 3D 볼. 표정8+소품2. 대표님 준 제미나이 이미지 기반, 이모지 세트 아님
- 낙서 플립북(`DoodleStory.jsx`) — 하단 여백에 12초 졸라맨 싸움(A집 KO→B집 승리)
- **미해결/검수 중**: 글자 크기·여백·겹침을 여러 번 왔다갔다 함. 문제·옵션 카드 두 장만 겹침 고친 것 확인. 나머지 카드는 코드 반영됐으나 눈으로 확인 안 됨
- 폰트: 제목 Black Han Sans, 본문 Noto Sans KR (셋 다 SIL OFL 무료)
- `mode` prop: `card`(인스타 캐러셀, 상단240 4:5크롭대비) / `video`(쇼츠·틱톡, 상단100+하단620 낙서자리)

## 2. 카드뉴스 관련 파일 (`_shorts/remotion/src/cards/`)

```
card_anchor.js    편 데이터(문구·숫자·표정·낙서 지정)
CardNews.jsx      카드 한 장 레이아웃 (mode=card/video)
CardVideo.jsx     6장+표지 넘기는 영상(12.2초)
OlmaBall3D.jsx    3D 볼 (표정8·소품2)
BallSheet3D.jsx   볼 점검 시트
Doodle.jsx        카드별 짧은 낙서 루프(캐러셀용)
DoodleStory.jsx   12초 이어지는 싸움 낙서(영상용)
DoodleSheet.jsx   낙서 점검 시트
```

렌더 명령(대표님이 시킬 때만):
```
카드 1장   npx remotion still CardNews out/cards/c0.png --props='{"i":0,"mode":"card"}'
영상       npx remotion render CardVideo "out/배달옵션꼼수.mp4"
```
