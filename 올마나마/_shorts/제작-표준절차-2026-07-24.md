## 1. 화면(판)부터 만든다 — 대사보다 먼저

숫자를 `card_anchor.js`의 `calc`에 넣고, 합계·결제액은 **계산해서** 쓴다. 손으로 적으면 어긋난다.

```js
calc: { base: 13900, A: {combo:4000, topping:4000, sale:5000}, B: {...} }
sum = base + combo + topping   /   pay = sum - sale
```

**판 만들 때 지킬 것 (옛 카드뉴스에서 난 결함을 구조로 막은 것)**

- **글씨 최소 68px.** 작으면 안 읽힌다. 대신 문구를 짧게 깎는다
- **A집·B집은 좌우가 아니라 위아래로.** 판 안쪽이 920px인데 큰 숫자 두 개를 나란히 두면 각 칸이 230px밖에 안 나와 숫자가 서로 붙는다. 옛 카드에서 `16,900`과 `15,900`이 한 덩어리로 읽힌 게 이 이유였다
- **모든 텍스트 nowrap.** 두 줄로 흘러내리면 레이아웃이 무너진다
- **캐릭터는 판 밖에만.** 판 안으로 들어오면 글자를 가린다

## 2. 한 소스 두 판형 — `mode`만 다르게

| | short | card |
|---|---|---|
| 크기 | 1080×1920 | 1080×1080 |
| 쓰는 곳 | 쇼츠 | 인스타 캐러셀 |
| 판 위치 | top 250 | top 210 |
| 캐릭터 | 아래 가운데 크게 | **판 위쪽 바깥**(정사각엔 아래 여백이 없다) |

**표지는 쇼츠 훅을 그대로 정사각으로 쓴다.** 캐러셀 1번 장이 곧 피드 썸네일이라, 쇼츠에서 본 얼굴이 이어져야 한다.

## 3. 대본 → TTS → 실측

```
_shorts/voice/script.json 작성       ← 숫자는 한글로 ("만 삼천구백 원")
python make_voice.py script          ← edge-tts, 무료
python normalize.py                  ← −13 LUFS 통일
python trim.py                       ← 앞뒤 무음 측정 → trim.json
```

- **화면 글은 아라비아 숫자(`13,900원`), TTS 대본만 한글 숫자.** 말풍선에 "만 삼천구백 원"이 뜨면 안 된다
- **속도는 +70%.** +35 → +45 → +50 → +70으로 올렸고 전부 잘 들린다. 쇼츠 시청자는 빠른 템포에 익숙하다
- ⚠️ **마라탕 2·3·5편 타이밍은 +35%로 잰 값이다.** 그 편들을 다시 뽑으려면 rate를 되돌리거나 trim을 다시 재야 한다

`lines_*.js`의 `sec`/`head`는 **trim.json 실측값을 그대로** 넣는다. 손으로 적으면 더빙이 어긋난다.

## 4. 조립할 때 아는 사람만 아는 것

**🔴🔴 LEAD는 0.2. 절대 늘리지 마라 — 늘리면 쇼츠가 죽는다.**

조회수 사고(2026-07-24): 배달 1편만 **11회**, 다른 편들은 **1,400회**. 유일한 차이가 LEAD였다.
- 터진 편들: LEAD **0.2** (0.2초 만에 목소리 시작)
- 죽은 배달편: LEAD **0.6** (0.6초 동안 소리 없이 정지 → "멈춘 영상"으로 오해받고 넘겨짐)

**첫 0.5초가 쇼츠의 생사다.** 무음 정지가 길면 알고리즘이 초반 이탈을 잡아 배포를 끊는다.
"소리가 화면보다 빠르다"를 잡겠다고 LEAD를 늘리면 안 된다 — 그건 훅 파트(0.12)로 잡는다.

```
LEAD 0.2     목소리 없는 정지. 이 값 고정. 늘리면 죽는다
훅 파트 0.12 목소리는 나오는데 말풍선만 없는 최소 구간
```

**말풍선은 글자를 줄이지 않고 쪼갠다**
- 한 조각 최대 16자 → 폰트는 항상 72로 유지
- 자르는 자리 우선순위: **문장 끝 > 쉼표 > 띄어쓰기**
- 쉼표는 **뒤에 공백이 있는 것만** 경계로 본다 (`13,900`의 쉼표에서 잘리면 안 된다)

**마지막 사이트 카드의 `ask`를 꼭 넘긴다.** 안 넘기면 배달편인데 "마라탕 궁금한 거 있으면"이 뜬다.

## 6. 사이트 상세 글 — 채널 분업

**쇼츠·인스타는 훅 하나, 사이트는 전부.** "자세한 건 사이트에서"로 유입을 만든다.

`_posts/*.md`에 front-matter + 본문. 지원 문법: `## 소제목` · `**굵게**` · 목록 · **표** · `cards:` 카드 묶음.

- **카드 이미지는 본문에 흩지 않고 글 맨 위에 3개씩** 모은다 (front-matter `cards:`)
- 글에는 **개념 설명 + 근거 + 해결책**을 넣는다. 이번 편은 앵커링 어원(닻) → 카너먼·트버스키 1974 룰렛 실험 → 배달앱에서 작동하는 자리 4곳 → 해결책 2가지
- **해결책은 숫자로 떨어지게.** "뒤집히는 지점 = 할인 차이 ÷ 옵션 1개당 차이" 같은 공식이 저장을 부른다

```
python scripts/gen_posts.py     ← _preview/info.html + info_{slug}.html
```

## 8. 인스타 캐러셀 발행 — 여기서 두 번 막혔다

```
python post_ig_carousel.py --id {id}             ← 미리보기
python post_ig_carousel.py --id {id} --publish   ← 실제 발행
```

**🔴 함정 1 — JPEG 색 포맷.** `ffmpeg -q:v 3`만 주면 `yuvj444p`로 나오는데 **인스타는 4:2:0만 받는다.** 400 오류(`Only photo or video can be accepted as media type`)로 튕긴다.
```
ffmpeg -i card.png -pix_fmt yuvj420p -q:v 3 card.jpg    ← 반드시 pix_fmt 지정
```

**🔴 함정 2 — 클라우드플레어 엣지 캐시.** 이미지를 고쳐 재배포해도 엣지가 옛 파일을 준다. 인스타가 옛 파일을 받아 또 튕긴다.
→ 큐의 이미지 주소에 **`?v=2`** 를 붙여 통과시킨다.

**🔴 인스타 음악은 앱에서 올릴 때만 붙는다.** API로도, 발행 뒤 수정으로도 못 넣는다. 음악이 필요하면 그 편은 앱 업로드로 돌린다.

**🔴 스레드는 무조건 반말.** 인스타·유튜브·사이트는 존댓말인데 스레드만 반말이다.
존댓말로 쓰면 광고처럼 읽힌다. 이미지도 **2장까지** — 6장 올렸더니 뒷장을 아무도 안 봤다.

**🔴 스레드 글은 API로 못 지운다.** 앱에 `threads_delete` 권한이 없어 `code 10`으로 거부된다.
잘못 올리면 스레드 앱에서 직접 지워야 한다. **그래서 `--publish` 없이 미리보기로 먼저 확인받는다.**

**🔴 캐러셀과 릴스를 같은 날 올리지 않는다.** 같은 내용이 하루에 두 번 나가면 도달이 갈린다. 하루 이틀 띄운다.

## 11. 썸네일·훅 규칙 — 조회수 7편 실측 (2026-07-24)

7편 올려보고 확인한 것. n=7이지만 신호가 뚜렷했다.

| 편 | 조회 | 썸네일 특징 |

| 마라탕 팍팍 담으면 완벽한 호구 | 1,000 | 음식 사진 |

**11회짜리만 혼자 4개가 겹쳤다** — 음식 없음 · 큰 숫자 없음 · 닻(0.3초에 못 읽음) · 빈 배경.
반대로 1,400짜리는 **음식 or 큰 숫자를 화면 절반에** 박았다.

**🔴 썸네일 3원칙**
1. **화면 절반에 음식 사진 or 큰 숫자.** 닻 같은 추상 기호 금지 — 0.3초에 뭔지 몰라 넘긴다
2. **"이득 / 남는다 / 아낀다" 이득 단어.** (개이득 방향과 일치)
3. **숫자는 정확하게.** 16,974가 17,000보다 세다. 어중간한 숫자가 진짜 같다

**🔴 훅은 질문 말고 결론.** `?`로 물으면 생각하게 되고, 생각하면 넘긴다.
- ❌ "할인 큰 집이 더 비싸다?" (배달편 11회)
- ✅ "지금 이거 모르면 피자값 3천 원 버리는 중" (손해·나·결론)
- ✅ "마라탕 이렇게 담으면 만 원 아낌" (이득·나·숫자)

첫 프레임에 결론·충격 숫자를 이미 터뜨린다. 궁금하게 만들지 말고 꽂아버린다.

## 12. 가격원가 쇼츠 — 필수 규칙 (2026-07-24 확정)

**🔴🔴 쇼츠 대사는 무조건 반말 + 웃기게.** (2026-07-24 확정)
뉴스앵커처럼 딱딱하면 안 넘긴다. 병맛·드립·"ㅋㅋ"가 들어가야 산다.
- ❌ "원재료값은 단돈 4,200원입니다" (딱딱)
- ✅ "원가가 4,200원이래 ㅋㅋ" / "다 때려박아도 4,200원 ㅋㅋㅋ"
- 사장님볼은 반말로 발끈("야 그건 원래 다 그래!" "임대료! 인건비!") — 이게 웃김
- ⚠️ 단, **숫자·팩트·원산지는 정확하게.** 톤만 가볍고 내용은 안 틀린다
- 스레드 반말과 결이 같다 ([[threads-casual-tone-two-images]] 참고 — "~다"체 아닌 구어체)


**🔴 모든 원가 쇼츠에 무조건 넣는다: "원재료 기준 원가입니다"**
- 첫 화면 상시 자막으로 박는다. 조리·인건비·임대료·수수료는 안 다룬다는 선긋기
- 없으면 "인건비 뺐네" 반박이 매번 달린다. 애초에 못 달게 막는다
- 공지 대사에서도 한 번 짚어준다: "우린 원재료 원가만 봅니다"

**🔴 중량은 ×1.2 보수적으로.** 정확한 그램수는 브랜드가 공개 안 한다.
넉넉히 잡아 원가를 실제보다 **높게** 보여준다 → "실제론 더 쌌다"는 역풍이 없다.
화면엔 "넉넉히 잡은 값"이라고 밝히면 반박 원천봉쇄.

**🔴 재료 종류는 공식 홈페이지 원산지·토핑 표시로 검증.** 우리 DB는 추정이라 틀린다.
(도미노 포테이토: DB엔 양배추·당근이 잘못 들어가 있었고 버섯·옥수수·마요가 빠져 있었다)
자잘한 채소 그램수는 화면에 안 박고 **재료 종류만** 보여준다.

**🔴 마무리는 "할인 강한 이유"로 인사이트를 준다 (까기 아님).**
피자업체가 5천~1만 원씩 할인을 강하게 지르는 건 **원가율이 낮아서**다(15% → 만 원 깎아도 남음).
"왜 이렇게 할인이 많은지" 구조를 알려주는 게 개이득. 사장 욕하는 게 아니다.

## 14. 업로드 자동화 — 2026-07-25 구축

**유튜브·틱톡이 자동화됐다.** 편 하나 만들면 이 두 줄이면 나간다.
```bash
python upload_yt_api.py --id {편id} --publish    # 유튜브 (API)
python upload_tt.py     --id {편id} --publish    # 틱톡 (브라우저)
```

| 플랫폼 | 방식 | 상태 |
|---|---|---|
| 유튜브 | **API** (`upload_yt_api.py`) | ✅ 자동. 최초 1회 `auth_yt.py` |
| 인스타 캐러셀·스레드 | API (`post_ig_carousel.py`·`post_threads.py`) | ✅ 자동 |
| 틱톡 | 브라우저 (`upload_tt.py`) | ✅ 자동 |
| 인스타 릴스 | `upload_ig.py` | ❌ 파일칸 셀렉터 깨짐 |
| **네이버 클립** | 폰 앱 전용 | **스킵**(2026-07-25 결정) |

**네이버를 뺀 이유** — 폰으로만 올릴 수 있어 매 편 손이 간다. 주 11개 페이스에서 제일 먼저 무너지는 게 이것. 지속 가능한 것만 남긴다.

### 🔴 유튜브 — 브랜드 계정 함정 (두 번 당했다)

**올마나마 채널은 `dndmotor1@gmail.com` 계정의 브랜드 계정 「엠볼」 아래에 있다.**
계정만 고르면 개인 채널(=**사장픽**)로 올라간다. 실제로 사장픽에 두 번 올라가 지웠다.

인증 순서: 계정 선택 → **「계정 또는 브랜드 계정 선택」 화면에서 `엠볼`** → 경고(고급→이동) → 권한 허용
- 이 화면이 안 뜨면 `prompt="select_account consent"` 가 빠진 것
- `open_browser=False` 로 URL 을 찍게 해서 원하는 브라우저에서 열어야 제어가 된다
- **업로드 전에 `📺 업로드될 채널` 로그를 반드시 눈으로 확인**한다(스크립트가 찍어준다)

**업로드된 영상은 비공개(private)로 잠긴다.** 구글 미인증 앱 정책이라 우회 불가.
→ 스튜디오에서 **공개로 바꾸는 클릭 한 번**이 남는다. 제목·설명·태그는 자동으로 다 들어간다.

**OAuth 동의화면은 「프로덕션」이어야 한다.** 「테스트」면 토큰이 7일마다 만료된다.

### 🔴 틱톡 — 한글이 깨진다

`box.type()` 으로 한 글자씩 치면 **한글 조합이 섞여 깨진다**(실제 발생):
`차지합니다`→`테차지합니다` · `비싸다`→`사비싸다` · `게 아니라`→`이게 아니라`

→ **클립보드 붙여넣기**로 넣는다(`navigator.clipboard.writeText` + `Ctrl+V`). 조합 과정이 없어 깨질 수가 없다.
붙여넣기 뒤 **Esc** 로 해시태그 자동완성 팝업을 닫는다(안 닫으면 엉뚱한 태그가 붙는다).

**커버(썸네일)는 손댈 필요 없다** — 첫 프레임이 곧 썸네일이라 자동으로 맞게 잡힌다.
**음악은 안 넣는다** — 말로 설명하는 구조라 음원을 깔면 내용이 묻힌다.

⚠️ `uploader_profile` 은 크롬 하나만 열 수 있다. 이전 실행 창이 남아 있으면
`크롬이 바로 종료됐습니다 (exit=0)` 가 뜬다 → 그 프로필 크롬만 종료 후 재실행.
