## 목소리 (TTS)

`_shorts\voice\` — 엣지 TTS(마이크로소프트). **무료, API키 없음.**


### 🔴 여기서 크게 데었다

- **속도를 +40%까지 올렸다가 되돌렸다.** 짧게 쪼갠 대사를 빠르게 읽으니 뚝뚝 끊기고 안 들렸다.
  해법은 속도가 아니라 **문장을 완결형으로 길게 쓰는 것**이었다. 천천히 읽어도 내용이 더 들어간다.
- **edge-tts는 문장 앞뒤에 무음 0.3~1.0초를 붙인다.** 13줄이면 15초가 무음이다.
  파일을 자르지 않고 `<Audio trimBefore/trimAfter>`로 재생할 때만 건너뛴다.
- 목소리 끝을 딱 끊으면 마지막 음절이 잘려 "뚝" 소리가 난다. **0.12초 페이드아웃** 필수.

## 영상 조립 — `src\shorts\Talk.jsx`

**대사 배열(`LINES`)이 곧 영상이다.** 좌표를 손으로 잡지 않는다.

```js
{
  who: "올마", with: "교촌", sec: 5.69, head: 0.27, gap: 0.4,
  parts: [
    { text: "닭 정육 팔백오십 그램", face: "시치미", sec: 3.44, upto: 1, hot: 0 },
    { text: "튀김가루",             face: "시치미", sec: 2.25, upto: 2, hot: 1 },
  ],
}
```

- `sec`/`head` = **`voice\trim.json`의 실측값**. 손으로 고치지 말 것
- `gap` = 대사 뒤 숨. **여기로 전체 길이를 59초에 맞춘다**
- `parts` = 한 대사가 읽히는 동안 바뀌는 화면들. sec 합이 대사 길이와 같아야 한다
- `upto/hot` = 원가 장부에 몇 번째 재료까지 띄우고 어느 줄을 강조할지
- `total` 합계줄 · `minus` 차액 계산식 · `big` 큰 숫자 · `site` 사이트 화면 · `noBubble` 자막 숨김

### 🔴 안전 영역 — 3편에서 데였다

카드를 `top:80`에 붙였더니 **쇼츠 목록 썸네일에서 첫 줄이 잘렸다.**
유튜브·틱톡·인스타 모두 위아래를 UI가 덮거나 크롭한다.

```
위    1920 × 10% = 192px   제목·시간 표시가 덮는다
아래  1920 × 20% = 384px   제목·채널명·좋아요 버튼이 덮는다
우측  1080 × 12% = 130px   버튼 줄이 세로로 선다
```

- **카드는 top 200부터** 시작한다
- **캐릭터 발끝은 1660을 넘기지 않는다** (캐릭터 top 1130 기준)
- 중요한 글자·숫자는 절대 이 밖으로 내보내지 않는다

### 화면 규칙
- **한 화면에 캐릭터 둘까지.** 넷을 세우면 표정이 안 보인다
- 말하는 쪽 1.28배 + 통통 튐, 듣는 쪽 1.0배. **말하는 동안 미세하게 흔들린다**(멈추면 그림 같다)
- 말풍선은 **화면 가운데에 크게**, 꼬리 방향으로 말하는 사람을 표시. 넘치면 두 줄
- 숫자·장부는 **어두운 카드를 깔고** 그 위에. 배경이 알록달록해서 그냥 얹으면 안 읽힌다
- 카드는 화면 **위쪽**, 캐릭터·말풍선은 아래쪽

## 🔒 템플릿 규격 — 3편부터 고정 (2026-07-22 확정)

**내용의 순서는 바꾸지 않는다.** 4편부터는 이 8단계를 그대로 쓰고 숫자와 브랜드만 갈아끼운다.

```
① 훅          "OO 하나 팔면 N원 남는다?"      ← 사람들이 아는 오해를 던진다
② 인사         소상공인 여러분 힘내세요
③ 브랜드 주장   "저희는 이래서 비쌉니다"        ← 먼저 이유를 대야 뒤가 '검증'이 된다
④ 재료 검증     ①②③④⑤ 장부가 한 줄씩 쌓인다
⑤ 합계 + 정적   영상의 70% 지점에서 처음 공개
⑥ 차액 계산     판매가 − 재료비 = 남는 돈
⑦ 사장님 반전   "그래서 사장님 모셨습니다" → "저희 손엔 몇천 원"
⑧ 마무리       추정치 안내(말로) + 소상공인 힘내세요
```

**바뀌는 것:** 브랜드 · 메뉴 · 숫자 · 브랜드볼 색과 로고
**계속 개선하는 것:** 화면 배치 · 자막 크기 · 효과음 · 캐릭터 연출 · 문구

### 왜 고정하나
1~3편이 매번 구조가 달랐다(1편 소매, 2편 39초 한방공개, 3편 62초 지연공개).
**결과가 좋아도 뭐 때문인지 알 수 없다.** 조회수도 266 / 361로 사실상 같은 수준이라
아직 데이터로 최적화할 표본이 없다. 먼저 같은 걸 반복해서 채널 정체성을 만든다.

### 터뜨리려면 훅을 테스트한다
2편은 **361회 노출에 유효 조회 47회(13%)** 였다. 87%가 첫 몇 초에 넘겼다.
본편이 아무리 좋아도 여기서 막히면 알고리즘이 4시간 만에 배포를 끊는다(2편 실측).
그래서 **본편은 그대로 두고 훅만 편마다 바꿔** 조회율을 비교한다.

```
A  도발 숫자   "하나 팔면 16,966원 남는다?"      ← 3편
B  극단 대비   "26,000원 치킨, 재료는 9,000원"
C  반전 예고   "사장님한테 직접 물어봤습니다"
D  의문 제기   "치킨값, 진짜 재료비 때문일까?"
```

하나라도 1,000회를 넘기면 그 훅이 정답이다. 그때부터 그 공식으로 찍는다.

### 🔴 이 구조가 된 이유
1. **인사를 훅 뒤로 옮겼다.** 쇼츠는 1초 안에 잡아야 하는데 인사부터 하면 그 1초를 버린다
2. **브랜드가 먼저 이유를 대야** 재료를 까는 게 '나열'이 아니라 '검증'이 된다.
   처음엔 묻지도 않고 가격부터 깠다가 "다짜고짜"라는 지적을 받았다
3. **합계는 70% 지점에서 처음 공개.** 2편은 19초(중간)에 다 까서 완주율 12.8%로 끝났다
4. **차액이 사장님 몫으로 오해되면 채널 톤이 무너진다.** 그래서 사장님이 직접 수수료·임대료를 말한다
5. **마지막에 "나머지는 어디로?"를 물었다가 뺐다.** 사장님이 이미 답한 걸 또 묻는 논리 구멍이었다.
   배달 수수료·본사 마진 파는 건 **나중에 롱폼**에서 한다(배민·쿠팡볼은 그때 만든다)

5. `gap`으로 59초 맞춤 → `npx remotion render Talk out\4편_xxx.mp4`

## 아직 손으로 하는 것 (자동화 후보)

| 항목 | 지금 | 하면 |
|---|---|---|
| DB → config.js | 손으로 옮겨 적음 | 스크립트로 자동 |
| trim.json → Talk.jsx | 손으로 옮겨 적음 | JSON을 직접 읽게 |
| 업로드 제목·설명 | queue.json에 손으로 | config에서 자동 생성 |
| 자막 타이밍 | 글자 수로 추정 | Whisper로 단어 단위 (무료) |

⚠️ **플랫폼 자동 업로드는 대부분 막혀 있다.** 유튜브 썸네일은 앱 전용, 네이버 클립은 폰 전용,
틱톡은 세션 유지가 안 된다. 브라우저 자동화로 우회하는 게 한계다.
