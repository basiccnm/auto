## 1. 대표님 작업 방식 — 이걸 어기면 화내신다

### 🔴 질문이든 수정이든 **모아서 한 번에**
말이 끝날 때까지 듣고 한 번에 답하고 한 번에 실행한다.
하나 듣고 바로 답하거나 파일을 고치면 **대표님이 다음 말을 하려고 매번 끊어야 한다.**
오늘 이걸로 지적받았다. "자꾸 수정사항 안 모으고 한 번에 진행하니 내가 중간에 끊고 말하는 거다"

- 말이 이어질 것 같으면 "목록에 담았습니다 (현재 N개)" 로만 받고 멈춘다
- "처리해" · "고고" · "ㄱㄱ" 가 나오면 그때 전부 실행한다

### 🔴 기획은 대표님이 한다
오늘 좋은 아이디어는 전부 대표님이 냈다(도발형 훅, 오해 바로잡기 구조, 셰프 식당 편들기,
마라탕 100g 단가, 계산기). AI가 먼저 방향을 정하려 들면 평범한 답만 나온다.
**대표님이 던지면 검증하고 화면으로 만드는 역할**로 갈 것.

### 🔴 답변은 짧게
표·선택지 나열 금지. 3~5줄. 질문은 한 줄.

## 2. 3편 성적 — 템플릿이 먹혔다

| | 2편 황금올리브 | 3편 허니콤보 |
|---|---|---|
| 총 조회 | 361 (24시간) | 492 (3시간) |
| 유효 조회 | 47 | 114 |
| 조회율 | 13.0% | **23.2%** |
| 완주율 | 12.2% | **22.7%** |
| 평균 시청 | 21초 | 26초 |
| 길이 | 39초 | 51초 |

**바꾼 두 가지가 각각 먹혔다**
- 도발형 훅("하나 팔면 16,974원 남는다?") → 조회율 1.8배
- 합계를 70% 지점으로 미루기 → 완주율 1.9배

**⚠️ 7월 24일에 다시 확인할 것.** 위 값은 게시 3시간 시점이라 아직 안정된 값이 아니다.
2편은 4시간 만에 배포가 끊겼는데 3편은 계속 늘고 있었다.

### 다음 편에서 바꿀 것은 **길이 하나뿐**
APV가 51%(26초/51초)다. 목표는 80%. **40초 안쪽으로 줄이면 60%대**가 된다.
훅과 구조는 검증됐으니 건드리지 않는다.

## 3. 🔒 템플릿 — 순서는 고정, 연출만 개선

```
① 훅          "OO 하나 팔면 N원 남는다?"   ← 사람들이 아는 오해를 던진다
② 브랜드 주장   "저희는 이래서 비쌉니다"
③ 검증 시작
④ 재료 ①②③④⑤ 장부가 한 줄씩 쌓임
⑤ 합계 + 정적(0.7초)
⑥ 차액 계산
⑦ 사장님 반전   "그래서 사장님 모셨습니다" → "저희 손엔 몇천 원"
⑧ 마무리       첫 문장으로 돌아와 결론 ("반은 맞고 반은 틀렸네요")
```

- **인사("소상공인 여러분 힘내세요")는 뺐다.** 훅 다음 바로 본론. 그 이야기는 설명란에서
- **유도 문구도 뺐다.** "댓글로 알려주세요" 없이 질문만 남긴다
- 바뀌는 것: 브랜드 · 메뉴 · 숫자 · 브랜드볼 색과 로고

## 4. 다음 할 일 — 마라탕 특집

**대표님이 실제 마라탕 가게를 하신다.** 그래서 데이터로 못 구하는 정보가 나온다.
자세한 내용은 `마라탕-현장정보-2026-07-22.md` 참고.

### 이미 확보된 것
- 식자재 단가 **307종**이 DB에 들어와 있다 (2026-07-22 갱신분)
- 숙주 마진 **14배** (도매 3.5kg 5,000원 → 배달 100g 2,000원)
- 배달 기본료 원가 분해 (소스 300~500 + 육수 500 + 용기 500)
- **실제 배민 정산 화면** — 13,000원 주문 → 사장님 입금 4,191원

### 아직 필요한 것
- **채소 단가** (청경채·숙주·팽이 등) — 다른 세션에서 정리 중이었다
- **불림 배수** — 마른 목이버섯 5~8배, 표고 4~6배, 당면·분모자 2~3배 등.
  ⚠️ 이걸 안 잡으면 마른 재료 단가가 반대로 나온다(목이버섯 1,780원 → 실제 250원쯤)
- **마라탕 가게 배경 그림** — 대표님이 챗GPT로 받아주시기로. 셀프바와 저울이 보이게

### 만들 편 순서 (센 것부터)
1. **배민 정산 구조** — 9,000원 결제, 사장님 통장 4,191원. **실제 화면이 있어서 제일 강하다**
2. **숙주 14배** — 5,000원 한 박스가 7만 원 매출
3. **기본료의 진실** — 1,500원 받는데 원가 1,300원
4. **마라샹궈가 비싼 이유** — 판매가 5,000원 차이인데 원가는 628원 차이 (DB로 확인됨)
5. **마라탕 소스가 고기보다 비싸다** — 소스 100g 1,200원 > 우삼겹 1,158원

⚠️ **톤 주의**: 대표님 본인 가게 이야기라 **자기 고백** 형식으로 간다.
"저희도 이렇게 합니다"면 신뢰가 생기고 "저 가게들 이래요"면 업계와 싸운다.

## 5. 파이프라인 — 4편 만드는 순서

```
python make_menu.py 메뉴명       DB → menu.json (재료·가격 자동)
python make_marat.py 2000        마라탕용. 재료별 100g 단가
voice\script.json 대사 작성
python make_voice.py script      TTS (엣지, 무료)
python normalize.py              볼륨 −13 LUFS
python trim.py                   앞뒤 무음 측정 → trim.json
python align.py                  Whisper 단어 타임스탬프 → align.json
Talk.jsx의 LINES 갱신 → npx remotion render Talk out\N편_xxx.mp4
업로드 폴더에 편별 폴더 만들어 넣기
```

**출력은 하나면 된다.** BGM이 없어서 유튜브·틱톡·인스타·네이버에 같은 파일을 쓴다.

## 6. 🔴 오늘 데인 것들 — 같은 실수 반복 금지

1. **단위 환산** — g인데 kg 단가를 곱해 **496원이 496,000원**으로 나왔다.
   `make_menu.py`의 `UNIT` 표에서 처리한다. 새 단위가 나오면 표에 추가할 것
2. **안전 영역** — 카드를 top:80에 붙였더니 **쇼츠 목록 썸네일에서 첫 줄이 잘렸다.**
   카드 top 200부터, 캐릭터 발끝 1660 이내
3. **normalize.py 버그** — `out_raw\`에 옛 백업이 남아 있으면 새 음성이 통째로 날아간다.
   `make_voice.py`가 지우게 고쳤다
4. **대사를 짧게 쪼개지 말 것** — +40%가 안 들렸던 건 속도가 아니라 문장이 안 완결돼서였다.
   완결 문장으로 쓰면 빨라도 들린다 (현재 +35%)
5. **정적은 0.7초가 한계** — 1.6초로 뒀더니 "영상이 멎은 것 같다"는 지적을 받았다
6. **입은 눈에서 멀리** — 가까우면 코로 보인다. 세 번 반복한 실수
7. **듣는 쪽 표정도 지정** — `of` 프롭. 상대가 무표정이면 아무 일도 안 일어난 것처럼 보인다
