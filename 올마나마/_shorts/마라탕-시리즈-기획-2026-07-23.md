- **길이 시뮬레이션 결과 재료 18종이 55초 한계**다. 고정 파트(훅·공지·정렬·표·회수·마무리+숨)가 21.2초,

## 제작 파이프라인 (편당)

```
1. voice/script.json 대사 작성
2. python make_voice.py script → normalize.py → trim.py → align.py
3. remotion/src/shorts/ep_maratN.js   재료 데이터
                       lines_maratN.js 대사+화면 지시(trim/align 실측값)
                       TalkN.jsx       화면(카드) — talk_engine.jsx가 조립
4. Root.jsx에 컴포지션 등록
5. npx remotion render TalkN "out/마라탕N편_xxx.mp4"
```

**엔진은 공통**(`talk_engine.jsx`) — 편별로는 카드만 새로 쓴다. 2편 것(`Talk2.jsx`)을 복사해 쓰면 빠르다.
