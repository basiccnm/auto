## 1. 확정된 실측 데이터

### 배민 정산 — 9,000원 결제, 사장님 손엔 4,191원
실제 주문 캡처 있음. 국가대표 셀프마라탕.

```
메뉴 합계                    13,000원  (쌀국수·중화당면·청경채·팽이버섯·푸주 각 2,000
                                        + 숙주100g할인 1,500 + 땅콩소스2개 1,000 + 탐스제로 500)
즉시할인                     −4,000원
손님 결제                     9,000원
──────────────────────────────
중개이용료                     −702원
고객할인비용(사장님 부담)      −4,000원
배달비(사장님 부담)            −3,400원
결제정산수수료                  −270원
부가세                         −437원
──────────────────────────────
입금예정                     4,191원   (주문금액 13,000원의 32%)
```

**헷갈리는 지점**: 3,400원이 두 번 나온다.
- 배달팁 3,400원 → 손님이 낼 돈인데 배민이 지원 (손님 0원)
- 배달비 3,400원 → 사장님이 내는 돈, 그대로 차감
서로 다른 주머니인데 금액이 같아서 헷갈린다. 배민 공식 문서로 확인 완료
(ceo.baemin.com/guide/12699, 12204). "배달비 무료"는 손님 것만 무료다.

### 숙주의 연금술 — 14배
```
도매   3.5kg 1박스 5,000원 (100g당 143원)
배달   100g 판매가 2,000원
──────────────────────
한 박스 5,000원 → 매출 70,000원 (마진율 93%)
```
시리즈에서 제일 센 숫자. 훅 후보 1순위.

### 배달 기본료 — 여기선 안 남는다
```
소스 300~500 + 육수 500 + 용기 500 = 원가 1,300~1,500원
받는 돈 1,500~2,000원 → 거의 다 원가
```

### 9,900원의 실체 — 다 합쳐도 400g
기본료 + 숙주100g(2,000) + 분모자6개(2,000) + 당면3줄(2,000) + 소고기할인가(1,900) = 9,900원인데 400g 남짓.
단가를 잘게 쪼개 놔서 다 합쳐도 양이 적어 보인다.

### 홀 vs 배달 — 계산법 자체가 다르다
홀은 무게(g) 과금, 배달은 재료별 개별 단가. 같은 가게인데 손님은 이 차이를 모른다.

### 즉시할인의 구조
재료·기본가를 처음부터 높게 세팅(앵커)해두고, 할인은 그 앵커를 원래 받으려던 가격으로
되돌리는 것. 할인이 적은 가게에서 시키면 앵커 가격을 그대로 다 낸다.

### DB로 확인된 것 (프랜차이즈 마라탕)
```
마라탕 기본형   판매 10,000  원가 3,147 (31.5%)
마라샹궈 기본형  판매 15,000  원가 3,775 (25.2%)
→ 판매가 차이 5,000원인데 원가 차이는 628원뿐

마라탕 소스 100g  1,200원  ← 우삼겹(1,158원)보다 비싸다

꿔바로우  직접 만들면 돼지등심250g 2,380원+튀김옷=3,245원
          냉동 완제품 100g 1,137~1,237원
```

## 2-0. 방향 전환 (2026-07-22 저녁 확정)

**어두운 주제(배민 정산·수수료)는 채널 큰 뒤로 미룬다.** 신생 채널이라 밝은 꿀팁 톤으로 시작.
진행은 **올마볼**(추후 올마나마 마라탕 계산기로 유입), 사장님볼은 검증·증언 역할.
로테이션: `꿀팁 1 → 재료 2 → 지식 1 → 재료 2 → …`

**넘버링은 치킨 4편이 아니라 "마라탕 시리즈"로 새로 간다** (마라탕1편_~ 형식).

**마라탕 1편 = 홀 업태 비교** — A(소스바 운영, 현장 실측: 100g 2,700원, 최소 9,180원) vs
B(소스바 미운영, 100g 1,900원, 고기·음료 별도, 최소 6,000원).
"싼 집이 진짜 싼 게 아니다"가 훅. 상세는 현장정보 문서 1-1.
**재료 랭킹 편은 업태 구분 편 뒤로** — 랭킹은 업태 프레임 없이는 가격 단정 오류가 생긴다.
(양고기 1,980원/100g도 "또 올랐네" 반응 — 장부 재확인 필요)

## 2. 편성 순서 (센 것부터, 6개 — ⚠️구 버전, 위 2-0이 우선)

1. **배민 정산 구조** — 9,000원 결제, 통장 4,191원. 실제 화면 있어 제일 강함
2. **숙주 14배** — 5,000원 박스가 7만 원 매출
3. **기본료의 진실** — 1,500원 받는데 원가 1,300원, 안 남는 편
4. **9,900원의 실체** — 다 합쳐도 400g
5. **즉시할인의 구조** — 깎아주는 게 아니라 원래 가격으로
6. **홀 vs 배달** — 같은 가게, 다른 계산법

*(마라샹궈 원가차 628원, 마라탕 소스>고기, 꿔바로우 완제품 건은 여유분/보조 소재)*

### 톤 주의 — 반드시 지킬 것
대표님 본인 가게 이야기다. **"저희도 이렇게 합니다"(자기 고백)**로 가야 신뢰가 생긴다.
"저 가게들 이래요"가 되면 업계 전체와 싸우는 톤이 된다. 3번(기본료는 안 남는다)을
앞쪽에 배치해 균형을 잡는다. 대표님 반응은 담담했다("안 놀라 나는") — 놀라는 역할은
항상 올마(=시청자 대변)가 맡는다.

## 4. DB에 이미 들어있는 재료 단가 (마켓봄 실거래명세, 2026-07-22 갱신)

당면·분모자·버섯류는 **여러 제품 옵션이 이미 실거래가로 채워져 있다** (`ingredients` 테이블,
`wholesale_basis`에 "마켓봄(수발주앱) 실거래명세"로 출처 표시). 대표 몇 개만:

```
마른표고버섯(干香菇)        kg 22,700원   1KG*10 22,700원
청정들 목이버섯(秋耳)       kg 19,000원   1KG*10 19,000원
흑목이버섯(黑木耳)          kg 17,800원   1KG*10 17,800원
흰목이버섯(银耳)            kg 15,000원   1KG*6  15,000원
쌀국수 건면                 kg  4,505원
당면(업소용 벌크)           kg  2,908원   네이버 13kg 37,800원
푸주                        kg  8,400원
팽이버섯                    kg  1,885원
숙주나물                    kg  1,885원
마라탕 소스(대표 실측)      kg 12,000원   가게 운영 경험 기반, 계수 미적용
```

### ✅ 목이버섯 불림 계수 — 대표님 확정, DB 반영 완료 (2026-07-22)
