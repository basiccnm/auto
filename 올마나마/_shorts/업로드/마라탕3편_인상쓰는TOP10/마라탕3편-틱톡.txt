【1】 파일 옮기기
  · PC의 마라탕3편_인상쓰는TOP10.mp4 를 폰으로 보낸다
    (카카오톡 나에게 보내기 / 구글드라이브 / USB 케이블)

【2】 업로드
  1. 틱톡 앱 → 하단 '+' → 갤러리에서 영상 선택
  2. '다음' → 편집 화면
  3. 음악  ⚠️ 우리 영상엔 BGM이 없다
       · 그대로 둬도 되고, 틱톡 안 트렌딩 사운드를 얹으면 노출에 유리하다
       · 얹을 경우 볼륨을 10~20%로 아주 낮게 줄인다
       · 원본 볼륨은 100% 유지
  4. '다음' → 게시 화면
  5. 캡션 붙여넣기 (위 ■ 캡션)
  6. 커버 선택 → 맨 앞 프레임("눈치 보이는 재료" 카드)
  7. 공개 범위 : 모든 사람
     댓글 / 듀엣 / 이어찍기 : 전부 허용
  8. 게시

【3】 올린 뒤
  · 틱톡은 며칠 뒤 갑자기 터지는 일이 많다. 하루 만에 판단하지 않는다
  · 지표는 앱 안 '분석'에서 본다
    ⚠️ 개인 계정이면 안 보인다 → 설정 → 계정 → 프로 계정으로 전환
