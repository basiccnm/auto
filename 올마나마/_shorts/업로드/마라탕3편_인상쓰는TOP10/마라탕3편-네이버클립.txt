【1】 파일 옮기기
  · PC의 마라탕3편_인상쓰는TOP10.mp4 를 폰 갤러리로 옮긴다

【2】 업로드
  1. 네이버 앱 → 하단 '+' → '클립'
  2. 갤러리에서 영상 선택
  3. 설명 붙여넣기 (위 ■ 설명. 제목 필드 없음 — 첫 줄이 사실상 제목)
  4. 해시태그 입력 (위 ■ 해시태그) — 네이버는 검색 유입 비중이 크다
  5. 커버 선택 → 맨 앞 프레임("눈치 보이는 재료" 카드)
  6. 공개 설정 : 전체 공개
  7. 게시

【3】 네이버는 다르게 접근한다
  · 검색 유입이 크다 — 설명 첫 줄에 "마라탕 원가" 같은 실제 검색어를 그대로 넣는다
  · 블로그가 있으면 클립을 블로그 글에 임베드해 같이 노출시킬 수 있다
