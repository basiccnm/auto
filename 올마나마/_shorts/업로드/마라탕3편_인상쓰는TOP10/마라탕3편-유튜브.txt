【1】 PC에서 업로드

  1. studio.youtube.com  →  우측 상단 '만들기' → '동영상 업로드'
  2. 마라탕3편_인상쓰는TOP10.mp4 끌어다 놓기
  3. 제목 붙여넣기   (위 ■ 제목)
  4. 설명 붙여넣기   (위 ■ 설명 전체. 해시태그까지)
  5. 시청자층  →  ⚠️ "아니요, 아동용이 아닙니다" 선택
  6. '자세히 보기' 펼쳐서
       카테고리      : 인물/블로그  또는  노하우/스타일
       댓글          : 허용
       유료 프로모션  : 해당 없음
  7. 공개 상태  →  예약  →  피크타임 30분~1시간 전으로 설정


【2】 재생목록에 넣기   ← "마라탕 시리즈" 재생목록에 이어서 추가

  · 1·2편과 같은 재생목록(마라탕 시리즈)에 순서대로 넣는다
  · 2편(싼 것 TOP10) 바로 다음에 배치 — 짝을 이루는 편이라 붙여서 봐야 효과적


【3】 썸네일 지정   ← ⚠️ 폰으로만 된다

  · 유튜브 모바일 앱에서:
       내 동영상 → 해당 쇼츠 → 우측 상단 '⋮' → '수정'
       → 미리보기 좌측 위 연필 아이콘 → 타임라인을 맨 앞(0.2초 이내)으로
       → 첫 화면("눈치 보이는 재료" 카드) 선택 → 완료


【4】 관련 동영상 연결

  · 2편(사장님 최애 TOP10)과 서로 연결 — 대조되는 짝
  · 4편 나오면 그쪽도 연결
