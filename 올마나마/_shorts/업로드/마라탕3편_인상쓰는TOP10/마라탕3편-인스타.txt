【1】 파일 옮기기
  · PC의 마라탕3편_인상쓰는TOP10.mp4 를 폰 갤러리로 옮긴다

【2】 업로드
  1. 인스타 앱 → 하단 '+' → '릴스'
  2. 갤러리에서 영상 선택 → '다음'
  3. 커버 선택 → 맨 앞 프레임("눈치 보이는 재료" 카드)
  4. 오디오 : 원본 그대로. BGM이 없으니 손댈 것 없다
  5. '다음' → 캡션 붙여넣기 (위 ■ 캡션)
  6. 설정 확인
       · 페이스북에도 공유    : 켜기(선택)
       · 프로필 그리드에 표시  : 켜기
       · 댓글 허용            : 켜기
  7. 공유하기

【3】 프로필 링크 확인
  · 프로필 → 프로필 편집 → 링크 → olmanama.com 등록돼 있는지 확인

【4】 올린 뒤
  · 지표는 릴스 → 하단 '인사이트'
