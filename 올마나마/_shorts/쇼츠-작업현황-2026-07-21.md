## 업로더 (별개 트랙, 거의 완성)

`_shorts\uploader\`
```
common.py       크롬 실행(CDP 포트 방식) · 로그 · 대기열
login.py        최초 1회 수동 로그인

upload_yt.py    유튜브 — 실제 업로드 성공 확인됨
queue.json      올릴 영상·제목·설명·태그
uploader_profile\  로그인 세션 (백업 제외 처리됨)
```

**상태**
- 유튜브 ⭕ / 인스타 ⭕ / 틱톡 ❌ (크롬에 세션 없음. 폰 앱만 쓰시는 듯)
- **쇼츠 썸네일은 웹에서 못 바꾼다** — 유튜브가 "모바일 앱에서 하라"고 표시. 자동화 불가
- **유튜브 전화번호 인증이 아직 안 됨** → 설명문 링크가 클릭이 안 된다. 유입 통로가 막혀 있음
- 네이버 클립은 **폰 앱 전용**이라 자동화 불가 → 손으로 올린다
- 틱톡·인스타 업로더는 미작성

**중요:** Playwright 기본 크로미움은 이 PC에서 실행이 안 된다(side-by-side 오류).
`launch_persistent_context`도 이 프로필에선 죽는다.
→ **크롬을 직접 띄우고 `--remote-debugging-port` + `connect_over_cdp`** 로 붙는다. (common.py에 구현됨)

## 🚨 AI 사고 기록 (같은 실수 반복 금지)

**1. 사용자 턴을 지어낸 사고** (이전 세션, 20번 이상)
응답이 끝나는 지점에서 안 멈추고 대표님이 할 법한 말까지 이어 씀.

**2. 오배포 사고** (2026-07-21)
GA를 붙이려다 옆 폴더(`얼마남아-web`, B2B API)에 넣고 배포함.
`wrangler deploy` 출력에 낯선 워커명이 찍혔는데 안 멈췄다.
→ **배포 전 워커명·도메인을 반드시 확인할 것.**

**3. 엉뚱한 테이블 조회** (2026-07-21)
`dishes`(집밥)를 보고 매장 원가라고 단정. 210원 어긋남.
→ 쇼츠 원가는 **`menu_ingredients`**다.

**4. "다 해"를 잘못 해석** (2026-07-21, 이번 건)
*할 일을 다 하라* → *화면에 다 넣으라*로 받아 3편을 조잡하게 만듦.
**인트로·썸네일 화면은 고정인데 그것까지 갈아엎었다.**

**지켜야 할 것**
1. 응답은 **내 말로 끝낸다.** 다음 사용자 발화를 예측해 쓰지 않는다
2. **파일 고치기 전에 묻는다.** 특히 이미 확정된 것(인트로·썸네일)은 건드리지 않는다
3. **한 번에 하나씩 만들고 보여준다.** 12장면을 한 번에 만들지 않는다
4. 물음표로 끝나는 말은 질문이다. 답만 하고 멈춘다
5. **답변은 짧게.** 표·선택지 나열 금지
