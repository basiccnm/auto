# 마라탕 현장 정보 — 대표님 실무 (2026-07-22)

> **출처: 대표님이 직접 마라탕 가게를 운영하며 아는 내용.**
> DB나 검색으로는 못 나오는 값이다. 쇼츠 대본의 근거로 그대로 쓴다.
> ⚠️ 이 문서는 **추정이 아니라 현장 실제값**이다. 다른 추정치와 섞지 말 것.

---

## 1. 홀과 배달은 가격 구조가 아예 다르다

| | 계산 방식 |
|---|---|
| **홀(매장)** | **무게(g)** 로 계산. 음료·소스 포함 여부는 매장마다 룰이 다르다 |
| **배달** | 앱 특성상 **재료별 개별 단가**. 거의 모든 마라탕집이 이 방식 |

→ 같은 가게인데 홀과 배달의 가격 논리가 다르다. 손님은 이걸 모른다.

### 1-1. 홀 업태는 두 갈래다 (2026-07-22 대표님 추가)

**⚠️ 홀 g당 가격을 하나로 단정하면 안 된다.** 업태에 따라 가격대 자체가 다르다.

| | A. 소스바 운영 | B. 소스바 미운영 |
|---|---|---|
| 제공 | 소스 10종 이상 + 밥 + 음료 | 밥 + 소스 2~4가지 무료 |
| 별도판매 | 새우 · 라면사리 · 우동사리 | 고기 100g · 유부 · 피쉬볼 · 꼬치 · 음료 |
| 100g당 | **최소 2,500원부터** | **2,000원 안팎이 최소** (2026-07-22 대표님: 요즘 1,500원대는 없다) |
| 최소금액 | 보통 9,000원대 | 6,000원 |

- 겉가격은 B가 싸 보이지만 **별도판매를 합치면 역전될 수 있다** — 이게 비교 편의 핵심
- 서빙 방식도 두 갈래: **직원 서빙 / 직접 받아서 먹는 셀프**

**🔴 A업태 기준점 = 현장(의정부) — 대표님 배우자가 운영하는 가게다.**
100g 2,700원 · 최소 9,180원 · 소스바 무료 + 밥·음료 무한리필 · **고기도 저울 무게에 포함**(별도 없음).
→ 부부가 A업태(현장)와 배달 중심(국가대표 셀프마라탕)을 각각 운영 = **두 업태 모두 현장 실측 가능.**
B업태 시세 참고(웹 조사 2026-07-22): 탕화쿵푸 1,800~2,100원 · 라화쿵부 1,800~1,900원 ·
고기(소·양) 100g 3,000원 별도 사례. 쓰촨마라(범계)는 소스바만 있고 고기 별도인 중간형.

## 2. 배달앱 앵커 가격과 즉시할인

- 재료·기본가를 **처음부터 높게(앵커) 세팅**해 둔다
- 할인은 퍼주는 게 아니라, **부풀린 가격을 깎아 원래 받으려던 정가에 맞추는** 심리전
- 즉시할인이 적은 가게에서 시키면 손님은 **앵커 가격을 그대로 다 낸다**

```
예시   소고기를 3,000~4,000원으로 세팅
       → 리뷰 이벤트로 1,900원에 "할인"
```

---

## 3. 배달 9,900원어치의 실체 — 약 400g

최소주문을 맞추고 5,000원 할인을 받아 4,900원에 먹는 방법이 있지만, **애초에 양이 적다.**

```
기본료              1,500~2,000원
숙주 100g                2,000원
분모자 자른 것 6개          2,000원
납작당면 3줄              2,000원
소고기(리뷰 할인가)         1,900원
──────────────────────────────
합계                    9,900원  →  400g 남짓
```

단가가 비싸게 쪼개져 있어서 다 합쳐도 400g밖에 안 된다.

## 4. 배달 기본료(1,500~2,000원) 원가 분해

```
마라탕 소스 1숟가락    300~500원
육수 500g               500원
배달 용기               500원
────────────────────────────
합계               1,300~1,500원
```

→ **기본료는 거의 원가다.** 여기서 남는 게 없다. 재료를 담아야 마진이 생긴다.

## 5. 🔴 숙주의 연금술 — 14배

```
도매 식자재    숙주 3.5kg 1박스 = 5,000원   (100g씩 35개)
               → 100g당 원가 143원
배달 판매      숙주 100g = 2,000원
────────────────────────────────────────
한 박스        5,000원  →  70,000원 매출
배수           14배 · 마진율 93%
```

**이게 이 시리즈에서 제일 센 숫자다.** 훅으로 쓴다.

## 6. 🔴 실제 배민 정산 — 9,000원 결제, 통장에 4,191원

대표님 가게 실제 주문 건이다. **화면 캡처가 있어서 근거가 확실하다.**

### 주문 내역 (국가대표 셀프마라탕)
```
쌀국수 2,000 · 중화당면 2,000 · 청경채 2,000 · 팽이버섯 2,000 · 푸주 2,000
숙주 100g(할인) 1,500 · 땅콩소스 2개 1,000 · 탐스제로 500
──────────────────────────────────────────
메뉴 합계                    13,000원
즉시할인                     −4,000원
손님 결제                     9,000원
```

### 할인 7,400원은 누가 냈나
```
통합할인      4,000원   └ 파트너 부담      ← 사장님 돈
배달팁할인    3,400원   └ 배민 100% 지원   ← 배민 돈(손님 배달팁)
────────────────────────────────
총 할인      7,400원
```

### 정산
```
주문금액                13,000원
중개이용료                −702원
고객할인비용(사장님 부담)  −4,000원
배달비                 −3,400원   ← 배민배달 이용료. 사장님 부담
결제정산수수료             −270원
부가세                   −437원
──────────────────────────────
입금예정                 4,191원   (주문금액의 32%)
```

### 🔴 헷갈리는 지점 — 3,400원이 두 번 나온다
```
배달팁 3,400원   손님이 낼 돈  →  배민이 지원  →  손님 0원
배달비 3,400원   사장님이 낼 돈 →  그대로 차감
```
**서로 다른 주머니다.** 금액이 우연히 같아서 "지원해준 걸 다시 가져갔나" 싶게 보인다.

배민 공식 문서 확인 완료:
- **배달비** = 배민 배달대행을 쓰며 **파트너가 부담**하는 비용
- **배달팁** = **고객이 부담**. 배민 매출로 잡히고 파트너에게 정산되지 않음
- 배민배달 상생 요금제 배달비는 건당 **1,900~3,400원** (매출 규모·지역별 차등)
- 2026년 6월 '통합할인' 도입 — 음식값보다 **배달팁을 먼저 깎는** 방식

출처: ceo.baemin.com/guide/12699 · ceo.baemin.com/guide/12204

### 이게 왜 센가
- **"배달비 무료"인데 사장님은 3,400원을 낸다** — 손님 것만 무료다
- **할인 7,400원 중 4,000원은 사장님 돈** — 손님은 누가 냈는지 모른다
- 뉴스에서는 여러 번 다뤘지만(치킨 22,000원 팔면 1,000원 남는다 등)
  **실제 정산 화면을 띄운 쇼츠는 못 찾았다.** 형식이 비어 있다

⚠️ 대표님 반응: "안 놀라 나는" — 사장님한테는 일상이다.
**놀라는 건 손님이다.** 담담하게 숫자만 보여주는 게 제일 설득력 있다.

## 쇼츠로 만들 순서 (센 것부터)

1. **배민 정산 구조** — 9,000원 결제, 통장에 4,191원. **실제 화면이 있어 제일 강하다**
2. **숙주 14배** — 5,000원짜리 한 박스가 7만 원이 되는 구조
3. **기본료의 진실** — 1,500원 받는데 원가가 1,300원. 여기선 안 남는다
4. **9,900원의 실체** — 다 합쳐도 400g. 왜 적어 보이는지
5. **즉시할인의 구조** — 깎아주는 게 아니라 원래 가격으로 돌아오는 것
6. **홀 vs 배달** — 같은 가게인데 계산법이 다르다

### DB로 확인된 것 (프랜차이즈 마라탕)
```
마라탕 기본형   판매 10,000  원가 3,147  (31.5%)
마라샹궈 기본형  판매 15,000  원가 3,775  (25.2%)
────────────────────────────────────────
판매가 차이 5,000원인데 원가 차이는 628원뿐
```
→ **"국물도 안 들어가는데 왜 비싼가"** 가 숫자로 증명된다

```
마라탕 소스 100g  1,200원   ← 우삼겹(1,158원)보다 비싸다
```
→ 이것도 한 편이 된다

```
꿔바로우   직접 만들면  돼지등심 250g 2,380원 + 튀김옷 = 3,245원
           냉동 완제품  100g 1,137~1,237원
```
→ 대부분 가게가 완제품을 튀긴다. **"고기 원가"가 아니라 "완제품이냐"** 가 진짜 이야기

### 톤 주의
대표님이 **직접 하는 가게 이야기**라 자폭이 아니라 **자기 고백** 형식으로 간다.
"저희도 이렇게 합니다"가 되면 신뢰가 생기고, "저 가게들 이래요"가 되면 업계 전체와 싸운다.
2번(기본료는 안 남는다)을 앞쪽에 배치해 균형을 잡는다.
