# OpenAI 클라이언트 — 공통모듈 원본

새 프로젝트에서 OpenAI API가 필요하면 **이 폴더를 프로젝트로 복사**해서 쓴다 (직접 import 금지 — `..\CLAUDE.md` 규칙).

## 파일

| 파일 | 역할 |
|---|---|
| `config.py` | 키·모델·파라미터. 키는 **환경변수 → .env** 순으로만 읽는다(코드에 박지 않음) |
| `client.py` | `complete()` 텍스트 · `gen_images()` 이미지 · `list_models()` 모델 확인. 재시도·백오프 포함 |
| `.env.example` | 복사해서 `.env` 만들 것 |
| `.gitignore` | `.env` 커밋 방지 |

## 키 관리 (🔴 중요)

- **코드·문서·채팅에 키를 평문으로 두지 않는다.** 2026-07-20 채팅에 키가 노출된 사고가 있었고, 그 키는 폐기 대상이다.
- 설정: `setx OPENAI_API_KEY "sk-..."` (PowerShell, 새 창부터 적용) 또는 `.env` 파일
- 이 모듈은 키를 화면에 출력하지 않는다.

## 모델명 주의

`config.py`의 기본값 `gpt-5.6-terra`는 **얼마남아 레시피 파이프라인 지시서(2026-07-20)에 적힌 이름**을 그대로 넣은 것이다. 계정에서 실제 호출 가능한지는 확인이 필요하다:

```python
python -c "import sys; sys.path.insert(0,'.'); from client import list_models; print(list_models('gpt'))"
```

목록에 없으면 `.env`의 `OPENAI_TEXT_MODEL`을 실제 이름으로 바꾼다. (잘못된 이름은 런타임 404)

## 비용 주의

이미지 생성은 텍스트보다 훨씬 비싸다. 배치 실행 전 **1~2건으로 검증**하고, 총 호출 수를 먼저 계산할 것.
얼마남아 레시피 파이프라인은 요리 1종당 텍스트 1회 + 이미지 3장이다 → 68종 전량이면 이미지만 204장.
