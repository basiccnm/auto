# 쇼츠업로더 — 한 편을 유튜브·틱톡·인스타에 한 줄로

> **왜 있나 (2026-07-31 대표 지시)**
> 편마다 사람이 3개 명령을 따로 조립하고 있었다. 절차는 매번 똑같은데 그걸
> 매번 다시 짜느라 시간·토큰이 나갔다.
> **내용(제목·설명·댓글)은 사람이 쓰고, 올리는 절차는 스크립트가 한다.**

```bash
python publish.py --id 순대국1          # 미리보기 — 아무것도 안 올림
python publish.py --id 순대국1 --go     # 실제 업로드 (유튜브 → 틱톡 → 인스타)
```

## 들어 있는 것

| 파일 | 역할 |
|---|---|
| `publish.py` | **이게 본체.** 3곳 순차 업로드 + 인스타용 배포까지 |
| `publish_config.example.json` | 프로젝트마다 다른 값(사이트 주소·배포 명령) |
| `queue.json` | 편 목록. 제목·설명·댓글·태그가 여기 한 곳에 |

⚠️ `publish.py` 는 아래 세 스크립트를 **호출**한다. 같은 폴더에 있어야 한다.
`upload_yt_api.py` · `upload_tt.py` · `post_ig_reel.py` (+ `common.py`·`meta_common.py`)

## 붙이는 법

1. 이 폴더를 프로젝트의 업로더 폴더로 **복사**한다 (원본을 import 하지 말 것)
2. `publish_config.example.json` → `publish_config.json` 으로 복사하고 값을 채운다
3. 기존 `queue.json` 항목에 `ig` 블록을 더한다 (아래)

## queue.json 항목

```jsonc
{
  "id": "순대국1",
  "brand": "이거 얼마남아 6 — 순대국 한 그릇",
  "file_yt": "../업로드/순대국1편_한그릇/순대국1편_한그릇.mp4",
  "title": "...", "desc": "...", "desc_tt": "...", "comment": "...",
  "tags": ["shorts", "..."],
  "playlist": "음식 원가 해부",     // 없으면 제목으로 판별
  "ig": {                           // 없으면 인스타는 통째로 건너뛴다
    "slug": "keunmam-1",            // https://<site>/reels/<slug>.mp4
    "caption": "...",               // 없으면 desc_tt
    "comment": "...",               // 없으면 comment
    "tags": [...]                   // 없으면 tags
  },
  "status": { "yt": "", "tt": "", "ig": "", "nv": "skip" }
}
```

## 알아둘 것

- **인스타는 로컬 파일을 못 받는다.** 공개 HTTPS 주소만 받는다.
  그래서 인스타 차례엔 «영상 복사 → 빌드 → 배포» 가 먼저 돈다(`deploy_steps`).
- **첫 댓글 «고정» 은 자동이 안 된다.** 유튜브는 API에 그 기능이 없고,
  인스타는 폰에서만 된다. 댓글 **등록**까지는 자동으로 된다.
- **이미 done 인 곳은 건너뛴다.** 다시 올리려면 `--force`.
- `--only yt` / `--skip ig` 로 일부만 돌릴 수 있다.
- 자식 스크립트에 `PYTHONIOENCODING=utf-8` 을 강제한다 —
  안 하면 윈도우 콘솔(cp949)에서 이모지 하나에 죽는다(2026-07-29 실제 발생).
