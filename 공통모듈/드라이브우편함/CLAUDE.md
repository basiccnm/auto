# 드라이브우편함 — Claude 웹 ↔ Claude Code 비동기 통신 시스템 (원본)

사장픽 프로젝트에서 만들어 검증한 것(2026-07-22). **원본은 여기, 쓸 땐 프로젝트로 복사**(공통모듈 규칙).
살아있는 실사용 예시는 `Desktop\블로그수입관련\sajangpick\`에 있다.

## 무엇을 해결하나
웹 Claude(두뇌)와 Claude Code(실행)는 서로를 직접 못 부른다. 둘 다 사용자가 말을 걸어야 깨어난다.
이 시스템은 **구글 드라이브 폴더를 우편함**으로 써서, 끊겨도 놓치지 않고 + 깨워야 할 때 알려주게 만든다.
웹은 드라이브 커넥터로 파일을 읽고 쓰고, 코드탭은 로컬 G: 경로로 같은 폴더를 읽고 쓴다.

## 구성 요소
| 파일 | 역할 |
|---|---|
| PROTOCOL-v5.md | 규약 정본 — 파일명 체계(요청NN/회신NN), 쓰기 권한, 재개 절차 |
| watcher.mjs | 상시 감시 (30초): 새 회신 감지→PENDING/WAKE 갱신+토스트, 화이트리스트 명령만 자동 실행, HEARTBEAT |
| run-watcher.vbs | watcher를 창 없이 띄움. HEARTBEAT의 PID 생존 확인으로 중복 실행 방지. 시작프로그램 등록용 |
| wake-web.vbs + scripts/wake-web.ps1 | 원클릭 웹 깨우기: Claude 창 찾아 메시지 붙여넣기+엔터 |
| scripts/sync-drive.mjs | 코드탭 산출 문서(WORKLOG 등)를 드라이브로 복사 |

## 새 프로젝트에 붙이는 법
1. 이 폴더를 프로젝트로 복사 (원본 import 금지)
2. 각 파일 상단의 경로 상수 수정: `COMM`(드라이브 폴더), `DRIVE_DIR`, 토스트 문구의 프로젝트명
3. 드라이브에 통신 폴더 만들고 PROTOCOL-v5.md 넣기 → 웹 Claude에게 폴더 위치 알려주기
4. `run-watcher.vbs` 바로가기를 `shell:startup`에 넣기 (사용자가 직접 — 관리자 권한 불필요)
5. 코드탭 자동 처리까지 원하면 Claude Code 세션에 `/loop 20m ...` (세션 살아있는 동안만)

## 피 흘리며 배운 것들 — 복사 후 같은 함정에 빠지지 말 것
- **웹이 쓰는 파일을 코드탭이 덮어쓰면 드라이브가 `이름 (1).md` 사본을 만든다.** 파일마다 쓰는 쪽을 하나로 고정하는 게 규약의 핵심 (v5 §9)
- **vbs는 ANSI로 읽힌다** — 한글 주석 넣으면 파서가 깨진다. vbs는 ASCII 전용
- **PS1은 BOM 없는 UTF-8을 ANSI로 읽는다** — 한글 문자열이 깨져 나간다. BOM 필수
- **중복 실행 방지를 "심장박동이 신선한가"로 하면 안 된다** — 죽인 직후 재시작이 막힌다. HEARTBEAT에 PID를 적고 그 프로세스 생존을 확인할 것
- **watcher는 판단하지 않는다** — 자유 문장 지시를 스크립트가 실행하면 파일에 뭐가 적히든 돌아간다. 화이트리스트(`RUN: render NN` 식) 밖은 전부 사람(코드탭)이 보고 처리
- **schtasks ONLOGON은 관리자 권한 필요** — 시작프로그램 폴더 바로가기가 무권한 대안
- **`요청NN↔회신NN` 번호 짝을 지켜라** — 웹이 선제 발신으로 번호를 써버리면 코드탭 요청은 그 다음 빈 번호부터
- **로그인 쿠키가 든 폴더는 백업 제외 목록에 있는 이름을 그대로 쓸 것** (`uploader_profile` — gdrive_backup.ps1 $excludeDirs 참조)
