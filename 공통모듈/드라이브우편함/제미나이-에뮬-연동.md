# 제미나이 ↔ 코드탭 자동 연동 (에뮬레이터 경유)

2026-08-01 사장픽에서 실제로 돌린 것. **웹 클로드 자리를 제미나이로 바꾸고, 사람이 깨우는 단계를 없앤 기록.**
여기 적힌 건 전부 실측이다. 추측 없음.

---

## 왜 이 구조인가

PROTOCOL-v5 의 유일한 구멍은 **"웹을 사람이 깨워야 한다"** 였다.
Gemini Spark(24시간 에이전트)를 붙여 보려 했으나 **최소 주기가 1시간**이라 실무엔 느렸다.

그래서: **에뮬레이터에 제미나이 앱을 띄워두고, 코드탭이 adb 로 찔러 깨운다.**

```
[watcher]      WEB_NEEDED 감지
     ↓
[gate.ps1]     3분마다 · adb 로 제미나이에 "check" 입력      ← AI 안 씀. 비용 0
     ↓
[제미나이]      드라이브 읽고 판단 → 구글 문서로 답 작성
     ↓
[collect_reply.py]  드라이브 API 로 문서 회수 → 회신NN.md    ← AI 안 씀. 비용 0
     ↓
[watcher]      CODE_NEEDED 로 올림
```

**AI 사용량은 제미나이 쪽만 나간다.** 코드탭은 루프에서 빠져 있다.

## 제미나이가 되는 것 / 안 되는 것 (2026-08-01 실측)

| 항목 | 결과 |
|---|---|
| 드라이브 **읽기** | ✅ 됨 |
| 드라이브 **쓰기**(구글 문서 생성) | ✅ **된다.** 이름 지정도 됨 (`REPLY08`) |
| 판단·문서 작성 | ✅ 형식(주제·STATUS)까지 지킴 |
| **스스로 감지** | ❌ 못 함. 누가 찔러야 함 |
| **폴더 지정 저장** | ❌ 못 함. `내 드라이브` 최상단에만 |
| **`.md` 파일 생성** | ❌ 못 함. **구글 문서(.gdoc)만** |
| **이미지 드라이브 저장** | ❌ 못 함 ("시스템 오류" 응답) |

> ⚠️ **「쓰기 못 한다」는 제미나이 말을 믿지 말 것 (2026-08-01 정정).**
> 대화창이 한 번 꼬이자 제미나이가 *"드라이브에 파일을 생성하거나 저장할 수 있는 기능 자체가 없습니다"* 라고
> 단호히 답했고, 그걸 사실로 받아 문서에 「쓰기 ❌」로 적었다. **틀렸다.**
> Gem 대화창에서 곧바로 `REPLY08` 구글 문서를 만들어 저장했다.
> → 제미나이의 자기 능력 진술은 근거가 아니다. **직접 시켜보고 드라이브를 확인**할 것.

### 오래된 파일을 못 찾는다 — 원인 규명됨

제미나이는 폴더를 훑는 게 아니라 **"최근 수정된 파일"만 검색**한다.
그래서 열흘 지난 `PROTOCOL-v5.md`·`INDEX.md` 를 "없다"고 답했다.

**해결:** 규약 문서들의 수정시각을 주기적으로 갱신하면 다시 검색된다.

## 에뮬레이터 셋업 (LDPlayer)

```
adb    : C:\LDPlayer\LDPlayer14\adb.exe      ← 안드로이드 SDK adb 말고 이것
기기    : 127.0.0.1:5555                      ← 자주 끊긴다. 매번 adb connect 할 것
제미나이 : com.google.android.apps.bard
          /com.google.android.apps.bard.shellapp.BardEntryPointActivity
```

- `monkey` 명령이 없다 → `am start -n <패키지/액티비티>` 로 띄운다
- 화면 좌표는 창 크기 따라 변한다. **입력창 ~(1200,989) · 전송 ~(1761,989)** (1920 폭 기준)
- **엔터(keyevent 66)가 자주 안 먹는다.** 전송 버튼을 직접 탭하는 게 확실하다

### 한글 입력 — ADBKeyboard

`adb shell input text` 는 **영문만** 된다. 한글은 ADBKeyboard 로:

```bash
adb shell ime set com.android.adbkeyboard/.AdbIME
adb shell "am broadcast -a ADB_INPUT_TEXT --es msg '한글 입력'"   # ⚠ 반드시 따옴표
adb shell "am broadcast -a ADB_CLEAR_TEXT"
```

⚠️ **함정 둘**
1. 공백을 따옴표로 안 감싸면 `pkg=테스트` 처럼 인자가 쪼개진다
2. ADBKeyboard 를 켜면 **전체 편집창**이 떠서 대화창에 안 들어간다.
   화면 오른쪽 **[완료]** 를 눌러야 본문으로 옮겨진다 → 그래서 평소엔 꺼두고, 필요할 때만 켠다

### 클립보드는 공유 안 됨

LDPlayer 는 윈도우 클립보드를 공유하지 않는다. `keyevent 279`(PASTE) 로 한글 붙여넣기 실패.

## 이미지 받아오기 (제미나이 생성 이미지)

제미나이는 **드라이브에 이미지를 못 올린다.** 대신 앱에서 저장하면 에뮬 안에 떨어진다.

```
① 제미나이에 "○○ 그려줘" 요청
② 생성된 이미지를 **탭** → 뷰어가 열리고 [복사] [저장] 버튼이 나온다
③ [저장] 탭 → "원본 크기 다운로드 중..." → 저장됨
④ 저장 위치: /storage/emulated/0/Pictures/<타임스탬프>.png
   ⚠ /sdcard/Pictures, /sdcard/Download 에는 없다. find 로도 안 잡힌다.
     MediaStore 로 찾아야 한다:
     adb shell "content query --uri content://media/external/images/media \
                --projection _display_name:_data --sort '_id DESC'"
⑤ adb pull 로 PC 로 가져온다
```

## 「저장했습니다」를 믿지 말 것 — 회수 3중 경로 (2026-08-02)

제미나이는 **저장하지 않고도 "REPLY09 저장했습니다"라고 답한다.** 실제로 그랬다.
모델이 Pro 에서 Flash 로 내려가 있으면 특히 그렇다. 화면 상단 모델명을 확인할 것.

**판정은 말이 아니라 드라이브 API 로 한다.**

```bash
python collect_reply.py --list      # 실제로 있는 것만 나온다
```

없으면 앱 기능으로 뽑는다. 이건 모델이 뭐라 하든 항상 된다.

```bash
python gemini_ui.py export          # 마지막 답변 ⋯ → Docs로 내보내기
```

⚠️ 내보내기로 만든 문서는 **이름이 답변 첫 줄**로 붙는다(`You said REPLY09 was saved...`).
그래서 회수기가 번호를 **이름 → 본문 순서로** 찾도록 고쳤다. 이름이 뭐든 회수된다.

### 좌표로 누르지 말 것

전송·메뉴를 화면 좌표로 누르다가 요청09 가 전송 안 된 채 멈춰 있었다.
사이드바가 접히면 전송 버튼 x 가 1761 → 1499 로 움직인다.
→ `gemini_ui.py` 가 **content-desc 이름**으로 찾아 누른다.

확인된 이름: `보내기` · `옵션 더보기` · `복사` · `듣기` · `새 채팅` · `사이드바 열기` · `첨부파일 추가`

⚠️ `옵션 더보기` 는 **상단 앱바에도 있다.** XML 순서로 마지막을 고르면 앱바 것(y≈98)이 잡힌다.
→ **y 가 가장 큰 것**을 골라야 최신 답변의 ⋯ 다.

## 스크립트 (사장픽에 구현됨)

| 파일 | 역할 | AI |
|---|---|---|
| `scripts/gate.ps1` | 3분마다 도는 문지기. WEB_NEEDED 뜨면 제미나이 찌름, 회신 문서 생기면 회수 호출 | ✕ |
| `scripts/collect_reply.py` | 드라이브 API 로 구글문서 → `회신NN.md` 변환 | ✕ |
| `watcher.mjs` | 폴더 감시·신호판 갱신 (PROTOCOL-v5) | ✕ |

작업 스케줄러 **"사장픽문지기"** 가 `gate.ps1` 을 3분마다 실행.
트리거를 2개 둔다(오늘치 24시간 반복 + 매일 00:05 재시작) — 하나만 두면 하루 뒤 멈춘다.

### collect_reply.py 인증

- 구글 OAuth. `credentials.json` 은 블로그스팟API 것을 복사해 씀 (같은 구글 프로젝트)
- 토큰은 **`drive_token.pickle` 로 분리** — 블로그 발행용 `token.pickle` 과 섞으면 권한 범위가 달라 블로그가 깨진다
- 권한은 **읽기 전용**(`drive.readonly`). 쓰기를 안 받아야 실수로 지울 경로가 없다
- ⚠️ 구글 클라우드 콘솔에서 **Drive API 를 켜야 한다.** 안 켜면 403 (`accessNotConfigured`)

### 겪은 함정

- **구글 문서 export 에 BOM 이 붙는다** → `startswith("주제:")` 가 빗나가 「주제:」가 두 번 찍혔다. `lstrip("\ufeff")` 필요
- **파이썬 3.9 는 google-auth 호출마다 FutureWarning 을 stderr 로 쏟는다** → `2>&1` 로 합치면 오류처럼 보인다. 걸러낼 것
- **성공 판정을 출력 문자열로 하면 안 된다** → "Not logged in" 같은 실패도 문자열로 온다. **파일이 실제로 생겼는지**로 판정할 것

## claude -p 는 쓰지 않는다

처음엔 회수를 `claude -p` 로 시키려 했으나 **헤드리스에서 로그인이 안 된다**(`Not logged in`).
게다가 3분 주기로 AI 를 부르면 하루 480회라 사용량이 감당이 안 된다.

→ **판단이 필요 없는 일은 코드로.** 회수·찌르기 둘 다 AI 없이 돈다.
