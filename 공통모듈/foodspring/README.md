# 식봄(foodspring) 수집 모듈 — 공통 원본

식봄(foodspring.co.kr, 식자재 중계몰) 시세 수집. **원본은 여기.** 프로젝트는 복사해서 쓴다.
(2026-07-25 올마나마에서 확립. 다른 세션에서 재발견하지 말 것.)

## 🔑 규칙 — 카테고리 우선, 검색은 폴백
- **카테고리(nid) 먼저** 긁는다. `goodsCategory(nid)`. 원물/세절 둘 다.
- **검색(goodsSearch)은 카테고리에 없는 품목일 때만** 폴백. 검색부터 하면 형태·품목·원산지가 섞여 오매칭 남발(염지닭 검색→대부분 염지제, 소갈비에 돼지갈비 등).
- 카테고리가 비어 보이면 → **잎 nid가 틀렸나부터 의심**(맞는데 정말 없는 품목도 있음. 예: 한우 다짐육).
- 소포장(pack_kg<1)·가공품·양념·교차종(소잎의 돼지 등) 필터링. 대표값은 원산지별 최저(원물/세절 합쳐).
- 육우 ≠ 한우(품종 다름). **식당 "국산" 소고기 = 대개 육우**(한우는 비싸서 못 씀).

## GraphQL
```
POST https://api.foodspring.co.kr/v2/graphql
헤더: Content-Type json · X-Device-Type: pc · Referer/Origin https://www.foodspring.co.kr
카테고리: goodsCategory(nid){name goodsList(sort:POPULAR_DESC,first:80){edges{node{name price{salePrice}}}}}
트리:     goodsCategory(nid){nid name parent{nid} children{nid name children{nid name}}}
검색:     goodsSearch(first,input:{keyword,sort},areaId:"area_324"){edges{node{name price{salePrice}}}}
```
- `salePrice` = 상시가(쿠폰가·정가 아님). introspection 막힘. areaId=area_324(게스트 기본).
