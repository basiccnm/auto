# coupang — 쿠팡 파트너스 API (상품 검색 · 제휴 링크)

**소매가**를 받는 공용 모듈. 상품 검색과 제휴(딥)링크 변환, 상품명에서 용량 읽기까지.
2026-07 올마나마에서 재료 소매가를 이걸로 모았다.

> 쿠팡**이츠**(배달 앱 화면으로 배달가 수집)는 옆 폴더 `coupang_eats\` 다. **다른 것이다.**

## 파일

| 파일 | 하는 일 |
|---|---|
| `coupang_api.py` | **원본 핵심.** 인증·검색·딥링크·용량파싱. `main()` 도 `sys.exit` 도 없다 |
| `coupang_cli.py` | 단독 확인용. 아무것도 저장하지 않는다 |

## 단독 테스트

```bash
python coupang_cli.py "동치미 냉면육수"
python coupang_cli.py --max 2500 "고춧가루"                       # 용량 상한(g)
python coupang_cli.py --deeplink "https://www.coupang.com/vp/products/1234567"
```

키는 `.env` 또는 환경변수:

```
COUPANG_ACCESS_KEY=...
COUPANG_SECRET_KEY=...
```

`.env` 는 **현재 폴더에서 위로 5단계까지** 찾는다(프로젝트 루트에 두면 된다).
경로를 프로젝트에 박지 않으려고 이렇게 했다 — 이식형 모듈이라서.

## 붙여 쓰기

```python
from coupang_api import keys, search, ok, items, parse_pack

ak, sk = keys()
body = search("생크림 500ml", ak, sk)
if ok(body):                       # 🔴 200 이라고 믿지 말 것
    for it in items(body):
        g, u = parse_pack(it["productName"])
        ...
```

`공통모듈/CLAUDE.md` 규칙대로 **import 하지 말고 복사**해서 쓴다.

## 검색해서 **최저가 고르는 절차** (이 순서대로)

```
① 검색            search(keyword, ak, sk)      ← 상위 10개만 온다
② 성공 확인       ok(body)                     ← rCode. 200 이라고 믿지 말 것
③ 용량 읽기       parse_pack(상품명)            ← 못 읽으면 후보에서 뺀다
④ 옵션 묶기       group_options(rows)          ← opt_n>1 이면 용량-가격을 짝짓지 않는다
⑤ 원/kg 로 줄 세우기                            ← 절대가격 아님
⑥ 사람이 ①물건 맞나 ②최소규격 ③총지출 최저 를 보고 고른다
⑦ 못 고르면 비운다                              ← 빈칸이 가짜보다 낫다
```

### 왜 「제일 싼 줄」이 최저가가 아닌가

- **옵션이 섞여 있다** — 같은 이름·다른 상품번호면 **싼 게 제일 소량**이다(아래 6번)
- **용량이 다르다** — 500g 3,000원보다 2kg 9,000원이 싸다(원/kg 6,000 vs 4,500)
- **샘플·선물세트** — `선물·기프트·세트박스·체험·샘플` 이 들어간 이름은 거른다
- **배송비** — 로켓이 아니면 배송비가 붙는다. `is_fresh()` · `isRocket` 을 함께 본다

### 검색어 요령

- **용량을 검색어에 넣는다** — `생크림 500ml` 처럼. 그래야 용량이 상품명에 박힌 게 올라온다
- 상위 10개뿐이고 **호출마다 결과가 조금씩 바뀐다.** 한 번 못 찾았다고 «없다» 로 단정하지 말 것
- 웹에서 눈으로 더 싼 걸 찾았으면 **`deeplink()` 로 제휴링크를 만든다**(그냥 주소는 수수료 0)

## 반드시 지킬 것

### 1. 실패해도 HTTP 200 이 온다
`rCode` 를 봐야 한다. `ok(body)` 가 그걸 한다.
안 보면 **«0건인데 정상»** 으로 착각한다 — 실제로 반복해서 겪었다.

### 2. 분당 50회
여러 번 부를 때 **`time.sleep(1.3)`**(분당 46회). 2026-07-27 에 쿠팡 용량을 3초 간격으로
몰아 읽다 **11건에서 차단**당했다. 브랜드별로 5~10건씩 끊고, **한 건씩 즉시 저장**해
끊겨도 이어가게 한다.

### 3. `limit` 은 최대 10
20 을 주면 `rCode=400 «limit is out of range»`. 그래서 검색 결과는 **상위 10개**뿐이고
호출마다 조금씩 바뀐다. 더 싼 걸 웹에서 눈으로 찾았으면 **`deeplink()` 로 제휴링크를 만든다** —
그냥 상품 주소를 걸면 수수료가 안 붙는다.

### 4. `signed-date` 는 GMT
로컬시간을 쓰면 401.

### 5. 용량은 **추측하지 않는다**
`parse_pack()` 은 개수가 엇갈리면(`(4인분)x3개, 1.816kg, 3개`) **None** 을 준다.
- 배수를 반드시 곱한다 — 식봄에서 「5kg 2팩」 배수를 놓쳐 **562건이 틀렸다**(2026-07-25)
- 쿠팡은 `냉면육수, 20개, 310ml` 처럼 **개수가 용량 앞에 오기도** 한다
- 틀린 용량은 「몇 인분 커버」를 통째로 망가뜨린다. **빈칸이 가짜보다 낫다**

### 6. 상품명은 같은데 상품번호가 다르면 — **싼 게 제일 소량이다** ⭐

같은 이름으로 여러 줄이 오는데 `productId`(또는 `itemId`)가 다르면, 그건 **다른 상품이 아니라
같은 상품의 옵션(용량·수량)** 이다. 그리고 **가격이 가장 낮은 줄이 가장 작은 용량**이다.

```
면사랑 함흥면사리(2kg)   1,250원   ← 제일 싸다 = 제일 작은 옵션 (2kg 값이 아니다)
면사랑 함흥면사리(2kg)   5,200원
```

🔴 **여기서 1,250원을 「2kg 가격」으로 쓰면 원가가 통째로 무너진다.**
같은 목록의 「10인분 9,900원」 = 1인분 990원과 견주면 1인분 104원은 말이 안 된다.
**상품명에 붙은 용량은 대표 옵션 하나의 표기일 뿐**이고, 싼 줄은 그보다 작은 옵션이다.

**그래서 이렇게 한다**

1. `group_options()` 로 같은 `productId` 를 묶는다 → 각 행에 `opt_n`(옵션 수)이 붙는다
2. `opt_n > 1` 이면 **상품명의 용량을 그 가격에 갖다 붙이지 않는다**
3. **원/kg 로 줄 세워** 고른다 — 절대가격이 아니라 **단위가격**이 최저가 기준이다
4. 그래도 어느 옵션인지 모르면 **비운다.** 사람이 상품 페이지에서 옵션을 보고 고른다

⛔ **최저가 = 목록에서 제일 싼 줄** 이 아니다. 그건 대개 「제일 작은 옵션」이거나
   샘플·체험·선물세트다. 용량을 못 읽은 줄은 후보에서 뺀다.

### 7. 로켓프레시는 별도 칸이 없다
**상품명에 붙어서** 온다 — `[로켓프레시] 면사랑 함흥면사리 10인분 (냉동)`. `is_fresh()` 참조.

### 8. 상품을 고르는 순서 (자동 판정 금지)
값이 싸다고 **다른 물건**을 붙인 적이 있다(포마스 혼합유·리코타 치즈·알룰로스, 2026-07-27).

1. **물건이 맞나**
2. 필요량을 덮는 **최소 규격**
3. **총지출** 최저
4. **못 찾으면 비운다**

### 9. 파트너스 약관
- 링크를 싣는 페이지에 **고지문 필수** — `DISCLOSURE` 상수를 그대로 쓴다
- ⛔ **제목·설명·도메인에 「쿠팡」·「로켓배송」 금지**(상표 사용 제한).
  본문에서 사실 서술("조사한 상품은 모두 로켓배송입니다")은 괜찮다

## 응답을 저장할 때

원본 키(`data.productData` · `productName`)를 그대로 쓰면 매번 헷갈린다.
올마나마는 «0건» 오독을 반복하다 **정본 형식**을 못박았다:

```json
{"keyword": "...", "fetched_at": "...", "count": 10,
 "items": [{"name": "...", "price": 0, "rocket": true,
            "free": true, "id": "...", "url": "...", "image": "..."}]}
```

`productData`·`productName` 이 아니라 **`items`·`name`·`price`·`rocket`** 이다.

## 함정 하나 더 — `sys.exit(main())`

이 모듈을 가른 이유다. 프로젝트의 `coupang_search.py` 는 파일 끝에 `sys.exit(main())` 이
있었고, 다른 데서 `import coupang_search` 만 해도 **프로세스가 그 자리에서 죽었다.**
관리자 서버에서 「쿠팡 찾기」를 눌렀더니 서버가 통째로 죽었다(2026-07-31).

→ **`coupang_api.py` 에는 `main()` 도 `sys.exit` 도 두지 않는다.** CLI 는 `coupang_cli.py` 로 분리.
