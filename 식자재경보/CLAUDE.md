## 구성

| 파일 | 역할 |
|---|---|
| `scripts/build.py` | 시세 수집 → 폭등 선별 → 대체재 검색 → `site/` 갱신. **이거 하나만 돌리면 된다** |
| `scripts/render.py` | data.json → index.html. 디자인 의도는 파일 상단 주석에 |
| `scripts/publicdata/` | 공공데이터 모듈 **복사본** (KAMIS·축평원·참가격·NEIS) |
| `scripts/coupang/` | 쿠팡 파트너스 모듈 **복사본** |
| `scripts/review.py` | **검수.** 원/kg 비교·중복·용량미상을 잡는다. 불합격이면 안 올린다 |
| `scripts/daily.ps1` | 매일 도는 갱신 (작업 스케줄러). 굽기 → 검수 → push |
| `site/` | 결과물. 이 폴더만 배포하면 된다 |

```bash
python scripts/build.py     # 굽기
python scripts/review.py    # 검수 (눈으로 보는 표 + 자동 판정)
```

## 🔴 깃허브 액션으로 수집하지 말 것 (2026-08-02 실측)

**KAMIS 는 해외 IP 를 막는다.** 깃허브 러너(미국 Azure, Cheyenne)에서 부르면
User-Agent·Accept·Accept-Language 를 어떻게 맞춰도 **HTTP 406 Not Acceptable** 이다.
4가지 조합 전부 실패했다. 헤더 문제가 아니라 **IP 차단**이다.

→ 수집은 **한국 IP 인 이 PC** 에서만 된다. 깃허브는 저장·배포만 맡는다.
→ ⚠️ 공공데이터 API 는 대체로 같은 정책이다. **다른 프로젝트를 액션으로 옮길 때도 같은 벽을 만난다.**
   (에듀싱크·학원비사이트의 NEIS 도 마찬가지일 가능성이 높다. 옮기기 전에 먼저 시험해 볼 것)
→ ⛔ 그렇다고 여러 번 찔러보지 말 것. 방화벽에 IP 가 걸리면 잘 되던 것까지 죽는다.
