| 파일 | 역할 |
|---|---|
| `webgui.py` (8899) | 통합 관리 화면 — 글 등록·발행·위젯 갱신 |

## 주의

- ⚠️ **Flask가 자동 리로더로 돌기 때문에**, 이 폴더 안에서 다른 작업 파일을 만들면 서버가 재시작돼 튕긴다. 다른 프로젝트 파일을 여기 만들지 말 것 (2026-07-17 실제 사고)
- **쇼핑몰 링크가 본문에 있으면 발행이 차단된다** (네이버 글 규칙). `manager.py`·`webgui.py` 양쪽에 검증이 걸려 있으니 우회하지 말 것
- 네이버 검색 API 키(`naver_config.json`)는 **사이드바 쇼핑 위젯**이 쓰고 있다. ⚠️ 이 앱에 '네이버 로그인'을 추가하면 검색 API가 막힌다 — 로그인이 필요하면 별도 앱을 만들 것
- `token.pickle` · `credentials.json` · `naver_config.json`은 인증 정보다. 채팅·커밋에 노출 금지

전 프로젝트 공통 원칙(규칙 0·목업 먼저·API 물어보기)은 글로벌 `~\.claude\CLAUDE.md`에서 자동으로 읽힌다.
