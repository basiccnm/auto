# 블로그 테마/탐색성 개선 - 정리 (재미나이 전달용)

## 현재 상황
- 블로그가 최근 "Dynamic Views" 테마에서 "Classic" 테마로 바뀜 (본인이 바꾼 건지 불확실)
- Classic 테마 특성상 본문 옆 사이드바가 비어있어서 오른쪽이 휑하게 보임
- 블로그 API로는 테마/레이아웃/위젯을 건드릴 수 없음(Blogger API 공식 미지원) → 전부 Blogger 대시보드에서 수동으로 해야 함

## 목표
1. 블로그를 더 보기 쉽게 (사이드바 정리)
2. 조회수 Top 5 인기 게시물 노출 → 방문자가 블로그에 오래 머물게
3. 성분 카테고리(유산균/오메가3/향후 홍삼·비타민C·밀크씨슬·루테인·종합비타민·다이어트식품·칼슘·마그네슘·비타민D·단백질보충제·콜라겐·아연·철분 등)를 넘나들며 보기 쉽게

## 테마 추천
- **비추천: Dynamic Views** - 위젯 배치가 거의 안 되고 구글이 신규 지원을 축소하는 추세
- **비추천: 지금 쓰는 기본 Classic** - 디자인이 너무 기본형, 사이드바 관리가 불편
- **비추천: Emporio, Contempo** - 이미지 그리드 중심 디자인이라, 이 블로그는 사진이 많지 않아서 안 어울림
- **추천: Notable** - Blogger 최신 테마 중 가장 텍스트/블로그 중심적, 사진 적어도 자연스러움
  - Soho도 후보 (Notable과 비교해보고 선택)
  - 테마 적용 후 커스터마이저에서 "게시물 목록 스타일"을 그리드형이 아닌 리스트/클래식형으로 설정하면 이미지 의존도가 더 줄어듦

## 대시보드에서 직접 해야 할 작업 (위젯/가젯)
1. 테마 갤러리에서 Notable(또는 Soho) 미리보기 → 적용
2. 레이아웃(Layout) → 가젯 추가:
   - **인기 게시물(Popular Posts)** - 조회수 기준 Top N 자동 표시 (원하는 개수로 설정, 예: 5개)
   - **라벨(Labels)** - 카테고리별 클릭 이동 가능하게
   - **검색창** - 있으면 유지, 없으면 추가
3. 저장 후 모바일/PC 화면 둘 다 확인

## 콘텐츠 쪽에서 이미 반영된/반영해야 할 것 (Claude Code가 API로 처리한 부분)
- 각 글에 "목적별 라벨"(다이어트, 키즈, 시니어, 남성건강, 여성건강, 임산부 등)을 유산균/오메가3 공통으로 붙이는 작업 진행 중
- 이렇게 하면 Blogger가 자동 생성하는 라벨 모아보기 페이지(`블로그주소/search/label/다이어트` 등)에서 성분과 무관하게 같은 목적의 글이 다 모여서 보임
- **향후 원칙**: 홍삼이든 비타민C든 새 성분 글을 쓸 때마다, 이미 쓰고 있는 것과 동일한 목적 라벨 이름(다이어트/키즈/시니어/남성건강/여성건강/임산부/갱년기/청소년 등)을 그대로 재사용할 것 → 라벨 위젯 하나로 전체 카테고리를 넘나드는 탐색이 자동으로 됨 (매번 수동으로 글마다 링크 걸 필요 없음)

## 재미나이에게 요청할 수 있는 것
- 테마 갤러리 미리보기 화면을 보고 Notable vs Soho 중 실제로 더 나아 보이는 쪽 판단
- 레이아웃 가젯 추가 작업 수행 (인기 게시물/라벨/검색창)
- 리스트형 vs 그리드형 게시물 스타일 중 이 블로그에 맞는 쪽 적용
